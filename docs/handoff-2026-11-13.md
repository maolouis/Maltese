## 5.1 本轮（未升版本，未推送）

### GIF / 表情轮播

根因：素材外置后，本地存储里的轮播配置仍是 `/assets/pets/...` 原始路径（还有更早版本存下的
`http://asset.localhost/...` 绝对地址），而 `petGifItemSrc` 原样使用它们，于是整条轮播链 404。
从 `%LOCALAPPDATA%\com.maolouis.maltese\EBWebView\Default\Local Storage\leveldb` 读到的实际数据确认了这一点。

改法：

- `src/petAssetBase.ts` 新增 `builtinAssetRelative()`：把原始路径、反斜杠写法、旧 `asset.localhost` 绝对地址
  统一还原成 `/assets/pets/` 之后的相对路径，再交给 `petAssetUrl()` 用资源目录解析。
- `src/petGifRotation.ts`：读取配置时规范化（内置素材统一存原始路径，自定义文件仍用绝对路径）；
  `petGifItemSrc` 对内置素材一律重新解析。
- `src/petCharacters.ts` 新增 `characterFramePaths()`（原始路径版），`characterFramesForState()` 在其上做 URL 转换。
- `src/App.tsx`：睡觉帧改成运行期求值（原来在模块加载期就 `petAssetUrl()`，资源目录还没初始化）；破图回退只执行一次，避免死循环。

### 插件独立化

- 新增预注册窗口 `plugin`（`index.html?window=plugin`），每个插件有自己的一页；
  `plugins::open_plugin_window` + `get_active_plugin` 负责切内容，`PluginWindow.tsx` 渲染。
- 第三方插件清单新增 `ui` 字段：有它就加载插件目录里的 html（iframe），实现见 `docs/plugins.md`。
- **内置插件也是插件文件**：`ui: "host"` 表示界面由宿主渲染，`resources\plugins\video-automation`
  与 `resources\plugins\relationship` 就是两个普通插件目录（各一个 `plugin.json`），不进
  `%APPDATA%\com.maolouis.maltese\plugins`；代码里的内置清单只在开发环境没有预置目录时兜底。
- 新增预置插件源 `<安装目录>\resources\plugins`（随安装包分发，只读、标「预置」），
  用户目录同 id 插件可覆盖。示例 `examples/plugins/hello-world` 已带 `ui` 并打包进去。
- 自动刷视频面板从 `App.tsx` 拆到 `src/plugins/video/VideoAutomationPlugin.tsx`，App.tsx 行数降到 8825；
  另有 `VideoAutomationPlugin.css` 专门给插件窗口/视频页一套浅色高对比样式（原来是深色悬浮岛的白字小字）。

### 「关系」插件

`src/plugins/relationship/`：配对码（6 位）→ 关系选择（情侣/朋友/兄弟）→ 双方互聊。
没有自建后端，用 ntfy 公网中继（默认 `https://ntfy.sh`，`localStorage` 的
`maltese-relationship:relay` 可改）。`src-tauri/src/relay.rs` 只负责 HTTP 收发密文；
配对码派生频道名与密钥、加解密在 `pairing.ts`（WebCrypto SHA-256 密钥流异或）。
**注意**：这是明文隐私模型之外的公网第三方中继，换服务端只要改中继地址即可。

### 插件中心可读性

`PluginsPanel.tsx` / `.css` 重写：卡片只留插件名 + 按钮（打开 / 动作 / 停用 / 卸载），
说明、作者、路径、安全提示全部进悬停气泡（`plugin-help-window`）；正文字号从 8–11px 提到 13–16px，
配色用品牌浅绿/浅橙，浅色面板与深色悬浮岛分别给了一套对比度。

## 8. 构建与发布（复制即用）

```powershell
# 构建（需要 updater 密钥环境变量，脚本会准备 tauri.release.conf.json）
$env:TAURI_UPDATER_PUBKEY = (Get-Content "$env:USERPROFILE\.tauri\maltese\updater.key.pub" -Raw).Trim()
$env:TAURI_SIGNING_PRIVATE_KEY = (Get-Content "$env:USERPROFILE\.tauri\maltese\updater.key" -Raw).Trim()
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = (Get-Content "$env:USERPROFILE\.tauri\maltese\password.txt" -Raw).Trim()
node scripts/prepare-release-config.mjs

# ⚠ 本机 esbuild 被安全软件限制：直接 pnpm build 会在删临时文件时 Access denied。
# 前端构建绕法（2.0.0 用这套跑通）：
node_modules\.bin\tsc.cmd                                         # 类型检查，exit 0
node_modules\.bin\vite.cmd build --target esnext --minify false    # 出未压缩 dist（JS 2.17 MB / CSS 266 KB）
# 再用 esbuild CLI 就地压缩；输出必须写进 dist\assets，写 E:\MalteseWork\tmp 会被拒（Access denied）：
$esb = "node_modules\.pnpm\@esbuild+win32-x64@0.28.1\node_modules\@esbuild\win32-x64\esbuild.exe"
# & $esb dist\assets\<文件> --minify --outfile=dist\assets\__min_<文件>；再 Move-Item -Force 覆盖原文件
# 压缩后 JS 1.08 MB / CSS 204 KB。
# 然后往 src-tauri\tauri.release.conf.json 注入 "build": { "beforeBuildCommand": "" }，
# 让 tauri build 不再跑 pnpm build、直接复用现有 dist。

node_modules\.bin\tauri.cmd build --ci --config src-tauri/tauri.release.conf.json --bundles nsis

# 组装 release\v<ver> + zip + SHA256SUMS + latest.json
node scripts/make-latest-json.mjs --notes-file docs/releases/v<ver>.md

# 交付前检查（Defender 扫描 + 签名状态 + SHA256）
powershell -File scripts/verify-release-artifacts.ps1 release\v<ver>\Maltese-<ver>-x64-setup.exe release\v<ver>\Maltese-assistant.exe
```

**发布时注意**：本机 DNS 会把 `github.com` 解析到错误地址（`57.155.223.240`）。实测：

- **git 走 SSH 免改 DNS**：`~/.ssh/config` 已把 `github.com` 指到 `ssh.github.com:443`，
  `git push origin HEAD:main` 直接可用（git 是 schannel 后端，`http.curloptResolve` 会被拒绝）；
- **REST API / 下载走 curl `--resolve`**：
  `curl --resolve api.github.com:443:20.205.243.168 …`、`curl --resolve uploads.github.com:443:20.205.243.161 …`、
  `curl --resolve github.com:443:20.205.243.166 …`。

本次实际发布流程（无 `gh`，全用 API）：

1. `POST /repos/maolouis/Maltese/releases`（`draft=true`，body 取 `docs/releases/v0.2.5.md`）；
2. `POST https://uploads.github.com/repos/.../releases/<id>/assets?name=<文件名>` 逐个上传 6 个资产，
   逐个核对返回的 `state=uploaded` 与 `digest`；
3. `PATCH /releases/<id>` 置 `draft=false` + `make_latest=true`；
4. 验证 `releases/latest/download/latest.json` 的 `version` 与 setup 下载地址。
