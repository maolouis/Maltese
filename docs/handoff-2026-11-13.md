## 8. 构建与发布（复制即用）

```powershell
# 构建（需要 updater 密钥环境变量，脚本会准备 tauri.release.conf.json）
$env:TAURI_UPDATER_PUBKEY = (Get-Content "$env:USERPROFILE\.tauri\maltese\updater.key.pub" -Raw).Trim()
$env:TAURI_SIGNING_PRIVATE_KEY = (Get-Content "$env:USERPROFILE\.tauri\maltese\updater.key" -Raw).Trim()
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = (Get-Content "$env:USERPROFILE\.tauri\maltese\password.txt" -Raw).Trim()
node scripts/prepare-release-config.mjs
node_modules\.bin\tauri.cmd build --ci --config src-tauri/tauri.release.conf.json --bundles nsis

# 组装 release\v<ver> + zip + SHA256SUMS + latest.json
node scripts/make-latest-json.mjs --notes-file docs/releases/v<ver>.md

# 交付前检查（Defender 扫描 + 签名状态 + SHA256）
powershell -File scripts/verify-release-artifacts.ps1 release\v<ver>\Maltese-<ver>-x64-setup.exe release\v<ver>\Maltese-assistant.exe
```

**发布时注意**：本机 DNS 会把 `github.com` 解析到错误地址（`57.155.223.240`），
`git push` / `curl` 都要带地址覆盖：

```powershell
git -c http.curloptResolve=github.com:443:20.205.243.166 push <url> HEAD:main
curl --resolve api.github.com:443:20.205.243.168 …
curl --resolve uploads.github.com:443:20.205.243.161 …
```

发布流程（历史脚本模式）：创建 draft release → 上传 6 个资产
（setup / setup.sig / latest.json / Maltese-assistant.exe / win64.zip / SHA256SUMS）→ PATCH 为 latest。
