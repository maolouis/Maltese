# 视频插件（小狗刷视频）使用说明

面向第一次用「小狗刷视频」的人：怎么进面板、怎么登录、怎么开始、怎么看小结、
出问题看哪一行提示。对应 2026-11-17 精简后的面板（`docs/qa-video-plugin-2026-11-17.md` §1）。

> 结论来自对 v2.0.2 代码的只读核对 + 构建产物抽查；真实 B 站/抖音页面上的采集效果
> 仍需实机验证，请以你机器上的实际表现为准。设计边界见
> [video-automation.md](video-automation.md)，账号模型见 [video-agent-refactor.md](video-agent-refactor.md)。

## 一、5 步上手（选平台 → 登录 → 开始 → 看小结 → 停）

面板只有两段：**首屏**（状态条、平台、登录、小结）和两个折叠区（**高级设置**、**评论**）。
参数、账号档案、自检、清空都在「高级设置」里，首屏不用滚动就能点到「开始看」。

### 第 1 步：进入面板

| 入口 | 操作 | 是否需要先装插件 |
| --- | --- | --- |
| 主窗口「插件」页 | 展开桌宠 → 顶部「插件」页签 → 页面里的「小狗刷视频」 | 不需要，面板内置 |
| 独立插件窗口 | 插件中心 →「小狗刷视频」→「打开」 | 需要（列表里没有就先装，见 [plugins.md](plugins.md)） |

### 第 2 步：登录（第一次必做）

插件**不用你日常浏览器的登录态，也不读 Cookie**。小狗有自己的 Chrome/Edge 实例和
独立 profile，第一次必须在这个专用浏览器里登录一次。

1. 首屏点「打开登录窗」。按钮会变成「等待登录…」，**只有真的出现了一个新的浏览器窗口
   才算成功**；没出现会直接报错（见第四节），不会「提示成功但没窗口」。
2. 在那个窗口里登录（扫码 / 手机号 / 邮箱都行，验证码由你本人完成）。
3. 关掉登录窗或留着都行。之后点「开始看」，插件会**复用**这个登录态；
   下次再打开登录窗时，如果同一个专用浏览器还在运行，会直接复用它而不是再开一个。

用「小狗账号」长期运营（可选）：展开「高级设置 → 账号档案（可选）」，填写账号名称、
昵称、人设、目标，点「创建小狗账号档案」，选中它再点「打开登录窗」——每个账号用
独立的 profile；登录完成点「我已登录」，状态变「已就绪」。

### 第 3 步：开始看

1. 首屏「平台」选「B站推荐流」（抖音标注「实验」）。
2. 点「开始看」（唯一主按钮）。状态条会依次变成「正在准备小狗浏览器…」→
   「小狗正在看」，右侧显示已看条目数。
3. 想限制时长就展开「高级设置」改「上限（分钟）」，点一次「保存参数」——
   **参数仅本次运行有效**，重开面板或重启 Maltese 会回到已保存值（默认 30 分钟）。

> 安全提示：专用浏览器**不会被提到前台**（只有「打开登录窗」会）。请不要最小化它，
> Chromium 会节流后台标签页导致采集变慢。

### 第 4 步：看小结

- 首屏「最近小结」：有小结就显示主题 + 最多 3 条；没有就写「还没有攒到小结」。
- 打开面板会自动加载历史，也可以点「刷新历史」重新读取；展开「历史会话」后，每条都写明
  **真实结束原因**（浏览器没准备好 / 需要登录 / 页面没解析到内容 / 平台风控 / 手动停止 …），
  并标出来源账号或「临时观看」，不再统一显示「异常崩溃」。

### 第 5 步：停

- 点「停下」：状态变「已暂停」，**专用浏览器会自动关闭**（避免残留实例占住 profile）。
- 自然到达时长/条目上限：同样会保存会话、整理小结，并关闭专用浏览器。
- 中途「停下」不生成小结（只保留已采集的历史记录）。

### 附：在视频下评论（可选，默认折叠）

展开「评论（可选）」→ 写 1–200 字 →「发送评论」。插件只负责把文字输入当前视频页并点一次
发送，**不校验平台是否真的发布**。

自动评论需要在「高级设置」中明确打开权限。启动时它读取聊天设置里的当前后端：选择 DSH 就使用已登录的 DSH 模型，选择本地模型就使用已配置的 OpenAI 兼容接口。模型收到视频标题、简介、作者和标签后只生成一条短评论；模型请求失败、返回空内容或超出长度时会写入诊断并跳过，不会发送模板评论。每条视频最多尝试一次。

## 二、面板控件说明

### 首屏（不用滚动）

| 控件 | 含义 |
| --- | --- |
| 状态条 | 一行：状态（已暂停 / 正在准备小狗浏览器 / 小狗正在看 / 本轮失败 …）+ 条目数 + 强兴趣数 |
| 开始看 / 停下 | 唯一主按钮：开始一轮 / 中止本轮 |
| 平台 | B站推荐流 / 抖音推荐流（实验）；运行中禁用 |
| 登录：xxx | 当前使用的身份（未登录（临时观看）或某个账号 + 状态）；上次选中的小狗账号会在重开面板后恢复；点「打开登录窗」登录 |
| 打开登录窗 | 打开/复用专用浏览器并停在平台首页；失败会直接报中文原因 |
| 最近小结 | 待投递数量 +「查看待投递小结」+ 小结内容 + 历史会话折叠 |
| 错误条 | **常驻**：任何失败都会留在这里，收起浮层、重开面板后仍然可见 |

### 高级设置（折叠）

| 控件 | 含义 |
| --- | --- |
| 每次翻页 / 上限 / 采集间隔 / 每天投递 | 观看参数（15–600 秒 / 1–240 分钟 / 1–5 秒 / 1–5 次）；**仅本次运行有效** |
| 允许小狗根据视频内容自动评论 | 明确授权后，小狗会从推荐流打开视频详情页，读取标题、简介、作者和标签，交给当前聊天模型生成一条评论，对每条视频最多尝试一次；默认关闭 |
| 保存参数 | 把参数写进当前进程（不落盘；重开面板会回到已保存值） |
| 专用浏览器 | 显示当前实例状态：会复用上次实例 / 会先清理残留再启动；「刷新」重新探测 |
| 关闭专用浏览器 | 手动关掉残留实例（U10），之后下一轮会干净启动 |
| 账号档案（可选） | 账号下拉、名称/昵称/人设/目标、「创建小狗账号档案」、「我已登录」 |
| 自检与诊断 | 「重新自检」+ 当前通道/能力/上次失败原因（中文）+ 诊断日志（读后端 `logs/video-<日期>.jsonl`） |
| 清空观看数据（保留登录） | 二次确认后清空历史/画像/待投递/日志，保留浏览器登录 profile |

### 评论（折叠）

| 控件 | 含义 |
| --- | --- |
| 发送评论 | 把评论框内容输入当前视频页并点一次发送（1–200 字，仅手动触发） |

## 三、失败提示对照表（全部中文，可排障）

每次失败都会：① 状态条变「本轮失败」；② 首屏出现常驻错误条（含诊断码小标签）；
③ 写一条诊断日志（`%APPDATA%\com.maolouis.maltese\video\logs\video-<日期>.jsonl`，
DSH `GET /api/video/diagnostics` 也能读到）。

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 「小狗专用浏览器启动后没有打开调试接口，登录窗没有打开」`CDP_UNAVAILABLE` | 浏览器被安全软件拦、启动被旧实例转交、端口没监听 | 点「关闭专用浏览器」再重试；确认 Chrome/Edge 能正常启动；首次允许安全软件放行 |
| 「小狗专用浏览器已在运行，但没能把登录窗显示出来」`LOGIN_WINDOW_NOT_VISIBLE` | 浏览器在后台/被旧实例接管 | 任务栏找到专用浏览器手动打开，或「关闭专用浏览器」后重试 |
| 「小狗专用浏览器没有在 15 秒内打开调试接口，本轮已停止」`CDP_UNAVAILABLE` | 开始看时浏览器没起来 | 同上；面板里能看到上次失败原因，不用重新点一次才看到 |
| 「检测到残留的专用浏览器，但调试接口不可用：开始前会先关掉它再启动」 | 上次的专用浏览器还在占用 profile/端口 | 直接再点「开始看」即可（会自动关残留）；也可先点「关闭专用浏览器」 |
| 「小狗专用浏览器已关闭，本轮已经停止」`BROWSER_CLOSED` | 你手动关了专用浏览器 | 重新「开始看」；已采集内容保留 |
| 「视频页面连接多次失败 / 连续无响应」`CDP_RECONNECT_FAILED` / `CDP_STALLED` | 页面卡死、网络或安全软件干扰 | 停掉重开；换网络；把诊断日志一起反馈 |
| 「请先在小狗专用浏览器里登录一次」`LOGIN_REQUIRED`，状态「等待你登录一次」 | 出现登录墙 | 在专用浏览器里登录，状态会自己恢复采集 |
| 「平台要求验证，小狗已经停下来了」`RISK_CONTROL` | 验证码/风控页 | 手动完成验证后重新开始；插件不会绕过验证 |
| 「专用浏览器没能启动起来」`BROWSER_UNAVAILABLE` / `BROWSER_START_FAILED` | 没装 Chrome/Edge、版本低于 120、启动失败 | 安装/升级 Chrome 或 Edge（默认安装路径），重启 Maltese |
| 「本机调试端口被占用」`PORT_BUSY` | 9333–9338 都被占用 | 「关闭专用浏览器」后重试；关闭其它带调试端口的 Chrome/Edge |
| 「请先完成小狗账号登录，再开始运营」`ACCOUNT_NOT_READY` | 选中账号还不是「已就绪」 | 打开账号登录窗 → 登录 → 点「我已登录」 |
| 「配置超出允许范围」`INVALID_CONFIG` | 参数越界 | 翻页 15–600 秒、上限 1–240 分钟、采集 1–5 秒、投递 1–5 次 |
| 历史里「条目 0」并写着原因 | 未登录 / 页面没解析到内容 / 风控 / 浏览器没起来 | 按原因处理；诊断日志里有对应 code |
| 结束后没收到气泡/聊天小结 | 投递门槛不满足（主动程度 0、免打扰、空闲 <120 秒、全屏、当日次数上限、指纹去重） | 首屏「查看待投递小结」手动看；或调高主动程度、避开免打扰 |

> 所有提示都在 `src/plugins/video/videoPanelLogic.ts` 里统一转中文；
> 原始错误码只作为小标签展示（排障用），不会再出现英文码刷屏或 `[object Object]`。

## 四、数据与隐私

### 登录态

| 用途 | 路径 |
| --- | --- |
| 临时观看（不绑定账号） | `%LOCALAPPDATA%\Maltese\video-profile` |
| 每个小狗账号 | `%LOCALAPPDATA%\Maltese\video-accounts\<account-id>` |

这些就是 Chrome/Edge 的 `--user-data-dir`，包含平台 Cookie。插件**不读取、不上传**。

**残留实例标记**：`%LOCALAPPDATA%\Maltese\video-browser.json` 只记录当前专用浏览器的
pid / 调试端口 / profile 路径。应用重启后靠它认出上次留下的浏览器：能复用就复用，
不能复用（进程已死 / 端口不通）就先清理再启动，不会出现「一次失败 = 永久失败」。

### 采集内容

数据根目录 `%APPDATA%\com.maolouis.maltese\video\`：会话 `sessions\`、`index.json`、
`profile.json`、`deliveries.jsonl`、`pending.json`、`accounts.json`，以及
`logs\video-<YYYYMMDD>.jsonl`（脱敏诊断日志，7 天）。存的是页面事实（标题/作者/时长/
标签/互动状态），不含 Cookie、截图或原始 HTML。

### 清空

- 面板「高级设置 → 清空观看数据（保留登录）」：删历史/画像/待投递/日志，保留 profile。
- 连登录态一起清：先「关闭专用浏览器」，再删 `video-profile` / `video-accounts\<id>`；
  也可用 DSH API `DELETE /api/video/data`（`includeBrowserProfile: true`）。

## 五、已知限制

- **抖音是实验特性**（虚拟列表 + experimental 选择器），优先用 B 站。
- **必须本机有 Chrome/Edge ≥120**；插件自己启动浏览器，没有内置内核。
- **依赖页面结构**：平台改版后可能解析不到内容/翻不动页/发不出评论；诊断日志会写明。
- **专用浏览器不要最小化**（Chromium 会节流后台页）。
- **参数不落盘**：仅本次运行有效；重开面板会回到已保存值。
- **自动评论权限默认关闭**，开启后只对已打开的详情页尝试一次。评论由启动时读取的 DSH/本地聊天模型生成；模型失败会写入 `AUTO_COMMENT_MODEL_FAILED` 诊断并跳过，不会退回模板台词或重复刷屏。
- **中途「停下」不出小结**；要小结请让它跑到时长上限自然结束。
- **一轮结束/停下会自动关专用浏览器**；想继续用登录态不用手动开，下一轮会自动复用。
