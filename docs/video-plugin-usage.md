# 视频插件（小狗刷视频）使用说明

面向第一次使用「小狗刷视频」的人：怎么装、怎么登录、怎么开始、怎么看小结、怎么在视频下评论、数据存在哪里、出问题怎么办。

> 本文的结论来自 **2026-11-17 对 v2.0.2 代码的只读核对**，并在每节末尾用
> 「读代码确认 / 未实机验证」标注可信度。没有在真实 B 站 / 抖音页面跑过完整
> 流程的项目都归到「未实机验证」，请以你机器上的实际表现为准。
>
> 想先了解插件的设计与边界，看 [video-automation.md](video-automation.md)；
> 账号模型与重构背景看 [video-agent-refactor.md](video-agent-refactor.md)。

## 一、5 分钟上手

### 第 1 步：进入到插件面板

有两条入口，功能是同一块面板：

| 入口 | 操作 | 是否需要先安装插件 |
| --- | --- | --- |
| 主窗口「插件」页 | 展开桌宠 → 点顶部「插件」页签 → 页面上方就是「自动刷视频」 | 不需要，面板内置在主窗口 |
| 独立插件窗口 | 插件中心列表里找到「小狗刷视频」→ 点「打开」 | 需要，列表里没有就先安装（见下） |

安装方式（可选）：把 `video-automation.zip` 的路径粘贴到插件中心的安装框，
点「安装插件」；也可以解压后粘贴文件夹路径，或手动放进插件目录后点「刷新」。
发布包附带这个 zip；从源码构建时可用
`powershell -File scripts/pack-plugins.ps1 -OutputDir <目录>` 生成。
插件目录用「打开插件目录」查看。装好后卡片上会出现「打开」按钮。

> 读代码确认：主窗口 `VideoPage` 直接渲染面板（`src/App.tsx`），独立窗口走
> `open_plugin_window`，该命令会先 `list_plugins` 校验插件已安装
> （`src-tauri/src/plugins.rs`）。未实机验证：发布包里是否默认预置该插件因安装方式而异。

### 第 2 步：首次登录（重点：单独开的账号在这里登录）

插件**不使用你日常浏览器的登录态，也不读取 Cookie**。小狗有一个自己的
Chrome/Edge 实例和独立的 profile 目录，第一次必须在这个专用浏览器里登录一次。
你单独给小狗开的那个账号，也是在这个窗口里登录，而不是在你平时用的浏览器里。

**A. 想用「小狗账号」长期运营（推荐）**

1. 在面板「小狗自媒体账号」卡片里填：
   - 账号名称（必填，≤32 字，同一平台不能重名，例如「小狗运营号」）；
   - 平台昵称或账号（可选，填你单独注册的那个号，方便自己认）；
   - 小狗人设 / 运营目标（可选，会用于草稿风格）。
2. 点「创建小狗账号档案」。状态先是「草稿」（下拉框里显示 `draft`）。
3. 在账号下拉框选中这个账号。
4. 点「打开账号登录窗」。会弹出一个**普通浏览器窗口**（专用 profile，停在平台首页）。
5. 在这个窗口里用你单独开的账号完成登录（扫码 / 手机号 / 邮箱都行；验证码、
   注册流程都由你本人在官方页面完成）。**登录态会留在这个专用 profile 里。**
6. 回到 Maltese，点「我已登录」。账号状态变成「已就绪」。
7. 以后「开始看」都用这个账号的 profile，正常不需要再登录。

> 读代码确认：`AgentAccount` 保存 profile 目录，`open_login_window` 会
> `mark_login_started`（等待登录），「我已登录」调用 `video_mark_account_ready`；
> `video_start_session` 要求账号状态为 `ready`，否则报 `ACCOUNT_NOT_READY`。
> 未实机验证：真实登录态能否跨版本升级、跨浏览器更新长期保留（正常 Chrome
> profile 可以，但没有在本项目上实测）。

**B. 只是临时看看（不绑定账号）**

1. 账号下拉框保持「临时观看，不绑定账号」。
2. 点「打开登录窗」，在专用浏览器里登录（可以是你自己的账号）。
3. 回到面板直接点「开始看」。登录态保存在默认 profile 里，下次还在。

### 第 3 步：选平台、调参数、开始

1. 平台下拉框选「B站推荐流」或「抖音推荐流（实验）」。**先选 B 站**，抖音仍是实验特性。
2. 参数先用默认值（下面第二节有逐项说明），想试跑就先把「上限」改成 10 分钟。
3. 点「开始看」。小狗会：
   - 启动专用浏览器（先停在 `about:blank`；除「打开登录窗」外不会主动把窗口提到前台）；
   - 连上调试端口，打开平台推荐流；
   - 每「采集间隔」读一次页面事实，每「每次翻页」翻一页；
   - 到达「上限」分钟数（或内部条目上限 200 条）后自动结束。
4. 面板顶部会显示状态：「正在准备小狗浏览器」「等待你登录一次」「小狗正在看」等。
   中途如果出现登录页，状态变成「等待你登录一次」，你在专用浏览器里登录后它会自己继续。
5. 这期间**不要最小化专用浏览器**（Chromium 会节流后台标签，采集会变慢）。

> 读代码确认：启动时 `pick_port` 在 9333–9338 里挑空闲端口，`browser::launch`
> 带 `--user-data-dir` + `--remote-debugging-port`，非登录场景不前台化；翻页
> B 站用 PageDown / 抖音用 ↓；CDP 连不上 15 秒、连续无响应 3 次都会结束本轮并写诊断。
> 未实机验证：真实页面上的采集/翻页效果（页面改版会让选择器失效，见第五节）。

### 第 4 步：看小结

两种方式，二选一：

- **自动投递**：本轮结束后，小狗会尝试把小结写进聊天记录并弹一个云朵气泡。
  但投递有门槛：主动程度不能是 0、不能在免打扰时段、你要离开电脑 ≥120 秒、
  不能全屏、前台不能是会议/游戏，且当天投递次数没到上限。不满足就**不打扰你**。
- **手动查看**：面板「小结与历史」里点「查看待投递小结」（有待投递时按钮才出现），
  右侧会显示主题 + 最多 5 条 + 生成方式（模型/模板）。

「观后感草稿」区可以「复制草稿」，或点「打开投稿页 / 打开直播中心」用系统浏览器
打开官方页面。**插件不会替你发布、开播或关注。**

> 读代码确认：投递门槛在 `src/videoDelivery.ts` + `src/useVideoDelivery.ts`；
> 待投递队列最多 5 条（`delivery.rs`）。未实机验证：你机器上的主动程度/免打扰设置
> 会不会挡住投递（挡住了就用手动查看）。

### 第 5 步：在视频下评论

「在视频下评论」是**手动**功能，只有你点「发送评论」才执行：

1. 先点过「开始看」且专用浏览器还开着（评论复用这一轮的调试端口）。
2. 切到专用浏览器窗口，打开你想评论的视频页（B 站视频页 / 抖音视频页；
   只是停在首页推荐流时页面里可能没有评论框）。
3. 回到面板，在评论框写 1–200 字，点「发送评论」。
4. 到专用浏览器里确认评论真的出来了。插件只负责填框 + 点一次发送，
   **不会校验平台是否真的发布成功**，也不做重试。

评论失败时面板会给出原因码对应的中文提示（没找到输入框、没找到发送按钮、
连不上浏览器等），排查见第四节。

> 读代码确认：`src-tauri/src/video/comment.rs` 只找可见的 textarea /
> contenteditable，写入后点「发送/发布/评论/回复」按钮；`video_post_comment`
> 在没开始过（端口为 0）或连不上 CDP 时直接报错。未实机验证：在真实 B 站/抖音
> 页面能否一次成功（页面结构一变就会失败）。

### 第 6 步：停止与收尾

- **想提前结束**：点「停下」。它会立刻关掉专用浏览器。注意：**中途手动「停下」
  不会生成小结**，本轮采集的内容不会写进会话文件（历史里会留下一条开始时的空
  会话记录）。要有小结请让它跑到时长上限自然结束。
- **到点自然结束**：状态变成「这一轮看完了」，小结入队/投递；**专用浏览器不会
  自动关闭**，请自己关掉那个窗口，或让它在后台（不要最小化）。
- 下一轮开始前，先确认上一轮的专用浏览器窗口已经关掉，避免同一个 profile
  被两个实例占用。

> 读代码确认：`stop()` 只置停止标记并关闭浏览器，不调用 `finish`；只有到达
> 时长/条目上限、浏览器关闭、风控等路径才会保存会话并（视原因）生成小结。
> 未实机验证：结束阶段浏览器残留窗口的实际表现。

## 二、每个按钮/开关是什么意思

### 顶部控制区

| 控件 | 含义 | 推荐值 |
| --- | --- | --- |
| 平台下拉框 | 「B站推荐流」/「抖音推荐流（实验）」；运行中禁用，不能中途换平台 | 先用 B 站 |
| 每次翻页（秒） | 两次翻页之间的间隔，允许 15–600 | 45（想细看 60–90，想快 20–30） |
| 上限（分钟） | 本轮最长观看时长，允许 1–240；到点自动结束并出小结 | 第一次 10–15，稳定后 30 |
| 采集间隔（秒） | 每隔几秒读一次页面事实，允许 1–5；通道内部还有约 2 秒节流，填 1 实际也接近 2 秒；越小越细但越吃 CPU | 2（低配机器 3–5） |
| 每天投递（次） | 每天最多投递几份小结，允许 1–5；同时还会按 7 天指纹 / 24 小时话题去重 | 2 |
| 开始看 / 停下 | 开始一轮 / 中止本轮（停下不产生小结） | — |
| 保存配置 | 把页面上的参数写进当前进程的配置；**不落盘**，重启 Maltese 后回到默认值（插件窗口重开后「采集间隔 / 每天投递」也会回默认 2） | 调完参数点一次 |
| 打开登录窗 | 打开专用浏览器登录；**没有选中账号时**用默认 profile，**选中账号时**打开该账号自己的 profile | 第一次用 |
| 刷新历史 | 重新拉取最近会话摘要 | 想看历史时 |

### 小狗自媒体账号

| 控件 | 含义 | 推荐 |
| --- | --- | --- |
| 账号下拉框 | 「临时观看，不绑定账号」或某个小狗账号；只列当前平台的账号 | 长期用就选账号 |
| 打开账号登录窗 | 用该账号的独立 profile 打开浏览器，并把状态改为「等待登录」 | 第一次用某账号时 |
| 我已登录 | 只在「等待登录」时出现；确认登录完成后点它，状态变「已就绪」 | 登录后立刻点 |
| 账号名称 / 昵称 / 人设 / 运营目标 | 本地档案，只用于区分账号和草稿风格，不读取平台资料 | 人设可以随意写 |
| 创建小狗账号档案 | 新建档案（不会自动填手机号、验证码） | 需要长期运营时 |

### 通道与诊断

| 控件 | 含义 |
| --- | --- |
| 重新自检 | 调用 `video_probe_channels`，查看当前通道、能力等级、失败原因 |
| 诊断日志 | 展开「重新自检」得到的通道条目；真正的脱敏日志在 `logs\video-<日期>.jsonl`，也可用 DSH API `GET /api/video/diagnostics?limit=20` 读 |

### 小结与历史

| 控件 | 含义 |
| --- | --- |
| 查看待投递小结 | 从待投递队列取队首显示；若已自动投递过，可能没有待投递 |
| 刷新 | 重新读取最近 20 条会话摘要 |
| 清空小狗的观看数据（保留登录） | 删除会话、索引、画像、投递记录、待投递与日志，**保留浏览器登录 profile** |

### 评论与草稿

| 控件 | 含义 |
| --- | --- |
| 发送评论 | 把评论框内容输入当前视频页并点一次发送（1–200 字，仅手动触发） |
| 复制草稿 | 把观后感草稿复制到剪贴板 |
| 打开投稿页 / 打开直播中心 | 用系统浏览器打开官方页面，发布仍需你本人确认 |

> 读代码确认：所有按钮文案与调用在 `src/plugins/video/VideoAutomationPlugin.tsx`；
> 参数区间在 `src-tauri/src/video/config.rs`（`maxMinutes` 1–240、
> `pageIntervalSeconds` 15–600、`sampleIntervalSeconds` 1–5、`dailyDeliveries` 1–5、
> `maxItems` 20–500 默认 200 且界面不暴露）。前后端不一致的输入会被拒绝并提示。

## 三、数据与隐私

### 登录态存在哪

| 用途 | 路径 |
| --- | --- |
| 临时观看（不绑定账号）的登录态 | `%LOCALAPPDATA%\Maltese\video-profile` |
| 每个小狗账号的登录态 | `%LOCALAPPDATA%\Maltese\video-accounts\<account-id>` |

这些目录就是 Chrome/Edge 的 user-data-dir，里面会包含 Cookie 等平台登录信息。
**插件本身不读取、不上传这些内容**——它只是用这个 profile 启动浏览器。

### 采集内容存在哪

数据根目录：`%APPDATA%\com.maolouis.maltese\video\`

| 路径 | 内容 | 保留 |
| --- | --- | --- |
| `sessions\<YYYY-MM>\<sessionId>.json` | 会话、条目、信号、判定、小结 | 30 天 |
| `index.json` | 会话索引（损坏会自动改名为 `.corrupt` 并重建） | 随会话 |
| `profile.json` | 兴趣画像（正/负标签、作者偏好） | 常驻 |
| `deliveries.jsonl` | 投递记录（只留指纹与时间） | 90 天 |
| `pending.json` | 待投递小结队列（≤5） | 30 天 |
| `logs\video-<YYYYMMDD>.jsonl` | 脱敏诊断日志（内存里最多 200 条） | 7 天 |
| `accounts.json` | 小狗账号档案（名称、人设、目标、profile 路径、状态） | 常驻 |

会话里存的是页面事实：标题、作者、时长、进度、标签、互动状态等，不含 Cookie、
不含截图、不含原始页面 HTML。

### 怎么清除

1. **常规清空（保留登录）**：面板「清空小狗的观看数据（保留登录）」。
   会删除上表除 `accounts.json` 与浏览器 profile 以外的数据；运行中会提示先停止。
2. **连登录态一起清（需要重新登录）**：先关闭专用浏览器，再手动删除
   `%LOCALAPPDATA%\Maltese\video-profile`；账号的则删除
   `%LOCALAPPDATA%\Maltese\video-accounts\<account-id>`。
   DSH API 也可代劳：`DELETE /api/video/data` 带 `includeBrowserProfile: true`。
   注意清除账号 profile 不会删除 `accounts.json` 里的账号记录，状态会停在旧值。
3. **彻底重置**：停掉 Maltese → 删除 `%APPDATA%\com.maolouis.maltese\video\`
   和 `%LOCALAPPDATA%\Maltese\` 下的 `video-profile` / `video-accounts`。

> 读代码确认：路径来自 `browser.rs`（LOCALAPPDATA + `Maltese\video-*`）与
> `session.rs` 的 `data_root`（`app_data_dir()/video`，应用标识
> `com.maolouis.maltese`）；保留期与清空逻辑在 `store.rs`。

## 四、故障排查

面板里的报错码来自 `src/plugins/video/types.ts` 的 `errorMessageForCode`，下面按
「现象 → 原因 → 处理」排列。

| 现象（提示/报错） | 可能原因 | 处理 |
| --- | --- | --- |
| 「没有找到 Chrome 或 Edge（需要 120 及以上版本）」`BROWSER_UNAVAILABLE` | 标准安装路径下没有 Chrome/Edge，或版本低于 120 | 安装/升级 Chrome 或 Edge 到默认位置（Program Files 或 LocalAppData 下的 `Google\Chrome\Application\chrome.exe`、`Microsoft\Edge\Application\msedge.exe`），重启 Maltese 再试 |
| 「本机调试端口被占用」`PORT_BUSY` | 9333–9338 都被占用（其他调试实例、旧浏览器没退干净） | 关掉所有带调试端口的旧 Chrome/Edge 窗口，必要时重启 Maltese |
| 「小狗浏览器没有及时准备好，本轮已经停止」`CDP_UNAVAILABLE` | 15 秒内没连上 CDP：浏览器被安全软件拦、旧实例占着同一个 profile、端口没监听 | 关闭该 profile 的所有浏览器窗口，确认没有残留进程后重试；首次启动允许安全软件放行 |
| 「小狗浏览器连接连续失败」`CDP_RECONNECT_FAILED` | 运行中 CDP 反复断线 | 停掉本轮，关闭浏览器，重开一轮；频繁出现请检查网络/安全软件 |
| 「小狗浏览器已关闭，本轮已经停止」`BROWSER_CLOSED` | 你手动关了专用浏览器 | 重新「开始看」；本轮已采集内容会保留（但不会出小结） |
| 「视频页面连续无响应」`CDP_STALLED` | 页面卡死/加载不出/被平台限制 | 停掉重开；换网络或稍后再试 |
| 「请先在小狗专用浏览器里登录一次」`LOGIN_REQUIRED`，状态停在「等待你登录一次」 | 页面出现登录墙 | 切到专用浏览器窗口完成登录，状态会自己恢复采集；不再弹登录页后可继续 |
| 「平台要求验证，小狗已经停下来了」`RISK_CONTROL` | 出现验证码/风控页，插件不会绕过 | 在专用浏览器里手动完成验证，再重新「开始看」 |
| 「请先完成小狗账号登录，再开始运营」`ACCOUNT_NOT_READY` | 选中了账号但状态不是「已就绪」 | 打开账号登录窗 → 完成登录 → 点「我已登录」 |
| 「小狗账号的平台和当前选择不一致」`ACCOUNT_PLATFORM_MISMATCH` | 账号属于 B 站，平台选择了抖音（或反过来） | 换成匹配的平台，或换账号 |

## 五、已知限制

- **抖音是实验特性**：抖音推荐流是虚拟列表，抽取选择器标注为 experimental；
  翻页/采集比 B 站更容易失效。想稳定用请优先 B 站。
- **必须本机有 Chrome 或 Edge（≥120）**：插件自己启动浏览器，不用系统默认浏览器，
  也没有内置内核。没有就报 `BROWSER_UNAVAILABLE`。
- **依赖页面结构**：标题、作者、按钮、评论框都靠选择器找；平台改版后可能读不到
  内容、翻不动页或发不出评论。这是当前架构的硬限制。
- **专用浏览器不能被最小化**：Chromium 会节流后台页面，最小化后采集会变慢甚至停。
- **登录态与 profile 绑定**：换机器、删 profile、清浏览器数据都要重新登录；
  平台本身的风控/异地登录也可能让登录态失效。
- **评论只有手动一种**：插件不会自动评论、自动点赞、自动关注、自动投稿或开播。
  配置里虽然保留了自动点赞/收藏的字段与护栏骨架，但**当前没有接入执行路径**，
  面板也不暴露开关（读代码确认：`guard::default_guard()` 关闭且无调用点）。
- **手动「停下」不出小结**：要小结就让它自然到点结束。
- **同 profile 不要开两个实例**：登录窗和开始看都用同一 profile，建议先关登录窗
  再开始新一轮（未实机验证：并发时 CDP 能否连上，按 Chromium profile 锁的行为推断）。
- **历史最多 20 条**、待投递最多 5 份、单轮条目上限 200 条；会话 30 天、投递 90 天、
  日志 7 天后自动清理。
- **只在本机运行**：不抓包、不逆向平台接口、不读 Cookie、不上传内容；采集到的
  是页面事实，不是视频文件。
