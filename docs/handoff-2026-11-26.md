1. **同一时刻只让一个 agent 构建/安装/重启 `E:\Maltese2`**（用 `work/.build-lock`，删锁前核对 owner）。
2. **禁止 `git commit --amend` / `rebase` / `reset`**（发生过 3 次误伤）。
3. **禁止删除依赖**（`node_modules`、lock 文件、`%APPDATA%\npm`、corepack、`E:\.pnpm-store`）。
4. **agent 的实机结论要看它是否有 `os error 5` / `0x800700AA`**：agent 运行环境常缺数据目录写权限
