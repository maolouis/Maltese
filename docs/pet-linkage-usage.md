# 小白和小鸡毛的互动（实例联动）使用说明

> 面向使用者，不是开发文档。看完这一页你就能让两只小狗「接上话」。

## 1. 这是什么

打开「实例联动」之后，小白和小鸡毛会**互相接话**：你摸一下主狗，旁边的小狗会跟着动，
还会冒出一句台词；两只狗一人一句、有先后、有来有回——不是只换一张表情包。

## 2. 怎么开

设置 → 桌宠 / 桌宠形态 → **实例联动**（默认就是开着的）。

两个地方都能找到这个开关：

- **岛内设置页**：展开桌宠浮层 → 顶部「设置」→「实例联动」区块；
- **独立设置窗口**：托盘图标右键「配置桌宠」，或设置页里的「独立设置窗口」。

同一区块里还有一个 **「试一下联动」** 按钮，见下一节。

## 3. 怎么触发联动（三种方式，任选）

### 默认触发场景一览（打开联动后，主狗做什么 → 会听到什么）

| 触发 | 场景 | 默认台词（成对，一问一答） |
| --- | --- | --- |
| 摸主狗的头（单击换表情也算） | S1 摸头 | 小鸡毛：「小白小白！主人先摸我了！」→ 小白：「……嗯。我排队。」 |
| 互动面板「喂食」 | S2 喂食 | 小白：「你先吃，我不急。」→ 小鸡毛：「那我吃一半，留一半给你！」 |
| 主狗开心 / 庆祝 | S3 开心 | 小鸡毛：「好耶！一起跳！」→ 小白：「……就一下下。」 |
| Bongo 模式 + 按空格 | S4 Bongo | 小鸡毛：「咚！我也敲！」→ 小白：「……小声一点。」 |
| 连续同一类活动 ≥40 分钟 | S5 久坐 | 小鸡毛：「走啦走啦！」→ 小白：「……我陪着走到窗边。」 |
| 23:00–05:00 首次（且开了夜间陪伴） | S6 夜间 | 小白：「灯关小一点……晚安。」→ 小鸡毛：「明天还要一起玩！」 |
| 离开电脑 ≥10 分钟后回来 | S7 回归 | 小鸡毛：「你回来啦！！」→ 小白：「……欢迎回来。」 |

- 每对台词都是「小鸡毛先说、小白后应」，两句来自同一组、错峰约 120ms；每场景 6 组备选，轮换不重复。
- 主狗是「小白和小鸡毛」同框形象时，台词角色随机分配一人，随从补另一人（不会两只狗说同一句）。

### 方式一：点「试一下联动」——立刻看一次完整演示

在「实例联动」区块点 **「试一下联动」**：

- 会临时出现一只随从狗（即使你现在只有 1 只狗）；
- **那只临时随从一定会说话**：它会拿到一个临时身份（通常是小鸡毛，主狗是小鸡毛时换成小白），
  按剧本说一句，主狗说另一句；两只狗各一句、先后差约 0.12 秒，各自头顶冒气泡；
- 小鸡毛会蹦一下，小白会退半步再慢慢靠回来；
- **3 秒后自动复原**，你的「小狗数量」「Bongo」设置不会被改动
  （唯一副作用是在本地记一条台词去重历史，好让下次演示换一组台词）。

这是最快看到效果的方式，确认没问题后再用下面的真实触发。

### 方式二：把「小狗数量」调到 ≥2，然后摸主狗

1. 设置里把 **小狗数量（含主狗）** 调到 2～5；
2. 回到桌面，**摸主狗的头**（或用互动面板里的「摸头 / 喂食」）；
3. 随从狗会接话：

| 主狗动作 | 会看到的互动 |
| --- | --- |
| 摸头 | 小鸡毛：「小白小白！主人先摸我了！」→ 小白：「……嗯。我排队。」 |
| 喂食 | 小白：「你先吃，我不急。」→ 小鸡毛：「那我吃一半，留一半给你！」 |
| 主狗开心 / 庆祝 | 小鸡毛：「好耶！一起跳！」→ 小白：「……就一下下。」 |

### 方式三：打开 Bongo，用键盘触发

1. 设置里打开 **Bongo 模式**；
2. 主狗开心（或庆祝）时，Bongo 会敲一下；
3. 你按 **空格** 时，主狗会摇尾巴、轻跳一下，两只狗会说 S4 那句：
   小鸡毛：「咚！我也敲！」→ 小白：「……小声一点。」

## 4. 能看到什么

- **谁先说**：小鸡毛先（主动、直球），小白后（回应、克制），两句相隔约 120ms；
- **气泡位置**：台词气泡在**说话那只狗自己的头顶**，不在主狗头顶；
- **气泡样式**：白底小气泡，宽不超过 160px，显示约 1.8 秒；
- **动作差异**：
  - 小鸡毛：朝主狗方向蹦过去（位移 8–16px）+ 放大一下（1.0→1.08→1.0）+ 摇尾巴；
  - 小白：先退半步，再慢慢靠回来（回位约 1.2 秒）+ 小幅点头。
- **多只随从**：小狗数量 3 只以上时，被选中的两只随从一定是「一只小鸡毛 + 一只小白」各一句，
  不会两只随从说同一句（这时主狗本轮不说话）。

## 5. 台词会重复吗

不会一直念同一句。每个场景有 **6 组备选台词**（摸头 / 喂食 / 开心 / Bongo /
久坐 / 夜间 / 回归），**最近说过的 5 组不会马上重复**，会换着说
（备选组数 ≥ 去重窗口 + 1，所以「最近 5 组不重复」是能做到的）。
台词按角色区分：小鸡毛活泼直球、小白安静害羞，不会互相串词。

## 6. 关掉会怎样

关掉「实例联动」后：**0 句台词、0 个联动动作**。主狗自己的动作、气泡、聊天都不受影响。

## 7. 常见问题

**Q：我开了联动，但什么都没有？**
先看两件事：① 小狗数量是不是 1？② Bongo 是不是关的？
**Q：只有 1 只狗，联动是不是就没有台词？**
分两种情况：
- **真实触发**（摸头 / 喂食 / Bongo）：没有随从时主狗会自说两句（A/B 剧本，第二句是自我回应），
  不会完全没声音；想要「一问一答」就把小狗数量调到 ≥2，或点「试一下联动」临时拉一只随从；
- **「试一下联动」**：预览一定会临时出现一只随从，且**那只临时随从会说话**（主狗说另一句），
  所以即使 `petCount=1` 也能看到完整的两只狗各一句。

**Q：气泡被屏幕边缘裁掉了？**
不会。气泡现在钉在每只狗窗口的**内部顶部**，窗口贴边时也不出窗口；
如果狗在屏幕最边缘，气泡仍会完整画在它头顶。

**Q：多显示器 / 系统缩放 125%、150% 会乱吗？**
随从窗口的位置和大小由系统按缩放自动换算，气泡是窗口内布局，不依赖绝对坐标。
不过 200% 以上缩放 + 超小屏幕时气泡可能压住狗的头，属已知观感问题。

**Q：为什么有时候不触发？**
联动有节流：同一动作 0.8 秒内只触发一次、每秒最多 4 次、一次最多 2 只狗；
另外**缩边、睡觉、展开面板、拖动小狗时不联动**，这是为了避免打扰。

**Q：我用的是「小白和小鸡毛」同框形象，谁说话？**
主狗按当前台词角色说话，随从补另一个角色，不会两只狗说同一句
（同框时台词角色随机分配，可能这次小白先说、下次小鸡毛先说）。

## 8. 已知限制

- 只有 4 个桥段有台词触发点常用（摸头 / 喂食 / 开心 / Bongo）；久坐提醒需要连续
  40 分钟同一类活动、夜间告别只在 23:00–05:00 首次触发、回归提示需要离开电脑 10 分钟以上；
  久坐判断只看「前台程序有没有换 + 你还有没有在动」，**与「主动聊天」开不开无关**；
- 台词只有中英两套，跟随界面语言；
- 触摸屏/手写笔下滑动摸狗也支持，但极快的手势可能被系统识别成拖动；
- 「同框」形象下，主狗说哪一句是随机的，不保证每次都按你预期的那只开口。
