# Maltese v1.1.8

这一版修复鼠标悬浮气泡翻到小狗下方时，底部内容被窗口裁掉的问题。

## 修复

- **向下悬浮气泡显示完整**：气泡翻到小狗下方时，窗口高度现在会把小狗槽和间隙一起算进去，不再只按面板高度分配；悬浮面板底部按钮、快捷入口和“让小狗睡觉”不会再被窗口底边切掉。
- **小屏幕兜底**：如果显示器剩余高度确实不足，悬浮面板内容区可以在面板内部滚动，小狗和云朵尾巴的位置保持不动。

## 验证

- `cargo test`：68 passed / 0 failed / 9 ignored（新增浮层方向与窗口高度回归测试）。
- `tsc --noEmit` 通过。
- 前端生产构建通过。
- `verify-single-exe` 通过；发布包仍只有单个 `maltese-assistant.exe`，不依赖 `WebView2Loader.dll`。
