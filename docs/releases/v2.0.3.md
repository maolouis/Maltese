# Maltese v2.0.3

这一版把「小狗更像活的」和「以前会卡住、拖不动的地方」一起补齐：小狗有了自己的体力/情绪/亲密/专注，
双狗联动会说完整剧本，聊天能发表情包、排队和超时也不再误判；素材库、表情方格墙、视频插件、多显示器、
多实例启动、固定标签页也都在这一版里重做或修到位。**隐私上有一处行为变更，升级前请先看第 3 节。**

## 1. 新增

### 1.1 小狗的自我状态（体力 / 情绪 / 亲密 / 专注）

- 4 个隐藏数值会随互动变化、随时间自然回落（半衰期：体力 6 小时、情绪 2 小时、亲密 3 天、专注 45 分钟），
  **只影响待机时轮播哪张表情**：体力低更容易趴下睡，情绪高更容易开心/转圈，亲密高更黏人，专注高更像在陪你工作。
- 待机轮播的权重表覆盖**全部 25 个可轮播状态**（不再有状态落到兜底权重）：体力 <25 时 sleeping/relax 显著变多、
  happy/play/celebrate 变少；体力 >80 时 play/happy/chase 变多；情绪 >75 时 happy/celebrate/love/spin 变多；
  情绪 <35 时 pet/peek/relax 变多；亲密 >80 时 love/pet/peek 变多；专注 >60 时 working/attention/listening 变多。
- **不锁功能、不弹责备气泡**：数值再低也保留 idle/happy，永远不会自动播 angry；情绪极低时 cry 只是小概率（0.3），
  不做惩罚。动作、通知、音乐、Agent 状态的优先级完全不变。
- 有冷却（摸头 20s、喂食 30min…）、每日上限和重复动作递减，连点不会暴涨；体力 15 / 情绪 20 / 亲密 30 下限保护。
- 设置里（岛内「感知与陪伴」区、独立设置窗口「小狗的状态」卡）有 4 条进度条、一句话状态、「摸摸头」「喂零食」
  按钮和可折叠详情（上次结算时间 / 精确数值 / 隐私说明）；总开关默认**开**，关掉后待机轮播与以前完全一致。
- 聊天和主动消息会把这个状态作为 **system 消息**读进去（≤120 字 + 最近 3 条互动事实，如「3 分钟前被摸头」），
  不含任何聊天正文。
- 数据只在本机 `localStorage`（`maltese-pet-vitals` / `maltese-pet-vitals-log`）：不读聊天正文、不读剪贴板、
  不截图、不上传。

### 1.2 双狗联动补齐（剧本 / 预览 / 多狗不重句）

- 台词库扩到 **7 个场景 × 6 组**（中英各 42 组），并保证「最近 5 对不重复」在数学上成立（修复前 30 次抽取有 27 次复读）。
- 「试一下联动」改为**恒按有随从演示**：临时随从必说话，主狗说另一句；位移带缓动（小鸡毛 260ms / 小白 1200ms），
  不再瞬移；预览不改你的设置（只在本地记一条台词去重历史）。
- 3–5 只狗时两只随从**不会说同一句**；随从气泡补了 `aria-label`（「台词：…」），读屏与自动化可读。
- S5/S6/S7（久坐 / 夜间 / 回归）触发补全，久坐改用独立的活动计时，不再被主动聊天开关误触发。
- duo（小白和小鸡毛同框）台词的归属按「主狗形象 + 未被覆盖角色」决定，同框素材也不再混进单只狗的池子。

### 1.3 聊天表情包信使（不联网、不生图）

- 模型可以在回复末尾单独输出 `<sticker:happy>` 之类的标记（也容忍模型偷懒只写行尾裸 id，如「～ pet」「。eating」），
  前端从**现有 789 张本地 GIF 素材库**里挑同情绪的图，**作为一条独立表情消息**跟在文字回复后面显示。
- 表情尺寸 **144–160px**（最小 128、最大 180，源图小于 128 按自然尺寸不拉伸），圆角 12、与文字间距 ≥8px；
  点击放大到窗口 60%，点任意处或按 **Esc** 关闭。
- 开放 12 个表情 id（开心/庆祝/比心/摸摸/玩/困/吃/托腮/偷看/委屈/生气/放松）；标记非法或拼错**只删标记、不猜、不显示**；
  连续 3 条不重复（同族替换）。模型没输出标记且小狗体力偏低时，按状态权重兜底挑一个安静表情。
- 指令只注入主聊天，技能判断不带，避免拖慢动作决策。全程本地素材：**不上传、不调生图、不新增网络请求**。
- 旧版本已存的内联表情消息仍能正常显示；聊天字体补了 emoji / 符号回退链，修掉文字表情显示成方块的问题。

### 1.4 素材库与表情轮播

- 收录线条小狗官方微博表情包**第 1–33 弹与特辑**，整库并入轮播池，新增 6 个动作分类。
- 418 张白底 GIF 按连通边缘抠成透明（保留白色狗身，不误伤）；按 SHA-256 去掉 383 个完全重复的副本，
  素材从 **1172 张降到 789 张（-30.6MB）**，安装体积随之变小。
- 表情轮播改成**方格墙**：全部素材小图展示，未加入轮播的半透明可点选；拖拽排序、右键删除（删除前二次确认，
  支持撤销与「恢复最近删除」）。
- 设置里的「素材库总览」只留口径数字：**「共 789 张 · 说明见 docs/pet-characters.md」** + 五个分组计数 +
  「本表情可选 X 张 / 轮播随机抽 30 张」+ 同框短注（可见文案比上一版少一半）；完整解释（含轮播权重规则）
  迁到 `docs/pet-characters.md` 的「素材库说明」「轮播权重随状态变化」两节。

### 1.5 视频插件（小狗自己刷视频）

- 面板重做：首屏只留 6 个常驻控件，「开始看」在第一行不用滚动；参数 / 账号档案 / 自检都收进「高级设置」折叠，
  观后感草稿 / 投稿 / 直播整块删除；失败原因统一成可读的中文提示。
- 刷视频 P0 修复：残留专用的浏览器实例会被复用或先清理（不再 8s 超时）、登录窗会等真实可见窗口、
  失败写入诊断日志与会话记录（`stopReason` 区分 `userStop` / `browserUnavailable` / 端口占用）。
- 新增「打开视频内容」与「在视频下评论」，**评论受权限门禁控制**：没开评论权限就不会自动发评论；
  评论内容可以用本地聊天模型生成（也可以自己写死话术）。
- 账号与历史会话可以恢复 / 刷新。

### 1.6 其它新增

- **多显示器**：可指定小狗和 Bongo 落在哪块屏（下拉选屏、DPI 缩放、热插拔刷新、找不到屏时降级回主屏）。
- **六项技能**：待办计时、日记、播放音乐、打开应用、改设置、联网搜索；DSH 后端也能调用这些技能。
- **插件**：关系插件支持工作状态 / 心情同步；刷视频插件支持在视频下评论。

## 2. 修复

- **聊天排队/加载/输出三态，不再误判卡死**：Rust 新增 `local_model_status`（读模型 `status.value` 与 `/slots` 的
  `is_processing`），前端据此区分「排队中 / 已开始输出」——没有事件但后端忙 = 排队（提示「前面还有请求，排队中…」，
  上限 240s），**只有收到正文后才启用 45s 空窗超时**，总上限 300s；拿不到 `/slots` 时退化为「3s 无事件即显示排队」，
  同样不中止。连着发多条时新消息进本地队列，气泡显示「已排队 N 条…」，前一条结束后自动发下一条。
- **聊天状态栏稳定显示**：没有状态数据时用默认值 **70 / 70 / 50 / 0** 兜底并写回完整结构（新装、清缓存、从未互动的
  用户以前会整行不显示）；挂载即结算一次、2s 轮询兜底；只有总开关关闭才隐藏。
- **加载阶段「停止生成」真的停住**：新增 `local_model_load_cancel`，点停止后 Rust 侧轮询立即结束（不再后台跑到 240s）。
- **本地模型冷加载**：`ensure_local_model` 改为 `POST /load` + 每 2s 轮询到 loaded（最长 240s），
  加载期 UI 显示「正在加载本地模型…（已 Ns，首次约 1–4 分钟）」并可停止；打开聊天即后台预热。
- **流式失败兜底与取证**：流式失败自动退到非流式；错误对象落盘（`maltese-chat-last-error`）；
  三类失败共用同一句中文原因（模型没能加载 / 连接不到本地模型服务 / 已停止）。
- **固定标签页**：不再出现在任务栏、不再有灰框（设 `WS_EX_TOOLWINDOW` 并移出 `WS_EX_APPWINDOW`，同时移出 Alt+Tab）；
  跟随「小狗屏幕」设置（目标屏单独按 scale_factor 换算 420×560，150% 副屏不错位）；拔屏自动夹回主屏、插回再回副屏；
  用户拖动过的位置会被记住（程序位移过滤 + 换屏时夹进工作区）；连续切「小狗屏幕」下拉的偏好竞态改为
  generation + 串行队列，只认最后一次选择（以前会留在主屏）。
- **置顶 / 固定当前标签页**：新增 `PINNED_PAGE` + `get_pinned_page`，固定窗打开即落在你当时所在的页
  （以前会退回默认「聊天」）；顺序改为 `unminimize → show → always_on_top → focus`，最小化后再点 🔖 能恢复且仍在最上层。
- **表情轮播拖不动**：指针捕获改到网格容器级（节点被拖拽销毁也不断），松手时重新测量落点，
  写回后读回校验、不一致就报「顺序没能写进配置，请重试…」，不再静默失败；「全选现有表情」去重。
- **窗口几何**：最小化后位置漂移、面板闪烁、唤醒过渡帧被拖拽写成持久位置（8px 位移）、浮层开关挪动小狗、
  启动首帧显示不全、懒创建设置窗口打不开（B1）、浮层开关回归（B2）。
- **多实例启动**：显示与几何解耦（`show()` 必定执行 + 不可见时补显）、前端首帧握手、窗口懒加载、
  单实例锁、端口回退、剪贴板原子写。
- **主动消息**：情境一次性锁、依赖漏 `proactiveLevel`、未来时间戳 / 记账顺序导致的静默与重复。
- **素材**：删掉 383 个重复副本后仍能正确解析路径（兜底改走素材清单，不再引用已删除的根级 GIF）；
  小白 / 小鸡毛池剔除双狗同框图，同框只留给 duo；缩略图墙行高塌陷；表情数量标签与方格墙实际格子数一致。

## 3. 隐私行为变更（重要，升级必读）

- **微信提醒与 QQ 即时消息改为「只提醒、不显示文字」**：微信 OCR 链路已**整体删除**（`wechat_ocr.rs` 不再存在，
  读取消息内容的命令也已移除）。通知里的发送人 / 正文只在 Rust 内部用于判断新旧，**不序列化、不写日志、不进 localStorage**。
- 消息面板现在只有「微信有新消息 · 时间」「QQ 通知 · 时间」和通用的「只提醒有新通知，不显示发送人和内容」，
  **不会再出现任何发送人或正文**。云端气泡 / 收起态也只拼接「来源 + 有新消息」。
- 设置里旧的「读取消息内容」开关**不再生效**，并会在启动和打开设置时**自动清理**旧键
  （`focusd-island-wechat-read-content`）；新开关「显示消息预览」**默认关**，打开也只显示「来源 + 有新消息」。
- **范围边界**：QQ **邮件**预览行为不变，仍显示「发件人 + 主题」（邮件不是即时消息）；如果你要求「所有消息都不显示文字」，
  需要再开一轮改造。

## 4. 体验

- 设置页：小狗状态卡（4 条进度条 + 摸摸头 / 喂零食）、素材库总览（精简口径）、表情方格墙、
  所在屏幕（小狗 / Bongo）、实例联动的「试一下联动」。
- 聊天：顶部 4 指标状态条（缺数据也有默认值）、忙碌时「小狗在加载模型或思考… Ns」、
  排队时「前面还有请求，排队中…」+「已排队 N 条…」、「停止生成」、失败重试条、独立表情包消息（点击放大 / Esc 关闭）。
- 固定标签页：不再占任务栏、跟着小狗所在屏幕走，副屏 / 拔屏都不用重新固定。
- 插件：插件说明改为点击展开，浮层避开卡片操作区；视频面板首次使用只需「插件页签 → 开始看」两步。

## 5. 已知问题

1. **真实双狗联动的像素级/时序证据仍缺**：120ms 先后、位移缓动、联动期间 `rAF < 25ms` 只有代码 + 单测，
   未用录屏 / DevTools 逐帧实测（需要人工开 2 只狗摸头一次）。
2. **视频插件**：采集链路已验证，但「真实登录态下抓到具体视频条目（`/video/BV…`）」尚未实机验证
   （上一次唯一的「有内容」会话抓到的是 B 站首页标题）；「打开登录窗」在「有残留浏览器实例」状态下的真实可见窗口也未复测。
3. **聊天冷加载 UI**：「正在加载本地模型…（已 Ns）」按秒刷新、点停止后能再次发送，这两点待人工点一次确认
   （代码路径与单测已覆盖）。
4. **素材库数字**：总数 789 = 小白 394 + 小鸡毛 233 + 同框 152 + 微博表情包 9 + 旧兜底 1（脚本已核），
   设置页格子墙 / 分组计数的观感待人工看一眼。
5. **未做代码签名**：SmartScreen 会提示「未知发布者」；开启 Smart App Control 的机器上未签名安装包可能被拦
   （`os error 4551`）。签名方案见 `docs/distribution.md`。
6. **部分带安全软件的机器上 NSIS 安装包会报 `Error writing temporary file`**（安全软件拦自解压）：
   改用便携版 zip，或把安装包里的 `maltese-assistant.exe` 直接覆盖到安装目录。
7. **`STRATA_LAUNCHER` 仍写死本机路径**（`F:\Strata\bin\strata.cmd`）：别的机器点「启动 Strata」找不到启动器，
   聊天会提示「模型没能加载 / 连接不到本地模型服务」。
8. **小狗状态的手感**：轮播权重曲线与阈值来自模拟，还需要真人用几天调（见 `docs/research-pet-self-state.md`）。
9. 插件以当前用户权限启动本机程序，安装第三方插件前请先审查源码。

## 6. 安装与升级

| 方式 | 文件 |
| --- | --- |
| 安装包（推荐，支持应用内更新） | `Maltese-2.0.3-x64-setup.exe` |
| 便携版（解压即用） | `maltese-assistant-v2.0.3-win64.zip` |
| 插件（按需安装） | `billiards.zip` / `video-automation.zip` / `relationship.zip` / `hello-world.zip` |

- 安装包为 per-user 安装（写 `HKCU`，不需要管理员），`identifier` 仍是 `com.maolouis.maltese`，2.0.x 升级不换数据目录。
- 便携版含 exe 与 `resources\assets\pets`（桌宠素材，798 个文件），**不含任何插件**；解压运行 `Maltese-assistant.exe`，
  插件到插件中心粘贴 zip 路径安装。
- **升级提示**：如果你之前开过「读取消息内容」，升级后该设置会被自动清理，消息提醒只保留「有新消息」。

## 7. 校验

- `SHA256SUMS-v2.0.3.txt` 给出 exe / 便携 zip / 安装包 / 4 个插件 zip 的 SHA-256。
- 安装包带 Tauri updater 签名（`.sig`），`latest.json` 里的签名与安装包一致，应用内更新可直接使用。
- 交付前跑 `scripts/verify-release-artifacts.ps1`，Defender 扫描无威胁。
