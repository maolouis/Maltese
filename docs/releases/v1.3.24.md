# Maltese v1.3.24

## 聊天框：直接粘贴图片

- 输入框支持 `Ctrl+V` 直接粘贴截图 / 复制的图片，自动压到最长边 1280 px 后作为图片消息发出去；文件选择按钮仍然可用。
- 一次最多 4 张，超出会提示；每张图在待发送区显示缩略图，可单张移除。
- 消息气泡里会显示图片缩略图（存 360 px 缩略图，避免把原图塞进 `localStorage`）。
- 之前只有「流式」模式会带图，非流式会静默丢图；现在 `local_chat` 也接收 `images`，两种模式都能发图。
- DSH 后端不支持图片，选中它时仍会提示切换成本地模型。

## 聊天框：公式渲染

- 新增 `ChatText` 组件，用 KaTeX 渲染 `$...$` / `\(...\)` 行内公式和 `$$...$$` / `\[...\]` 块级公式。
- 同时把 ```代码块``` 和 `行内代码` 排成等宽样式，用户消息和助手消息都生效，流式回复也会实时渲染公式。
- 单个 `$` 只有在内容像公式（含 `\命令`、上下标等）时才当公式，避免「$5」「$HOME」这类文本被吃掉。
- KaTeX 关闭了 `trust`，不会执行 `\href` 等外部指令；渲染失败时原样显示公式源码。

## 刷视频插件：验证结果

把插件的纯逻辑抽到新模块 `src-tauri/src/video_rules.rs`（不依赖 Tauri / Win32），并让 `video_automation.rs` 全部改调用它，这样「被测的」就是「发版的」代码。

用 `rustc --test src/video_rules.rs` 单独编译运行（绕开本机测试二进制缺 WebView2 入口的问题），6 个用例全部通过：

- 标题匹配：`哔哩哔哩`、`bilibili`、`抖音`、`Douyin` 命中；`Bilibili` 不应命中抖音；`微信` 不命中。
- 进程识别：chrome / 360se / msedge 算浏览器，`douyin.exe` 只在抖音模式下算，`notepad.exe` 不算。
- 配置边界：间隔 15–600 秒、上限 1–240 分钟，越界报错。
- 平台校验：只接受 bilibili / douyin（大小写与空格容错）。
- 按键决策：**只在目标窗口位于前台时才发按键**；句柄失效时退化为「前台是浏览器且标题匹配」；其余情况只等待，不抢焦点、不乱按键。
- 翻页键：B 站 PageDown、抖音 ↓。

另外给 `video_automation.rs` 补了配置校验与「停止后状态清空」的用例（需要在能链接 Tauri 的机器上跑 `cargo test`）。

**注意**：这台机器上 `cargo test` 的测试二进制因缺少 WebView2 入口点（`0xc0000139`）无法启动，属于本机环境限制，不是代码问题；纯逻辑部分已用独立二进制验证。真实浏览器联调（`finds_live_bilibili_browser_window`，`#[ignore]`）需要一台能打开 B 站窗口的交互式桌面。
