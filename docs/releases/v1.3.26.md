# Maltese v1.3.26

## 评论：支持自动发送 + 投稿 / 开播引导

- 评论区新增「自动发送（先把光标点进评论框）」：勾选后每轮生成评论会依次执行 `Ctrl+V` + `Enter`，把评论直接发出去。光标不在评论框时按键不会命中，所以不会发到奇怪的地方。
- 新增「投稿 / 开播（半自动）」：
  - **准备投稿**：把当前视频标题 + 已生成的简介写进剪贴板，并打开 B 站 / 抖音的官方投稿页，粘贴即可。
  - **打开直播中心**：直接打开对应平台的直播后台。
- 上传视频与开播涉及实名认证、版权和平台风控，Maltese 只做准备和跳转，**不代替你点发布或推流**。想真正做到一键发布 / 自动开播，需要接平台开放平台 API（App ID/Secret + 授权），这属于另一个量级的接入。

## 聊天记录打开即停在最新一条

之前只在 `messages` 变化时滚一次，而聊天面板还在播展开动画，`scrollHeight` 还没长完，所以打开总是停在上方、要手动往下翻。现在：

- 挂载时用 `useLayoutEffect` 直接跳到底部（无动画）；
- 消息、忙碌状态、流式回复变化时平滑跟进；
- 用 `ResizeObserver` 监听列表尺寸变化（展开动画、聊天框高度设置），一有变化就贴底。

## 模型思考深度可调

聊天模型设置里的「思考」开关换成四档：**关 / 浅 / 标准 / 深**。

- 关：不发思考，`reasoning_effort=none`；
- 浅 / 标准 / 深：`reasoning_effort` 分别为 `low` / `medium` / `high`，思考预算 128 / 512 / 1536 tokens。
- 本机模型（OpenAI 兼容接口）走这套参数；旧配置里的 `enableThinking` 会自动迁移成「标准」或「关」。

## 主动聊天：找不到气泡的排查手段

- 设置里「让模型观察并主动找你聊天」下面多了「立即试一句」：点一下会先收起面板，然后立刻走一遍主动聊天流程，正常应弹出云朵气泡。
- 每次真正说话会记录时间戳到 `maltese-proactive-last`，方便确认是不是根本没到点（定时模式需要等满设定分钟数，跟随状态模式需要情境稳定 3 分钟且过冷却）。

如果点「立即试一句」也没气泡，说明问题在弹气泡这一段（窗口/浮层），不在计时；把当时的窗口状态告诉我即可继续定位。
