# Maltese v1.3.39

## 快捷方式路径填错时，说清楚错在哪

以前点「添加」只会弹一句「请填写程序或脚本路径」，路径写错也照样加进去，点了没反应。
现在新增 `src/shortcutPath.ts` 做格式校验，错误直接显示在输入框下面（红色小字 + 输入框描红），
并且改字时自动清掉。

### 会拦下来的情况

| 用户填的 | 提示 |
| --- | --- |
| 空 | 请填写程序或脚本路径，例如 `C:\Tools\tool.exe` |
| `"C:\Tools\tool.exe"` | 路径首尾不要加引号，直接写 `C:\Tools\tool.exe` 就好 |
| `file:///C:/Tools/tool.exe` | 这是 file:// 链接，请换成 Windows 路径 |
| `https://…` | 这里只能填本机的程序 / 脚本路径，不能填网址 |
| `tool.exe` | 需要用绝对路径（带盘符） |
| `C:Tools\tool.exe` | 盘符后面要跟反斜杠 |
| `C:\Tools\` | 这是文件夹，请填到具体的程序文件 |
| `C:\Windows\notepad.exe -foo` | 这里只填程序路径，不要再带参数 |
| 含 `\|` `<` `>` `?` `*` `&` `,` | 路径里不能有「x」这类字符 |
| `C:\Users\me\Desktop\notes` | 看起来不是完整文件名，请带上扩展名 |
| 带 `\\?\` 前缀 / 换行 / 超长 | 分别给出对应提示 |

`C:/Tools/tool.exe` 这种正斜杠会自动转成反斜杠并正常通过。

### 格式对了还要确认文件真的在

新增原生命令 `check_local_path`，返回「存在 / 是文件 / 是文件夹」：

- 不存在 → 「没找到这个文件：…，请确认路径拼写、盘符是否正确」；
- 是文件夹 → 「这是一个文件夹，请填到具体的程序文件」；
- 同一路径重复添加 → 「这个路径已经在快捷入口里了」。

输入框按回车也能直接提交，不用先点「添加」。
