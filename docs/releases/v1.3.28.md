# Maltese v1.3.28

## 先修根因：本机模型没在跑，主动聊天一路退化成模板

排查时发现 `127.0.0.1:8080`（F:\Strata 里的模型服务）当时根本没启动。模型调不通，主动聊天每次都走本地兜底台词，自然显得「重复又生硬」。

现在：

- 新增原生命令 `ensure_local_model(baseUrl)`：只对 `127.0.0.1/localhost:8080` 生效，先探 `/v1/models`，没起来就调用 `F:\Strata\bin\strata.cmd launch`（qwen36 / ud-q4_k_xl / 8192 上下文 / CPU 视觉 / 8080 端口），最多等 120 秒。
- 主动聊天开口前会先确认模型在跑（成功一次后缓存 10 分钟，不会反复探测）。
- 聊天发送遇到「连接不到」也会自动拉起 Strata 并重试一次，仍失败才报错。

## 主动关心：真的「看见」你在干什么

以前只说「前台程序 + 时间」，模型再自由发挥也容易写成「记得喝水」。现在收集：

- 前台程序类型（写代码 / 看视频 / 开会 / 聊天 / 打游戏 …）+ 清洗后的**具体窗口标题**（去掉 “- Google Chrome” 之类的尾巴）；
- 同一类活动**已经持续多少分钟**（忙碌感来源）；
- 正在播放的媒体标题；
- 键鼠闲置分钟数（人是不是走开了）；
- **最近的日记事件**（“开始了待办：…”“完成了待办：…”等，作为「刚才你…」的素材）。

提示词从「关心一句」改成明确要求：结合具体信息、12–30 字、口语化、不要客服腔 / 不要万能句、可以有情绪、不要连续发问。

## 反重复

- 最近说过的 12 句记在 `maltese-proactive-history`；生成后会做归一化比对（去掉标点后相同，或前 10 个字相同都算重复）。
- 撞车就让模型「换一个完全不同的说法和角度」重试一次；仍重复就用按情境挑选的兜底台词，并且**跳过最近说过的**。
- 兜底台词按场景重组：看视频（带视频名）、写代码（带时长）、开会、久坐聊天、人走开、打游戏、听歌、凌晨 / 深夜、刚才做过的事，最后才是通用闲聊句。
- 气泡标题也不再固定「小狗想你了」，按场景在 3 个里随机。
