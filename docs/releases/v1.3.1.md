# Maltese v1.3.1

## 快捷入口改版

- 快捷方式卡片移到面板最上方，打开快捷入口第一眼就是可点的按钮。
- 新增快捷方式、面板热键、自动识别 / 扫描目录、按名称搜索应用这些「添加与设置」项统一收进底部「添加与设置」区块，用一条分隔线和按钮区分开。
- 删除入口、恢复隐藏、清空这些管理操作仍留在快捷方式标题行，不跟着往下挪。

## 形象选择

- 岛内设置页的「桌宠形态」新增「小狗形象」三选一（小白 / 小鸡毛 / 小白和小鸡毛），和独立设置窗口里的选项同步，切换后主狗、陪玩狗、跟随狗一起换形象。

## 验证

- `tsc --noEmit` 与 `vite build` 通过。
