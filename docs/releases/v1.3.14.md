# Maltese v1.3.14

## 修复双击时小狗闪一下

- 双击打开互动气泡时，单击与双击会各触发一次点击：原来单击立刻切表情，双击的第一下已经换了一帧，看起来就是「闪一下」。现在单击延迟 240 ms 生效，双击会取消这次切换。
- 浮层展开时小狗按槽位尺寸钉在窗口角上再放大窗口，不再在「窗口变大、小狗还居中」的第一帧往左偏。

- `tsc --noEmit`、`vite build`、`cargo check` 通过。
