# Maltese v1.3.6

## 本次更新

- 修复 `.cmd` / `.bat` 等快捷入口使用扩展路径（`\\?\`）时无法由 `ShellExecuteW` 打开的问题；盘符路径和 UNC 路径都会在调用前恢复为资源管理器兼容的普通路径。
- 聊天跟随当前桌宠形象：小白使用安静温柔、细心、略胆小的设定，小鸡毛使用活泼、贪吃、爱撒娇的设定；选择「小白和小鸡毛」时，两只狗会分别以「小白：」和「小鸡毛：」回应。
- DSH 与本地模型两条聊天后端统一接收 `character` 参数，并补充未知形象的安全回退。

## 验证

- `tsc --noEmit`、Vite 构建和 `cargo check` 应在发布机完成。
- 生成安装包、便携 exe、zip、`.sig`、`latest.json` 和 SHA-256 清单后，必须运行 [交付前检查清单](../release-checklist.md) 中的 `verify-release-artifacts.ps1`。
