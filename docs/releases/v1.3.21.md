# Maltese v1.3.21

## 主动聊天支持两种模式

设置 →「感知与陪伴」（或独立设置窗口「陪伴与感知」）里，「主动聊天方式」可选：

- **定时**（默认）：每隔 5–240 分钟说一次，和之前一致。
- **跟随状态**：只有情境发生变化时才说。
  - 情境 = 前台程序类型 + 是否在播放媒体 + 是否离开电脑（闲置超过 10 分钟）。
  - 情境变化时只重新计时，不立刻开口；新情境稳定 **3 分钟**后才可能说，避免频繁切应用时不停打扰。
  - 同一个情境只说一次，两次之间至少有「最短间隔」的冷却。

两种模式都只在挂机（收起态）时说话，面板展开或正在聊天时自动跳过；模型不可用时仍用本地兜底台词，气泡照常弹出。原来那个滑杆在定时模式下叫「主动聊天间隔」，在跟随状态模式下叫「最短间隔」。

实现细节：情境判定用 `get_active_activity` + 媒体状态 + `get_system_idle_seconds` 组合出的字符串，`proactiveSituationRef` 记录当前情境、进入时间与已说过的情境；计时基准仍然只在首次进入时初始化，不受切歌、开关面板影响。
