# Maltese v1.3.35

## 1. 台球插件修好：三角摆球、六个球洞、你我一杆轮着打

上一版是把球摆在图标真实位置上，既没有球阵也没有洞，小狗也不会打。这一版按真实台球的规则重做：

- **三角摆球**：读到的桌面图标数决定球数（最多 45 颗），开局自动摆成三角形球阵（第 1 行 1 颗、第 2 行 2 颗……）。
- **六个球洞**：四角 + 两个中袋，画成深色圆洞；球心进洞即入袋，带淡出动画。
- **白球落袋**：回到开球点，本杆不计分（算犯规）。
- **轮流击球**：你打一杆 → 小狗打一杆，顶部条显示「你的回合 / 小狗的回合」。
- **小狗用模型算球**：轮到自己时，小狗会把白球位置、六个洞坐标、剩余球编号与坐标发给本机模型
  （本地 LLM 或 DSH），要求只回一行 `{"target": 编号, "power": 0.3~1}`；拿到后本地计算「幽灵球」瞄准点再出杆。
  模型不可用时退回几何最优解（离洞最近 + 白球可达）。
- 球与球之间也做了碰撞（等质量弹性近似），不再是"只撞白球"。

## 2. 台球界面精简

上一版把用时/进球/剩余/进度/杆数/重开/退出全铺在一条上，还压了一行说明和一行署名。现在：

- 顶部只有一条胶囊：**回合徽章 · 比分（你 X : Y 小狗）· 剩余 · 用时 · 重开 · 退出**；
- 条下面一行 11px 提示（"按住左键往后拉"、小狗思考状态、清台结果）；
- 桌面图标数、署名收到最不打扰的位置（提示行末尾 / 右下角淡字）；
- 台面画成淡绿毛毡 + 青色边线，球是白底蓝环，白球纯白，瞄线黄色虚线 + 力度条（偏红表示力大）；
- 只在你自己的回合才显示十字准星光标。

## 3. 模型开思考时不再"看起来没反应"

之前开启思考后，首字要等很久，界面上只有一个转圈，用户不知道是卡住还是模型真的在思考。

现在：

- 等待气泡文案变成「小狗正在思考…（12s）」，每秒刷新已等待秒数；
- 超过 3 秒且还没输出时，显示一行提示：「思考深度：标准，模型在推理；深度越大首字越慢，可在设置里调到「关」或「浅」加快回复。」；
- 流式思考内容默认**展开**，能直接看到模型在吐字；正文照旧随后出现；
- 思考深度为「关」时不显示这些提示，只保留普通"小狗正在想…"。
