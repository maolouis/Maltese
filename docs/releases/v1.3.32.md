# Maltese v1.3.32

## 让主动关心不再重复

之前只做了「文本完全相同 / 前 10 字相同」这种字面判重，模型换个说法照样绕过去；而且历史只存 12 条、模板池也偏小，用两天就开始「你又在写代码…」循环。

这一版从四个层面压重复：

### 1. 相似度判重（不只是字面相同）

改成中文二元字组 Jaccard 相似度：

- 完全相同 → 重复；
- 开头 6 个字相同 → 重复（换个后半句也算）；
- 相似度 ≥ 0.45（最近 10 句）/ ≥ 0.6（更早）→ 重复。

实测阈值效果：

| 两句 | 相似度 | 判定 |
| --- | --- | --- |
| 「都十点多了还在改 App.tsx，这聊天面板重构得让人头秃吧」vs「…真让人头秃」 | 0.82 | 重复 ✅ |
| 「代码写到第 95 分钟了，我只在旁边趴着不吭声」vs「…我趴在旁边没吭声」 | 0.565 | 重复 ✅ |
| 「看你又在写代码，我陪你一会儿」vs「看你又在写代码呢，陪你待一会儿」 | 0.563 | 重复 ✅ |
| 「都十点多了还在改 App.tsx…」vs「都十点多了，眼睛酸不酸？」 | 0.119 | 放行 ✅ |
| 「代码写到第 95 分钟…」vs「夜深了，说话声音我都放轻了」 | 0.000 | 放行 ✅ |

### 2. 按「角度」轮换

新增 8 个说话角度：心疼身体 / 好奇内容 / 撒娇黏人 / 调侃打趣 / 共情 / 抓具体细节 / 回忆刚做过的事 / 说小狗自己。

- 每次挑**最近最少用过**的角度（从没用过的优先），并在提示词里明确「这次只从这个角度说」；
- 角度随记录一起存进历史，避免连续两轮同一个调子。

实测同一情境连跑 6 个角度，模型产出 6 句明显不同的话，两两最高相似度只有 **0.08**：

```
[care]    都十点多了，眼睛酸不酸？重构累的话摸摸我充充电吧。
[curious] 重构聊天面板好复杂呀，里面藏了什么神奇的代码秘密吗？
[clingy]  都码了快一个半小时啦，那个重构任务能不能先放一放，摸摸我嘛。
[tease]   都深夜十点半啦，你的重构代码还在跑，本线条小狗都要困成一条线了。
[empathy] 深夜改代码辛苦啦，我乖乖趴在旁边陪你把这段重构搞定。
[detail]  盯着你屏幕上的 App.tsx 看了快一小时，重构的代码跑通了吗？
```

### 3. 重试更硬 + 记忆更长

- 撞车后连续重试**两次**：第一次要求换角度和开头，第二次直接列出「不要用这些开头：…」，并把温度拉到 1.0（重试期间不刷新气泡，避免闪烁）；
- 历史从 12 条扩到 **48 条**、保留 7 天，并自动清理过期记录（兼容旧版纯字符串格式）。

### 4. 模板池按角度扩充 + 最久未用优先

- 每个角度都有专属备用句，情境专属句照旧保留；
- 兜底时不再纯随机：先过滤掉「重复」的，再在**用过次数最少**的句子里挑；
- 气泡标题也做去重，不会连续两次都是「小狗想你了」。
