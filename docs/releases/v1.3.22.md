# Maltese v1.3.22

## 修复：收起 / 隐藏快捷键失效

现象：更新或重启后，`Ctrl+Alt+Shift+C`（收起面板）和 `Ctrl+Alt+Shift+M`（显示 / 隐藏桌宠）都不响应，手动退出重开又好了。

原因：这两个全局快捷键在启动时各注册一次，注册失败就静默放弃。自动更新、`install-latest.ps1` 都是「杀旧进程 → 立刻起新进程」，旧实例还没把 `RegisterHotKey` 释放掉，新实例注册失败，于是一整场会话快捷键都是哑的。用 PowerShell 复现确认：重启后立刻检查时两个组合键仍被占用但注册失败；隔几秒重启后两者都注册成功。

修复：

- 两个快捷键模块都记录「目标组合键」`DESIRED_BINDING`，注册失败时后台每 2 秒通过 `PostMessage` 让热键窗口重试，最多 30 次（约 1 分钟），抢回来就恢复，不用再手动重启。
- 主窗口启动时就把保存的「显示 / 隐藏」组合键注册上（以前要等快捷面板挂载才注册，用户改过键的话得先打开面板）。
- 设置窗口录制快捷键时，如果和另一个 Maltese 快捷键重复，直接提示换一个，避免一个把另一个顶掉。
