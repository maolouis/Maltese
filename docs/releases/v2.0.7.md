# Maltese v2.0.7

这一版是 **2.0.6 之后的两组修复**（2.0.6 → 2.0.7），主线有两件事：把云朵气泡搬进独立的透明 `bubble` 窗口，
从架构上消掉「双击小狗时左上角重影闪动」；以及把本地模型聊天在本机代理、中文输入法和长思考链下的几处硬伤补齐。
另外顺手调顺了待机轮播频率、体力曲线和「让小狗睡觉」的手感。

## 1. 修复（重点）

### 1.1 云朵气泡迁到独立 `bubble` 窗口（左上角重影闪动根治）

2.0.6 已经让主窗口不再为了弹气泡而改矩形，但气泡仍渲染在主窗口里：一旦主窗口需要扩宽去容纳气泡，
DirectComposition 的 SwapChain 重绘有 1–3 帧延迟，双击瞬间就能看到小狗「闪一下再对齐」。

**现在**：悬停面板 / 云朵气泡 / 菜单全部由 `show_pet_bubble` 渲染在独立的透明置顶窗口 `"bubble"`（`src/PetBubble.tsx`），
主窗口自身**零扩窗、零 `SetWindowPos`**；`frontend_ready` 之后延迟 1 秒在后台预热，第一次弹气泡不用等建窗。

- `place_bubble_near_main` 优先停在小狗右侧；右侧越界时自动翻到左侧，并返回 `side = "left"` 让云朵小尾巴翻转指向小狗；
- 落位在 `show()` 之前用 `set_window_rect_atomic` 一次性完成，不会出现「先出现在旧位置再跳」；
- 非 Tauri 环境保留原来的单窗方案作为回退，几何不变量写在 [pet-overlay-geometry.md](../pet-overlay-geometry.md)。

### 1.2 本地模型聊天：代理、输入法、长思考

- **环回/内网直连**：开着系统代理（如 Clash `127.0.0.1:7897`）时，WinInet 的 `127.*` 例外不被 `reqwest` 继承，
  `http://127.0.0.1:8080/v1/*` 被代理转发后返回 `502 Bad Gateway`。`src-tauri/src/local_chat.rs` 统一走
  `build_http_client()`，对 `localhost` / `127.*` / `::1` / 私有网段自动 `.no_proxy()`；`src-tauri/src/video/cdp.rs`
  的本机 CDP 客户端同样默认直连。
- **输入框聚焦与中文 IME**：从气泡或右键进入聊天页时解除浮层拦截、主动 `setFocus()` 并聚焦 `textarea`；
  `onKeyDown` 跳过 `isComposing || keyCode === 229`，中文输入法回车上屏不再误发送或读到空串；
  `send()` 读 `draft || textareaRef.current?.value`，并兼容「只发图片」。
- **system 上下文与思考流保活**：`build_messages` 把前端传入的 `"system"` 条目并入根 `system` prompt，不再丢弃；
  `stream_once` 收到 `reasoning` 增量时同样刷新 `first_token_at`，思考超过 12 秒也不会被首字超时误杀。

## 2. 新增与改进

- **动画切换频率接入待机轮播**：设置里的高频 5 秒 / 中频 10 秒 / 低频 20 秒现在真的作用在待机轮播上；
  单击手动切一张表情后不再把自动切换锁死。
- **体力曲线放宽**：初始 85、下限 30、半衰期 18 小时；陪玩改成温和回体力，在线睡觉按睡眠速率持续回血，
  **≥65 就显示「很有精神」**；当日体力增益上限放到 100，日常轻度互动即可维持高体力。
- **让小狗睡觉更干脆**：悬停面板底部或互动列表点「睡觉」后**直接无延迟缩边**并保持趴睡，
  普通气泡不再把它叫醒，只有鼠标靠近或点击小狗才唤醒。
- **聊天面板统一展开高度**：右键小狗直接打开聊天并自动聚焦输入框，高度不再随历史条数跳动。

## 3. 已知问题

1. **小红书评论**仍差真实账号安静窗口的一次真发复验（Mock DOM 4 个场景已过）。
2. **B 站自动评论受账号限制**：未转正账号站点返回 `-107`，面板给原因，不绕过风控。
3. **混合 DPI 未实测**：跨缩放换算已补齐，仍缺 100% + 150% 物理双屏实测。
4. **几何单一真值仍在收敛**：`DogSlot` 状态机终态未完成，极端边缘场景仍有理论残差（当前实测 0）。
5. **实例联动仍下线**：`PET_LINK_ENABLED=false`，设置页隐藏入口。
6. **未做代码签名**：SmartScreen 会提示「未知发布者」；部分带安全软件的机器 NSIS 自解压可能报
   `Error writing temporary file`，可改用便携版 zip。
7. **每日图文总结视频**未实现（预研完成，见 [research-daily-summary-video.md](../research-daily-summary-video.md)）。
8. **强杀后冷启动可能卡住**：被强杀时残留的 `msedgewebview2.exe` 子进程仍占着 `EBWebView` 配置目录，
   新实例会等锁等到不响应；结束 `CommandLine` 含 `com.maolouis.maltese` 的 WebView2 子进程后可正常启动（下一版修）。

## 4. 安装与升级

| 方式 | 文件 |
| --- | --- |
| 安装包（推荐，支持应用内更新） | `Maltese-2.0.7-x64-setup.exe` |
| 便携版（解压即用） | `maltese-assistant-v2.0.7-win64.zip` |
| 插件（按需安装） | `billiards.zip` / `video-automation.zip` / `relationship.zip` / `hello-world.zip` |

- 安装包为 per-user 安装（写 `HKCU`），`identifier` 仍是 `com.maolouis.maltese`，**2.0.6 → 2.0.7 不换数据目录**。
- 便携版含 exe 与 `resources\assets\pets`，**不含插件**；插件到插件中心粘贴 zip 路径安装。

## 5. 校验

- `SHA256SUMS-v2.0.7.txt` 给出安装包 / 便携 zip 的 SHA-256。
- 安装包带 Tauri updater 签名（`.sig`），`latest.json` 内签名与安装包一致。
- 交付前跑 `scripts/verify-release-artifacts.ps1`，Defender 扫描无威胁。

- 本地 `release\` 只维护最新版本产物，留档以 GitHub Release 为准。
