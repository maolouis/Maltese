# Maltese v1.3.9

## 修复向下展开比向上展开矮

- 现象：聊天面板翻到小狗下方时，可见高度比在上方时少了「小狗槽 + 间隙」那一截。
- 根因：窗口高度只按面板高度算（`max(狗槽, 面板)`），但面板在下方的布局是「狗槽 + 8px + 面板」，多出来的狗槽部分把面板挤出了窗口底边，看起来就被裁短了。
- 修复：原生层记住面板方向（`PANEL_BELOW`），面板在下方时窗口高度 = 狗槽 + 间隙 + 面板高度；CSS 里把面板高度固定为 `--expanded-island-height`，并用 `max-height` 兜住空间不足的情况。上下两种方向的可见面板高度现在一致。
- 单测 `expanded_stage_uses_the_requested_panel_height` 覆盖了两种方向：上方 800px → 窗口 800px；下方 800px → 狗槽 + 8 + 800。

## 验证

- `cargo test --lib expanded_stage` 通过；`tsc --noEmit`、`vite build`、`cargo check` 通过。
- 实机：面板在上方和下方各展开一次，量窗口高度与面板可见高度，两者面板高度一致。
