# Maltese v0.2.4（数据备份 + identifier 迁移）

本地更新（按要求**未推送远端、未发布 Release**）。

## 1. 数据备份

改 identifier 会换掉 WebView2 的数据目录，等于"换了个应用"——先备份再迁移。

**备份位置**：`E:\Maltese-backup\20261113-1615\`（2.2 MB / 31 个文件，含 `MANIFEST.txt`）

备份内容（原 `%LOCALAPPDATA%\com.maltese.desktop-assistant`）：

| 项 | 内容 |
| --- | --- |
| `Local Storage\leveldb` | 全部 localStorage：设置、待办、聊天记录、剪贴板、形象/GIF 配置、主动聊天历史等 |
| `IndexedDB` | 前端 IndexedDB 数据 |
| `Network` | WebView2 网络相关状态（Cookie/缓存索引） |
| `Preferences` | WebView2 偏好 |
| `MANIFEST.txt` | 时间、来源目录、版本、文件清单 |

> 旧目录 `%LOCALAPPDATA%\com.maltese.desktop-assistant`（176 MB）**原样保留**，作为第二份备份，
> 确认新版本一切正常后可以再删。

## 2. identifier 更改

| 项目 | 之前 | 现在 |
| --- | --- | --- |
| `identifier` | `com.maltese.desktop-assistant` | **`com.maolouis.maltese`** |
| 数据目录 | `%LOCALAPPDATA%\com.maltese.desktop-assistant` | `%LOCALAPPDATA%\com.maolouis.maltese` |

迁移步骤（本机已执行）：

1. 停进程 → 备份（上表）；
2. 启动 0.2.4，让新 identifier 建出自己的数据目录；
3. 停进程 → 把备份里的 `Local Storage` / `IndexedDB` / `Network` / `Preferences` 覆盖进新目录；
4. 再启动验证。

**迁移校验**：新旧 `Local Storage\leveldb` 的 4 个 `.ldb` 段文件 SHA-256 前缀逐一比对**完全一致**
（`000005` / `000402` / `000404` / `000407`），说明数据文件是原封不动搬过去的；
应用启动后正常写入新目录（`.log` 有更新），桌宠正常渲染。

⚠️ 唯一没有跟着改的是翻译密钥的 Windows 凭据条目名
（`translation.rs` 里 `com.maltese.desktop-assistant.translation`）——
故意保留，这样已保存的有道密钥不用重新填。要改名得连凭据一起迁移，属于另一件事。
