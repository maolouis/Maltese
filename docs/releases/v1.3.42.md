# Maltese v1.3.42

## 固定到桌面：支持聊天 / 待办 / 音乐 / 快捷，按钮挪进顶部按钮组

### 按钮位置

按你的要求，入口放在小狗面板右上角那组按钮里（消息 / 归位 / 最小化 那一排），
新增一个 **📌 固定按钮**，排在消息按钮左边：

- 悬停时变色高亮，提示文字会写明要固定哪个标签（"把「音乐」固定到桌面"）；
- 点一下就把**当前标签**固定到桌面，先收起面板也能用；
- 原来加在聊天页头部和悬停气泡里的入口保留，但现在都只是快捷方式。

### 固定窗口本身也升级了

固定窗口顶部新增标签栏：**聊天 / 待办 / 音乐 / 快捷**，可以随时切换，切换状态会记住。

| 标签 | 能力 |
| --- | --- |
| 聊天 | 完整聊天（模型、思考面板、图片、复制都在），和主面板共用一份记录 |
| 待办 | 可以直接加待办、打勾完成、设为「进行中」；和主面板共用同一份数据 |
| 音乐 | 显示曲目 / 歌手 / 进度，支持上一首、播放暂停、下一首（直接读系统媒体会话） |
| 快捷 | 完整的快捷入口面板（应用搜索、快捷方式管理都在） |

### 待办的数据一致性

固定在桌面的待办窗口和主窗口读写的是同一份 `focusd-island-todos`，两边通过 `storage`
事件互相同步：在固定窗口里打勾，主面板立刻跟着变；主面板新增，固定窗口也会刷新。
（另有 3 秒兜底轮询，避免事件丢失。）
