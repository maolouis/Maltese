# Maltese v1.3.10

## 快捷入口：搜索应用置顶、键盘直达

- 「搜索应用」输入框从底部挪到快捷入口最上方，打开面板第一眼就能输入。
- 用面板热键打开快捷入口后输入框自动获得焦点，可以直接打字；**↑ / ↓** 在搜索结果里切换，**Enter** 直接打开选中的软件，**Esc** 清空输入。鼠标悬停也会同步高亮当前项。
- 「＋ 新增快捷方式」（手动填路径）仍留在底部「添加与设置」里，位置和用法不变；点搜索结果依然是「加入快捷入口」，不会误触打开。

## 验证

- `tsc --noEmit`、`vite build`、`cargo check` 通过。
- 实机：热键打开面板 → 输入「微信」→ ↓ 选择 → Enter 能打开对应程序；点结果仍能添加快捷方式。
- 交付前按 [release-checklist](../release-checklist.md) 跑 `verify-release-artifacts.ps1`。
