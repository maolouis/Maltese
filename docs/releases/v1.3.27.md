# Maltese v1.3.27

## 思考过程默认折叠、可展开

- 本机模型流式回复时，Rust 现在把 `reasoning_content` / `reasoning` / `thinking` 字段单独作为
  `reasoning` 事件发出来，不再混进正文。
- 聊天里每轮回复上方出现「思考过程」折叠条：默认收起，点一下展开；流式过程中显示「正在思考…」，
  收起时只占一行，不会刷屏。
- 思考内容随消息一起存进聊天记录（单条上限 4000 字），历史消息也能展开回看。
- 折叠条右侧会显示大致字数 / 行数，方便判断要不要点开。

## 可以关掉思考过程展示

模型设置里新增「展示思考过程（默认折叠，可点开）」：

- 勾上（默认）：显示折叠条，需要时点开；
- 取消：完全不渲染思考内容，界面回到只有正文。

注意它只控制「显示」，不控制「要不要思考」——思考本身由上一版的「思考深度」（关 / 浅 / 标准 / 深）决定。

## 聊天界面参考 DeepSeek Harness 的几处

- 每条消息底部改为「时间 + 复制」一行，鼠标悬停在气泡上才显示复制按钮，点一下复制整条内容
  （走 `navigator.clipboard`，失败回退到原生剪贴板命令）。
- 思考过程用「折叠条 + 正文」两个层次，和 DSH 的 reasoning 展示一致：先看结论，需要再展开推理。
- 保持 KaTeX 公式、图片缩略图、动手模式执行提示在同一个气泡里共存，层级依次是
  思考 → 图片 → 正文 → 执行结果 → 时间/复制。
