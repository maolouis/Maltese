# Maltese v1.3.20

## 音乐卡：播放视频时不再当成音乐

浏览器播 B 站 / YouTube 时，系统媒体会话会像音乐播放器一样上报「正在播放 + 时长」，之前就被当成音乐处理，于是出现了给视频配歌词这种错乱。

现在用系统给的权威字段区分：读取 Windows 媒体会话的 `PlaybackType`（`Music` / `Video` / `Image`），作为 `mediaKind` 传给前端，不再靠标题去猜。

- **歌词**：`video` / `image` 时完全不请求歌词，歌词面板不出现。
- **听歌表情**：视频播放期间不切到 `listening` 状态，不会用音乐状态的 GIF 轮播。
- **听歌互动**：切到视频时不再说「你也喜欢听《…》」，避免把视频标题当歌名。
- `mediaKind` 纳入媒体状态比对，播放类型变化立刻反映到界面。
- 系统拿不到 `PlaybackType` 时退回 `unknown`，行为与以前一致。

## 隐藏桌宠时 Bongo 一起隐藏

用显示 / 隐藏快捷键、托盘隐藏或面板收起按钮隐藏主桌宠时，Bongo、陪伴狗、跟随鼠标的小狗会一起消失，不再留下 Bongo 孤零零趴在桌上。重新显示时按最近一次同步的配置（Bongo 尺寸、位置、透明度、陪伴数量和鼠标跟随）原样放回来。

实现上用 `hide_island` / `show_island` 统一挂接，`desktop_extras` 里用 `PETS_HIDDEN` 标记让鼠标跟随循环在这期间不要偷偷把小狗显示回来。

## 全屏时连 Bongo 一起隐藏（新设置）

- 岛内设置「外观 / 全屏避让」和独立设置窗口「互动」里新增开关「全屏时连 Bongo 一起隐藏」，默认开启。
- 开启时进入全屏会把 Bongo、陪伴狗、跟随小狗一并收起来，退出全屏自动恢复。
- 只在「全屏时」不是「不处理」时显示这个开关。
