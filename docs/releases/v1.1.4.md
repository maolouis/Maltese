# Maltese 线条小狗桌面助手 v1.1.4

## 修复

- **修复「复位到右下/右上」却回到屏幕中央**：设置里选择右下/右上角后，小狗没有落在角落，而是回到屏幕水平居中。
  原因：显示器归属判定仍用旧整窗宽度（640px）计算小狗中心，而实际落位按收起态小狗槽（约 151–168px）计算。
  右下/右上角的槽位中心被误判到屏幕右缘之外，系统丢弃角落坐标、回退到默认居中位置。
  现已改为按小狗槽实际尺寸计算中心点，四角复位在任何缩放比例下都落在正确的角落；拖拽到屏幕边缘也不会再被“弹”回中央。
- 四角复位按小狗槽位定位：面板展开时点「复位」，小狗也落在正确的角落，不再受展开面板尺寸影响。

## 新增

- **看视频独立页面**：B 站 / 抖音自动翻页从快捷面板移出，入口在悬停气泡和顶部导航「聊天」旁边，独立页面展示。
- **复位位置可调**：设置里可选底部居中 / 左上 / 右上 / 左下 / 右下，选择后立即落位，「复位」按钮也回到该位置。

## 其他改进

- 待办添加表单只在「今天」页显示，并新增明确的「添加」按钮，不再依赖回车或不可点击的图标。

## 运行方式

1. 解压发布包，确保 `maltese-assistant.exe` 和 `WebView2Loader.dll` 在同一目录。
2. 双击 `maltese-assistant.exe`，小狗出现在桌面。
3. 鼠标悬停打开互动面板；右键任务栏托盘图标可配置、隐藏或退出。
