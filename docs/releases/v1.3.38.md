# Maltese v1.3.38

## GIF 设置栏可以收起来了

「表情轮播」那一栏以前一展开就是几十张缩略图，设置窗口被撑得很长。现在：

- 标题右侧多了一个「展开（N 张）/ 收起」按钮，点一下整块淡出收起，只留标题和当前形象；
- **默认收起**，想看再展开；
- 展开状态会记住（`maltese-gif-settings-expanded`），下次打开设置保持你上次的选择；
- 按钮悬停会变色 + 上浮，箭头 180° 旋转，收放方向一眼看得出来；
- 收起时也会显示张数，不用展开就知道当前形象配了多少张。

表情选择下拉框挪到了标题同一行，收起状态下依然可以直接换表情。
