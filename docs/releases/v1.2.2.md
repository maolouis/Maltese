# Maltese v1.2.2

## 桌面体验

- 去掉云朵气泡下方的黑色投影；展开的快捷面板也只保留一圈很淡的内描边，不再有一大块黑色阴影。
- 修复顶部「待办 / 音乐 / 剪贴板 / 快捷入口 / 聊天 / 插件 / 设置」页签显示不全：
  - 页签改成独占一行、按可用宽度自动换行，不再被挤在 100px 宽的网格列里；
  - 当前页签不再继承圆点按钮的 1.18 倍缩放，左边缘不会被面板裁掉。

## 表情轮播

- 设置页新增「全选现有表情」：一键把当前表情的全部内置 GIF 补回轮播列表。
- 每张 GIF 下方显示实际路径（内置素材为 `/assets/pets/...`，自定义素材为应用数据目录里的绝对路径），方便核对和排查。
- 仍支持逐张上移 / 下移、删除、恢复默认顺序和添加自定义 GIF。

## OTA 自动更新

- 主窗口启动约 6 秒后自动检查一次新版本，之后每 4 小时检查一次；检查失败静默重试，不打扰使用。
- 发现新版本时：
  - 收起状态弹出云朵气泡提醒；
  - 展开面板顶部显示更新条，可直接点「立即更新」下载并安装，安装完成后应用重新启动；
  - 设置页仍保留手动检查入口和详细错误信息。
- 更新使用 Tauri updater + minisign 签名校验，下载地址改为 `maolouis/Maltese` 的 Release，并保留 GitHub 直连和两个镜像端点。
- 更新安装包为签名的 Windows NSIS 安装包，版本清单 `latest.json` 随 Release 发布。

> **首次升级说明**：v1.2.1 及更早的构建没有内置更新公钥，无法自动发现 v1.2.2；需要手动下载安装一次 v1.2.2。之后发布的新版本即可自动提醒并更新。

## 验证

- `tsc --noEmit` 通过。
- `node --test tests/*.test.mjs` 通过。
- `cargo test` 通过（71 passed / 9 ignored）。
- 更新包使用发布私钥签名，`latest.json` 指向本次 Release 的 NSIS 安装包与 `.sig`。
