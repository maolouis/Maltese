# Maltese v2.0.1

2.0.1 修复台球随启动自动开局的问题，插件改为独立 zip 分发，并调整聊天默认后端与本地模型默认值。

## 1. 修复：台球不再随启动自动开局（issue #1）

- 之前隐藏的台球窗口随应用启动就挂载，挂载即开局，物理循环反复搬动真实桌面图标（约每 1.4 秒一次重排）。
- 现在挂载不再开局：只有从插件/卡片里点「打开台球」或「开始这一局」才会动图标；未开局时物理循环空转返回。
- 应用退出时若台球窗口还开着，会恢复被移动过的桌面图标。

## 2. 插件改为独立 zip 分发

- **安装包和便携包不再预置任何插件**，插件中心初始为空；需要哪个插件自己装。
- 三个示例/宿主渲染插件各自打成独立 zip，随本 Release 一起提供：
  - `video-automation.zip`（自动刷视频，`video-automation`，宿主渲染）
  - `relationship.zip`（关系，`relationship`，宿主渲染）
  - `hello-world.zip`（Hello World 示例，自带页面）
- 插件中心支持直接粘贴 **zip 路径**安装：宿主解压，只取含 `plugin.json` 的那一层目录；也可以粘贴文件夹路径。
- 插件 id 统一为 `video-automation` / `relationship`，与宿主渲染分支一致；用户目录里同 id 的插件会覆盖预置目录副本。

## 3. 聊天默认后端与本地模型默认值

- 默认对话后端改为 **DSH**（已登录的 DeepSeek Harness，云端模型，记住会话）。
- 切到「本地模型」时，**接口地址和模型名称默认都是空的**：本地服务是每台机器自己装的，程序不再预填某台电脑的 Strata 地址（`127.0.0.1:8080`）和模型名；在设置里点 Ollama / LM Studio / Strata 预设或手动填写即可。
- 清空接口地址后保存就是空，不会再被强行补回默认地址；没填地址就发消息会提示先去设置。

## 4. 安装与升级

| 方式 | 文件 |
| --- | --- |
| 安装包（推荐，支持应用内更新） | `Maltese-2.0.1-x64-setup.exe` |
| 便携版（解压即用） | `maltese-assistant-v2.0.1-win64.zip` |
| 插件（按需安装） | `video-automation.zip` / `relationship.zip` / `hello-world.zip` |

- 安装包仍是 per-user 安装（写 `HKCU`，不需要管理员）。
- 便携版包含 exe 与 `resources\assets\pets`（桌宠素材），**不含插件**；解压后运行 `Maltese-assistant.exe`，需要插件再到插件中心装对应 zip。
- `identifier` 仍是 `com.maolouis.maltese`，从 2.0.0 升级不换数据目录，属于平滑升级。

## 5. 校验

- `SHA256SUMS-v2.0.1.txt` 给出 exe / 便携包 / 安装包 / 插件 zip 的 SHA-256；
- 安装包带 Tauri updater 签名（`.sig`），`latest.json` 里的签名与之一致，应用内更新可直接用；
- 交付前检查：`scripts/verify-release-artifacts.ps1`，Defender 扫描无威胁。

## 6. 已知问题

1. **未做代码签名**：SmartScreen 会提示「未知发布者」；带 Smart App Control 的机器上，
   未签名安装器可能被应用程序控制策略拦截（`os error 4551`）。签名方案见 `docs/distribution.md`。
2. **部分带安全代理的机器上安装包会报 `Error writing temporary file`**，
   属于安全软件拦截 NSIS 自解压；替代方案是用便携版 zip，或把安装包里的
   `maltese-assistant.exe` 直接覆盖到安装目录。
3. 插件动作以当前用户权限启动本机程序，安装第三方插件前请先审查其源码。

## 7. 版本策略

- GitHub 上的 Release 每个版本都保留，不删除、不改写；
- 本地 `release\` 只维护最新版本产物，旧版本不再备份，留档以 GitHub Release 为准。
