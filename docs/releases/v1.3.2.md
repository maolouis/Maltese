# Maltese v1.3.2

## 快捷入口启动更快

- 快捷方式不再经过 `cmd.exe /C start` 转一手，改为直接调用 ShellExecute（和资源管理器双击同一条路径），少一次控制台进程启动，也不再闪黑框；`.ps1` / `.py` 仍走各自的解释器。
- 点击后卡片立刻转圈并显示「正在启动…」，成功后提示里带上从点击到系统接受启动的耗时（毫秒），至少能看出有没有点进去。

## 缩边 / 睡觉动画

- 修复小白睡着或缩边时变成小鸡毛的问题：之前固定播 `rest.gif`（画的是金黄色小鸡毛），现在默认跟随当前形象自己的睡觉动画。
- 新增「缩边 / 睡觉动画」设置项：可以选一张自己的 GIF（最大 8 MB），也可以「恢复默认」回到跟随形象。设置页和岛内设置的「桌宠形态」里都能改。

## 验证

- `tsc --noEmit`、`vite build`、`cargo check` 通过。
