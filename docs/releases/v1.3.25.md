# Maltese v1.3.25

## 小狗能干活了（动手模式）

聊天框右上角新增手掌按钮，「动手模式」默认开启。开启后小狗会先判断要不要在本机动手，需要时调用内置技能，执行完再用一句人话回复你，气泡下面会显示一条绿色的「执行结果」。

内置技能（可在「技能」面板里逐项关掉）：

| 技能 | 说明 | 例子 |
| --- | --- | --- |
| 记待办 | 真的往待办列表里加一条 | 「帮我记个待办：下午三点开会」 |
| 看今天待办 | 列出未完成项 | 「我还有什么事没做」 |
| 完成待办 | 按关键词标记完成 | 「开会那条做完了」 |
| 打开网址 | 默认浏览器打开链接 | 「帮我开 B 站」 |
| 打开应用 | 按名称启动本机应用 | 「打开微信」 |
| 控制音乐 | 播放 / 暂停 / 上一首 / 下一首 | 「下一首」 |
| 读剪贴板 | 读出当前剪贴板文字 | 「我剪贴板里是什么」 |
| 写剪贴板 | 把文字放进剪贴板 | 「把这句话复制下来：明天九点」 |
| 看时间 | 当前日期时间 | 「现在几点」 |

实现方式：不依赖模型的 function calling（本地小模型大多不支持），而是让模型只输出一行
`{"tool":"todo_add","args":{"text":"..."}}`，前端解析后执行，再把结果喂回模型生成自然回复。所以任何能输出 JSON 的模型都可以用。

## 技能与 MCP 登记

聊天头部新增扳手按钮，打开「技能」面板：

- **内置技能开关**：关掉后对应动作不会提供给模型。
- **自定义技能**：填名称 + 说明，会作为额外技能注入提示词（相当于安装一个轻量 skill）。
- **MCP 服务器**：登记名称 / 命令 / 参数，支持启停和删除，并可「复制 MCP 配置」得到标准
  `{"mcpServers": {...}}` JSON，粘到 DSH 或兼容客户端的配置里。
  说明：MCP 的工具由宿主（DSH 等）执行，Maltese 只做登记与配置导出，不会自己连第三方服务器。

## 视频助理：刷视频 + 评论

「刷视频」面板新增评论区：

- **生成评论**：读取当前前台视频标题，让本机模型（或 DSH）写一句 ≤20 字的中文评论；模型不可用时用内置模板兜底。
- **复制**：把评论放进剪贴板，点开网页评论框 `Ctrl+V` 即可。
- **输入到评论框**：用 Unicode 键盘事件把评论直接敲进已聚焦的输入框（中文不依赖输入法）。
- **自动准备评论**：勾选后每次翻页都会自动生成一条并复制到剪贴板，方便随手粘贴。

自动模式只准备和复制，**不会替你发送**，避免在错误的地方乱发内容。翻页本身仍然是原来那套：只有目标视频页在前台才发 PageDown，切走就等待。

## 新增原生能力

`src-tauri/src/actions.rs`：

- `read_clipboard_text` / `set_clipboard_text`：Win32 剪贴板读写（带占用重试）。
- `type_text`：用 `SendInput` + `KEYEVENTF_UNICODE` 把文字打进当前焦点窗口。

## 验证

- `tsc --noEmit`、`vite build`、`cargo check` 通过。
- 手动可验证：聊天里说「帮我记个待办：测试一下」→ 待办页出现该条 + 气泡下有绿色执行提示。
- 刷视频页：点「生成评论」应出现一句评论；点「复制」后可在别处粘贴。
