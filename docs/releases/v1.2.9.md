# Maltese v1.2.9

## 快捷方式

- **自动识别改为参考系统应用**：默认读取桌面和 Windows 开始菜单（当前用户 + 公共），不再扫描 Program Files 或整块磁盘。
- **搜索应用名称添加**：快捷面板新增应用搜索框，输入应用名即可从系统开始菜单/桌面结果中直接添加。
- **手动路径添加保留**：仍可在「＋ 新增快捷方式」里填写程序或脚本的绝对路径。
- 开始菜单里的「卸载 / Uninstall」入口会自动过滤，不会被当成应用。
- 搜索结果和自动发现项都可单独移除；自动识别开关、扫描目录设置继续保留。

## 修复

- 保留 v1.2.8 的右键首帧遮罩，避免窗口放大时左上角小狗重影。
- 固定快捷入口、自动发现入口都可以删除；自动发现列表不再被 100 条上限重新填满。
- 自动识别可以关闭，关闭后只保留自定义快捷方式。

## 验证

- `pnpm build`（含 `tsc --noEmit`）通过。
- `node scripts/verify-build.mjs`：全部检查通过。
- `node --test tests/*.test.mjs`：34 项全部通过。
- `cargo test`：74 项通过，9 项忽略。
- 实机验证：搜索“微信”能从开始菜单找到并添加；卸载入口被过滤；手动路径添加和自动识别开关正常。
