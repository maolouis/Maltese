# Maltese v1.3.11

## 修复气泡被截断

- 云朵气泡正文不再限制 4 行（`-webkit-line-clamp` 已移除）。
- 气泡窗口改成按内容高度自适应：渲染后量一次实际高度，调用新的 `resize_pet_bubble` 让窗口长高并重新贴到小狗侧边，最高 560 px。开始待办、长标题、多行提示都能完整显示。

## 修复小狗拖不出屏幕上边

- 之前把小狗往屏幕上方拖时，槽中心一离开显示器范围，位置查找就失败，代码会把坐标夹回工作区，看起来“上面拖不出去，下面却可以”。
- 现在位置查找失败时退回当前/主显示器继续跟随，保留自定义坐标，上下两个方向都能把小狗拖到边缘外；想找回来用面板里的「复位位置」。

## 热键打开快捷入口自动聚焦搜索框

- 热键打开面板后直接可以打字，不需要再点一下。除了挂载时聚焦，还加了 60 / 180 / 400 ms 重试、窗口重新获得焦点时补聚焦，以及热键重复按下时的重新聚焦。
