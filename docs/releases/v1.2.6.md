# Maltese v1.2.6

## 聊天接入本地模型

- 聊天页右上角新增「聊天模型」设置，可在 DSH 和本地模型之间切换。
- 兼容 Ollama、LM Studio、llama.cpp 等提供 OpenAI Chat Completions 接口的服务：
  - 支持填写服务地址、模型名称和可选 API Key；
  - 「测试连接」会读取 `/v1/models`，显示发现的模型并提供输入建议；
  - 接口地址可填服务根地址，程序会自动补齐 `/v1`。
- 本地模型对话携带最近 16 条聊天记录，内容只在本机与所填服务之间流转。
- 聊天记录和本地模型配置都只保存在本机；DSH 原有行为保持不变。

## 修复

- 修复系统闲置后打开面板/聊天会被睡眠逻辑立刻重新缩回的问题。睡眠现在只在收起态生效，展开聊天或面板时不会被打断。
- 聊天页保留 v1.2.5 的气泡与睡觉缩边修复。

## 验证

- `pnpm build`（含 `tsc --noEmit`）通过。
- `node --test tests/*.test.mjs`：34 项全部通过。
- `cargo test`：74 项通过，9 项忽略。
- 用本地 OpenAI 兼容 mock 服务实测：测试连接返回模型列表；聊天消息成功返回本地模型回复。
