# Maltese v0.1.0（发布形式重构线）

从这一版开始，版本号归零重排，仓库走新的本地分支 **`refactor/external-resources`**。
本次不做功能变更，只重构「怎么打包、怎么分发」。

## 1. 分支与版本

- 分支：`refactor/external-resources`（**仅本地，未推送远端**）；
- 版本：`1.3.42` → **`0.1.0`**，`package.json` / `src-tauri/tauri.conf.json` /
  `src-tauri/Cargo.toml` / README 徽章四处同步。

## 2. 打包卫生（对照你给的约束逐条落实）

| 要求 | 现状 |
| --- | --- |
| 不用 UPX / 加壳 / 混淆 | ✅ 三处配置均无相关项，`verify-packaging.mjs` 会拦截 |
| 标准 NSIS 安装器 | ✅ `--bundles nsis`，`installMode=currentUser`，不做自定义安装器 |
| 从干净源码构建 | ✅ `pnpm tauri build` 直接产出，无额外桩程序 |
| 依赖常见可识别 | ✅ 新增依赖为 0，只用了已有的 `tauri` / `windows` / `serde` |
| 不往 Temp 丢 exe 再拉起 | ✅ 源码扫描无此路径（临时文件只用于原子写入自定义音效） |
| 不做动态代码注入 | ✅ 无 `WriteProcessMemory` / `CreateRemoteThread` / `CREATE_SUSPENDED` / 用户路径 `LoadLibrary` |
| 自启动最小化可说明 | ✅ 只写 `HKCU\...\CurrentVersion\Run`，且仅当用户开启；启动时只修正「已登记路径是否指向当前 exe」 |
| 资源外置 | ✅ 43.1 MB 桌宠素材已移出 PE，改为随 `resources/` 安装 |
| 发布地址/发布者/版本稳定 | 说明见 `docs/distribution.md` §4、§5 |

## 3. 资源外置（本次的主要改动）

- `public/assets/pets`（43.1 MB / 593 个 GIF）→ 仓库根 `assets/pets`，不再进入 `dist`；
- `tauri.conf.json` 增加 `bundle.resources: { "../assets/pets": "assets/pets" }`，
  安装后在 `<安装目录>\resources\assets\pets`；
- 新增原生命令 `get_pet_asset_base`：返回上面的目录（开发态返回空串）；
- 新增 `src/petAssetBase.ts`：启动前 `await initPetAssetBase()`，`petAssetUrl()` 把
  `/assets/pets/...` 换成 `convertFileSrc` 的真实文件 URL；
- 解析点收敛在 `petCharacters.ts`、`petAssets.ts` 和 3 处 `rest.gif`；
- `vite.config.ts` 增加只读中间件，`pnpm dev` 依旧能从 `/assets/pets/*` 加载（带目录穿越校验）。

体积：

| 产物 | 之前 | 现在 |
| --- | --- | --- |
| `dist` | 49.5 MB | **6.4 MB** |
| exe | 31.0 MB | **24.8 MB** |
| 安装包 | 29.6 MB | 29.1 MB（素材改走 `resources/`） |

## 4. 新增工具与文档

- `scripts/verify-packaging.mjs`：版本一致性、无加壳/混淆、NSIS、无注入、自启动范围、资源体积报告；
  不通过退出码 1，建议接进发布流水线（排在 `verify-release-artifacts.ps1` 之前）。
- `docs/distribution.md`：分发约束、资源外置三步方案（第 1 步已完成）、启发式风险清单、误报申诉流程。

## 5. 验证与未验证

已验证：`tsc --noEmit`、`vite build`、`cargo check`、`pnpm tauri build --bundles nsis` 均通过；
`verify-build.mjs`、`verify-packaging.mjs` 通过；安装包与 exe 已生成。

**未验证**：本会话环境里「静默安装 + 启动 GUI」会挂起，所以「安装后 GIF 是否从
`resources/assets/pets` 正常加载」没有实机确认。请在实机上跑一次安装，确认：

1. `<安装目录>\resources\assets\pets` 存在且含 593 个文件；
2. 启动后小狗 GIF 正常显示（不是空白/破图）；
3. 换一张 GIF 到该目录后重启，画面跟着变（说明资源可独立更新）。

## 6. 下一步（第 2 步：JS/CSS/字体外置）

需要注册自定义协议从 `<resourceDir>/web/` 提供前端产物，并把窗口 URL 改成

风险高于第 1 步（做错会白屏），方案与验证清单见 `docs/distribution.md` §3 第 2 步。
