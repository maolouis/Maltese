# Maltese v1.3.0

## 桌宠形象

- 还原 LineDogPet 的两套形象：小白、小鸡毛，外加「两只同框」共享素材，共 495 张 GIF。
- 设置页「桌宠形态」可选择 **小白 / 小鸡毛 / 小白和小鸡毛**：前两者播自己的素材，并按每 3 张插 1 张的比例混播双狗同框图；选「小白和小鸡毛」时只播同框素材。
- 抱起、转圈、追逐固定用共享池里的招牌图，和 LineDogPet 手感一致；动作缺素材时按回退链找近似动作，最后兜底小白待机。
- 表情轮播按形象分开保存，旧的按状态配置会自动迁移到小白。
- 每个状态最多轮播 30 张，避免一次预加载上百张 GIF 吃内存；设置页「全选」仍可取到完整素材池。

## 快捷入口

- 支持 Microsoft Store / MSIX 应用：新增 `Get-StartApps` 读取与 `shell:AppsFolder` 启动，ChatGPT 这类没有 `.lnk` 的应用现在能搜到、添加并打开。
- 移除「常用脚本」和「显示 / 隐藏桌宠」两块，面板只保留快捷方式；快捷键仍在设置页「互动」里配置。
- 商店应用暂不显示图标，其余快捷方式图标逻辑不变。

## 设置与交互

- 新增「显示桌面图标」一键开关，读取当前状态后可直接隐藏 / 恢复。
- 收起与展开的缩放范围从 0.75–1.4 放宽到 **0.5–1.8**，原生窗口尺寸同步调整。
- 面板展开后可用 ↑ ↓ ← → 在 待办 / 音乐 / 剪贴板 / 快捷入口 / 聊天 / 插件 之间切换，焦点在输入框时不拦截。
- 修复「关于与更新」在浅色设置窗口里白字白底看不清的问题，配色按设置窗口覆盖并放大字号。

## 桌宠聊天

- 修复 DSH 聊天报 `MISSING_CREDENTIAL` 的问题：headless 默认路由 `deepseek-official` 需要 `DEEPSEEK_API_KEY`，现在 patch 会把默认模型指到桌面端登录的账号路由（`deepseek-account` + `deepseek-flash`），无需额外配置密钥。

## 验证

- `tsc --noEmit` 与 `vite build` 通过。
- `cargo check` 通过（仅有既有告警）。
- DSH headless 实测返回 `OK`，会话 id 正常返回。
- ChatGPT 在 Windows 应用清单中确认为 `OpenAI.Codex_2p2nqsd0c76g0!App`，可通过新命令启动。
