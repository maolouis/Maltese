# Maltese v1.3.19

## 主动聊天要弹气泡

需求：小狗主动找人聊天时要有聊天气泡。检查后发现问题不在「弹不弹」，而是**几乎到不了点**：

- 主动聊天的 effect 依赖了 `mediaState.title/artist` 和 `mode`。切歌、开关面板都会让 effect 重跑，而每次重跑都会把计时基准重置成「现在」，间隔 30 分钟以内根本走不到，所以看不到任何气泡。
- 计时基准改成只在第一次进入时记录，依赖收缩到「开关 / 间隔 / 形象 / 弹气泡函数」，状态变化不再重置计时。
- 轮询从 60 秒改成 30 秒，到点判定更准。

同时保证「一定看得见」：

- 模型调用失败、未配置或返回空内容时，用按时间段准备的本地兜底台词（早上 / 中午 / 下午 / 晚上 / 深夜），气泡照常弹出。
- 生成完毕后会再确认一次仍在挂机（模型可能要几秒），避免面板打开后气泡突然盖上来。
- 弹气泡 + 写入聊天记录 `focusd-island-pet-chat-messages`，下次打开聊天能看到这句。
