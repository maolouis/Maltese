# Maltese v1.1.6

这一版把桌宠从“一只狗 + 一个气泡”扩展成可以同时陪着你的桌宠组合，并补齐了几个交互细节。

## 新增

- **多宠物**：设置里可把小狗数量调到 1–5 只（含主狗），陪玩狗会以独立透明窗口出现在桌面底部，可以摸头、拖动换位置。
- **Bongo 模式**：在设置里开启后，键盘上会多一只趴着的小狗；按下的键会切换成对应的爪子帧，空格和方向键也有反馈。大小、不透明度、镜像和鼠标穿透都可调。
- **跟随鼠标**：开启后会在光标旁显示一只小尺寸小狗，窗口保持鼠标穿透，不会挡住点击；靠近屏幕边缘时会自动翻到光标另一侧。
- **悬停气泡显示当前待办**：鼠标浮在小狗上时，互动气泡会显示“正在做”的待办标题；在气泡打开期间切换开始项也会同步更新。
- **快捷方式可删除**：快捷方式卡片右上角新增移除按钮。自动发现的桌面/开始菜单快捷方式只会从列表里隐藏，不会删除原文件；被隐藏的条目可以通过“恢复隐藏”找回。自定义快捷方式仍直接从列表删除。
- **Ctrl + 左键拖动小狗**：普通左键仍是摸头，按住 Ctrl 再拖动才会移动小狗，避免想摸头时误拖。

## 修复

- **气泡上下自适应**：悬停气泡、展开面板和独立气泡窗口现在不只会在左右翻边，空间不足时也会自动翻到小狗下方；小狗在屏幕上的位置保持不动。
- 气泡垂直方向改用工作区（排除任务栏）计算，避免翻到任务栏后面；气泡开合时按小狗槽的原始锚点还原，反复开关也不会把小狗越挤越偏。
- 气泡文字颜色现在会作用到“正在做”的待办行，不再被固定颜色覆盖。
- 快捷方式自动发现卡片复用自定义卡片的删除按钮样式，在展开白色面板里也清晰可见。
