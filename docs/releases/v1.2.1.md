# Maltese v1.2.1

本次修正快捷方式热键的作用范围：热键属于「快捷方式面板」这个整体，而不是某个具体应用。

## 修正

- **一个面板热键**：快捷入口页新增「快捷面板热键」，整个快捷方式面板只用一个系统级热键。按一次会显示桌宠、展开面板并切换到「快捷入口」，不会去启动某个应用。
- **不再逐项绑定**：移除了每张快捷方式卡片上的 ⌨ 热键按钮；旧版按路径保存的逐项热键不再注册，升级后会自动清理旧配置，避免按快捷键误启动应用。
- **设置方式**：点击热键按钮后直接按组合键录制，`Esc` 取消，右键清除；重启应用后自动恢复。
- **冲突提示**：组合键被占用或无效时在热键行显示原因，不会静默失败。

## 验证

- `tsc --noEmit` 通过。
- 前端生产构建通过。
- `cargo check --target x86_64-pc-windows-msvc` 通过。
- 真实 Tauri 窗口实测：面板内录制/清除热键、保存到 localStorage、重启后注册；向热键窗口发送 `WM_HOTKEY` 后窗口从收起状态展开并切换到「快捷入口」页。
- 检查快捷方式卡片不再出现逐项热键按钮。
