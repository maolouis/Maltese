# Maltese v2.0.2

2.0.2 从根上堵住「桌面图标被自动重排」（issue #1），把台球拆成独立插件，并修掉快捷入口搜索/打开的卡顿。

## 1. 修复：桌面图标不会再自己动（issue #1 根治）

- `desktop_icons.rs` 新增全局闸门 `GAME_ACTIVE`：只有用户真的开了台球这一局（`desktop_icons_begin_game` 成功）才置位。
- `desktop_icons_move` 未开局直接返回成功、不搬任何图标；`desktop_icons_restore` 未开局也不再去读上次留下的备份文件。
- 因此窗口挂载/卸载、应用启动/退出、热更新界面都不再触发图标搬动；只有点「开始这一局」才动图标，`Esc`/退出立即还原。
- 崩溃兜底仍保留：`restore_desktop_on_startup()` 在启动时发现残留备份会先把图标摆回去、再删备份，且只执行一次。

## 2. 台球改为独立插件

- 台球不再内置在插件中心，改为 `examples/plugins/billiards/plugin.json`（`ui: "host"`），随本 Release 提供 `billiards.zip`。
- 装上后插件页出现「桌面图标台球」，点「打开」走覆盖桌面的独立窗口（`open_billiards_window`）；其余插件仍走插件窗口。
- 配套：插件中心不再渲染内置台球卡片，`PluginsPanel.tsx` 相应瘦身。

## 3. 快捷入口搜索/打开不再卡顿

- `discover_installed_apps` 的完整清单缓存 10 分钟，搜索只在内存里过滤；`discover_start_apps` 同样缓存，不再每敲一个字就起一个 PowerShell 跑 `Get-StartApps`。
- `discover_*` / `get_shortcut_icon` / `launch_*` 全部改为 `async` 命令，不再阻塞 Tauri 主线程；打开应用、取图标不再让界面顿一下。

## 4. 安装与升级

| 方式 | 文件 |
| --- | --- |
| 安装包（推荐，支持应用内更新） | `Maltese-2.0.2-x64-setup.exe` |
| 便携版（解压即用） | `maltese-assistant-v2.0.2-win64.zip` |
| 插件（按需安装） | `billiards.zip` / `video-automation.zip` / `relationship.zip` / `hello-world.zip` |

- 安装包为 per-user 安装（写 `HKCU`，不需要管理员），`identifier` 仍是 `com.maolouis.maltese`，从 2.0.x 升级不换数据目录。
- 便携版含 exe 与 `resources\assets\pets`（桌宠素材），**不含任何插件**；解压运行 `Maltese-assistant.exe`，插件到插件中心粘贴 zip 路径安装。

## 5. 校验

- `SHA256SUMS-v2.0.2.txt` 给出 exe / 便携包 / 安装包 / 4 个插件 zip 的 SHA-256；
- 安装包带 Tauri updater 签名（`.sig`），`latest.json` 内的签名与安装包一致，应用内更新可直接使用；
- 交付前跑 `scripts/verify-release-artifacts.ps1`，Defender 扫描无威胁。

## 6. 已知问题

1. **未做代码签名**：SmartScreen 会提示「未知发布者」；启用了 Smart App Control 的机器上，未签名安装器可能被应用程序控制策略拦截（`os error 4551`）。签名方案见 `docs/distribution.md`。
2. **部分带安全代理的机器上安装包会报 `Error writing temporary file`**：属于安全软件拦截 NSIS 自解压；可改用便携版 zip，或把安装包里的 `maltese-assistant.exe` 直接覆盖到安装目录。
3. 台球依赖向 explorer 桌面窗口发跨进程消息，部分系统策略会拦截（返回 `ERROR_ACCESS_DENIED`）；被拦时不动任何图标、直接报错。
4. 插件动作以当前用户权限启动本机程序，安装第三方插件前请先审查源码。

## 7. 版本策略

- GitHub 上的 Release 每个版本都保留，不删除、不改写；
- 本地 `release\` 只维护最新版本产物，旧版本不再备份，留档以 GitHub Release 为准。
