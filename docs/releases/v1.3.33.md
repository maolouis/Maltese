# Maltese v1.3.33

## 修：小狗本体小、抠位大，点到空白就误触

### 原因（有数据）

收起态窗口的抠位是 **148×128**，但小狗图片只有 **112×112**，而 GIF 素材里还有一圈透明留白。实测 39 张素材：

| 素材 | 可见范围 |
| --- | --- |
| idle.gif | 64% × 69% |
| attention.gif | 81% × 37% |
| pet.gif | 44% × 58% |
| celebrate.gif | 60% × 45% |
| pickup.gif | 97% × 96% |
| **中位数** | **66% × 54%** |

也就是说，真正「看得见的狗」大约只有 74×60 px，而可点击区域是整个 18944 px² 的抠位——**约 80% 的点击范围是空气**。点到狗旁边就会切表情 / 双击开面板 / 开始拖动，这就是误触。

### 改法

新增 `src/petHitBox.ts`：把当前 GIF 的第一帧画到 96px 的 canvas 上，扫描 alpha > 24 的像素得到可见包围盒（相对整图的比例，外扩 2% 余量），按 `src` 缓存、换表情才重算。

DOM 改成三层：

```
.maltese-pet        → pointer-events: none（不再吃事件）
  .maltese-pet__stage → 尺寸 = 112px × scale，位置/位移都交给它
    img               → 100% 铺满，视觉完全不变
    .maltese-pet__hit → 绝对定位，按 alpha 包围盒百分比摆放，pointer-events: auto
```

所有交互（单击切表情、双击开面板、右键聊天、拖动、唤醒）都搬到命中层上，所以**只有真正画了狗的像素矩形会响应**。悬停放大、Q 弹、翻转、睡觉姿势等视觉效果不变（父级 `:hover` 依然生效）。

兜底：canvas 读不到像素（例如被跨域污染）时退回「整张图片」范围，仍比整块抠位小；测量失败的图不会出现点不中的情况。

### 效果

以 `idle.gif` 为例：

| 项目 | 数值 |
| --- | --- |
| 原可点区域（整块抠位） | 148 × 128 = 18944 px² |
| 现可点区域（狗的实际范围 + 2% 余量） | ≈ 76 × 82 = 6232 px² |
| 缩小 | **约 67%** |

`pet.gif`（44%×58%）这类素材缩小更多，`pickup.gif`（97%×96%）几乎不变——都只会「正好盖住狗」，多出来的空白不再响应。
