# Maltese v1.3.8

## 修复聊天框高度设置不生效

- 1.3.7 里「聊天框高度」只是写进了设置，但原生窗口尺寸仍然写死 520 px，所以拖了没反应。
- 根因：`stage_dimensions()` 的展开态分支用的是常量 `EXPANDED_PANEL_HEIGHT`，没有读前端传进来的 `expandedHeight`。现在改为 `slot_h.max(state.expanded_height)`，各页面自己算的高度（聊天框设置、待办行数、音乐面板等）都会真正作用到窗口上。
- 补了单测 `expanded_stage_uses_the_requested_panel_height`：请求 800 px 时窗口高度就是 800，请求 220 px 时不会小于小狗槽高度。

## 验证

- `cargo test --lib expanded_stage_uses_the_requested_panel_height` 通过。
- `tsc --noEmit`、`vite build`、`cargo check` 通过。
