# Maltese v1.3.16

## 双击闪一下：这次改的是窗口几何和方向预测

前面只处理了“单击/双击各切一帧”，但闪烁依旧，说明真正的问题是原生窗口的几何在过渡中出现了错位帧：

- **分两次改窗口几何**：`set_size` + `set_position` 是两次独立调用，中间那一帧「窗口已经变大、位置还没挪」或反过来，小狗按窗口内布局重排，看起来就是往某一侧闪一下。
  现在改成一次 `SetWindowPos`（新增 `set_window_rect_atomic`），浮层展开和收起都只应用一次几何。
- **方向回传晚一帧**：面板朝左还是朝右由原生计算后通过事件回传，前端第一次渲染用的还是上一轮的方向；窗口已经变宽、小狗却按旧方向摆，于是偏到左侧。
  现在浮层打开的那一帧先按小狗当前位置和屏幕剩余空间本地预判方向（`overlayPlacementRef`），只算一次，之后仍以原生回传为准。
