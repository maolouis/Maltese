# Maltese v1.2.8

## 修复

- **右键小狗不再出现左上角重影**
  - 右键打开聊天时，窗口从收起尺寸放大，旧画面会短暂保留成一层小狗重影。
  - 现在放大首帧先隐藏收起态小狗，等展开面板完成首帧后再恢复显示；同时保留 v1.2.7 的“不再先缩回再展开”修复。
- **快捷入口可以真正删除**
  - 固定快捷入口（网易云、豆包、计算器、常用脚本等）也增加 × 移除按钮，不再只能删自动发现项。
  - 自动发现项按规范化路径保存隐藏状态，避免 `\\?\` 前缀、大小写或斜杠差异导致删除后重新出现。
  - 自动发现列表上限从 24 提高到 100，删除后不会立刻被后来条目填满。
- **自动识别可以选择开或不开**
  - 快捷面板和设置窗口都增加「自动识别快捷方式」开关。
  - 关闭后不再扫描桌面/指定目录，只保留自定义快捷方式。
  - 扫描目录、自动识别开关都纳入构建前检查项。

## GIF / 插件（保留 v1.2.7）

- 表情轮播支持多选状态和全选所有状态，待机时合并轮播。
- 快捷方式只扫描桌面或用户指定目录，不再遍历开始菜单 / Program Files。
- 插件卡片精简，完整使用说明改为独立的 hover 浮窗。

- `pnpm build`（含 `tsc --noEmit`）通过。

- `node --test tests/*.test.mjs`：34 项全部通过。
- `cargo test`：74 项通过，9 项忽略。
- 实机验证：右键时页面遮罩生效；固定/自动快捷入口均可移除；关闭自动识别后只保留自定义入口。
