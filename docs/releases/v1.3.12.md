# Maltese v1.3.12

## 收起快捷键

- 新增「收起面板」全局快捷键，默认 `Ctrl+Alt+Shift+C`，在设置窗口「互动」里点击输入框即可录制新组合键。
- 展开面板时按一下直接收回成小狗；窗口隐藏时按它不做事。组合键注册失败（被其它软件占用）会回滚并显示错误。

## 小狗可以拖出屏幕上边

- 之前用的是系统标题栏拖拽（`start_dragging`），Windows 会把窗口上边缘卡在屏幕顶部，所以「往下能拖出去、往上不行」。
- 改成自己按光标位移移动窗口（每 8ms 跟一次），不再受系统拖拽约束，上下左右都能把小狗拖到屏幕边缘外；松开后位置照常保存。

## 设置窗口支持切换语言

- 独立设置窗口新增「语言」卡片，可选简体中文 / English，写入和主窗口共用的 locale 存储，主窗口立即切换。

## 待办气泡截断再修

- 之前一次 `requestAnimationFrame` 测量会撞上弹出动画的 `transform: scale` 和字体/换行未稳定，量出来的高度偏小（所以“有概率”截断）。
- 改用 `ResizeObserver` + `scrollHeight` 持续测量（不受 transform 影响），高度变化才重新调整窗口；窗口上限从 560 提到 640，超长正文内部滚动。
