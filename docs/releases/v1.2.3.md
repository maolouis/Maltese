# Maltese v1.2.3

## 应用图标

- 换成新的线条小狗图标：两只小狗并肩趴着（白色小狗 + 奶油色小狗），替换原先的单只小狗图标。
- 同一张源图（1024×1024）重新生成整套图标：`icon.ico`、`icon.icns`、`32x32` / `128x128` / `128x128@2x`、Windows 磁贴各尺寸与 `StoreLogo`。
- 生效范围：任务栏图标、托盘右键菜单、窗口图标、开始菜单与桌面快捷方式、NSIS 安装包与卸载程序图标，都由这一套图标驱动。

## 其他

- 除图标与版本号外，功能与 v1.2.2 完全一致；已安装 v1.2.2 的用户会通过 OTA 收到本次更新。
- 版本号同步为 1.2.3（`package.json` / `tauri.conf.json` / `Cargo.toml` 三处一致）。

## 验证

- `pnpm tauri icon` 从 1024×1024 源图生成全套图标，无报错。
- `tsc --noEmit` 与前端构建通过。
- `cargo test` 通过（71 passed / 0 failed / 9 ignored）。
- NSIS 安装包使用发布私钥签名，`latest.json` 指向本次 Release 的安装包与 `.sig`。
