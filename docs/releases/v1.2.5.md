# Maltese v1.2.5

## 修复

- **收起或右键后不再残留半截气泡**
  - 浮层的打开/关闭请求现在带递增 generation 并按顺序执行；快速收起、重新弹出时，迟到的旧请求不会再把新气泡的窗口缩回去。
  - 修复气泡已经渲染、主窗口却仍停在收起尺寸，导致只看到一条白色边或半个气泡的问题。
- **待办提醒不再重复弹气泡**
  - 修正「开始计时」提示的清理逻辑：收起、缩边、睡觉不再让同一个待办反复弹提示。
  - 这也避免了睡觉时反复出现气泡、遮住趴睡状态。
- **睡觉功能恢复**
  - 悬停面板里的「让小狗睡觉」现在会真正缩到最近的屏幕边缘并保持趴睡，鼠标靠近才醒。
  - 手动放在屏幕上方的桌宠睡觉时不再突然跳到屏幕底部缩边，而是从上方缩边并翻转露头。
  - 缩边方向按小狗实际位置选择最近的边缘。

## 验证

- `pnpm build`（含 `tsc --noEmit`）通过。
- `node --test tests/*.test.mjs`：34 项全部通过。
- `cargo test`：71 项通过，9 项忽略。
- 实机验证：屏幕上方的桌宠睡觉后从上方缩边；悬停面板睡觉按钮保持趴睡；收起后无残留气泡。
