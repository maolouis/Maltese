## 关于被识别成病毒

发布用的 exe 和安装包目前没有代码签名。未签名 + 每次构建都是新哈希 + 自带更新器，很容易被 Defender、SmartScreen 或第三方杀软按启发式判成风险——你遇到的就是这种情况。本机复核结果：1.3.4 的安装包 `a8760fdd…e883` 和便携 exe `6c8444c4…e725` 扫描均无威胁，说明是误报而不是真被感染。

可以先这样处理：

1. 用 **zip 便携版**（`maltese-assistant-v1.3.5-win64.zip`）解压运行，不经过安装器，拦截概率通常更低。
2. 把安装包哈希提交到 <https://www.microsoft.com/en-us/wdsi/filesubmission> 申请误报复核，通常几天内会更新特征库。
3. 长期方案是买代码签名证书（OV/EV）签 exe 和安装包；签好之后发布流程会自动带上签名，不用改代码。
