# Maltese v1.3.7

## 聊天框高度可调

- 右键小狗向下展开的聊天面板不再固定 520px，设置里新增「聊天框高度」，范围 **360–900 px**，拖动即时生效，重启后保留。
- 入口：岛内设置 → 布局，或独立设置窗口 → 显示，两个地方共用同一个值。
- 原生窗口高度上限同步放宽到 960，之前超过约 546 px 会被截断；实际高度仍会被屏幕工作区收一次，不会顶出屏幕。

## 验证

- `tsc --noEmit`、`vite build`、`cargo check` 通过。
- 交付前按 [release-checklist](../release-checklist.md) 跑 `verify-release-artifacts.ps1`。
