# Maltese v1.3.40

## 右键气泡新增「📌 固定当前标签到桌面」

右键小狗弹出的气泡里多了一个按钮，点一下就能把**当前标签页**从桌宠身上"摘"下来，变成桌面上一个一直存在的窗口。

- 入口：右键小狗 →「📌 固定当前标签到桌面」；
- 固定窗口置顶、可拖动（拖标题栏）、可缩放（最小 320×360），关闭后不影响桌宠；
- 第一次弹出会落在工作区右下角，不会挡住小狗；
- 顶部有徽章「已固定在桌面 · 聊天」和「取消固定」按钮，取消后窗口收回；
- 窗口显示在任务栏（`skipTaskbar: false`），不会"藏起来找不到"；
- 固定的标签会记住（`maltese-pinned-page`），下次固定直接是同一页。

目前支持固定**聊天**标签（聊天记录和主面板共用一份 localStorage 数据）；如果当前停在别的标签，
固定窗口会说明"该标签暂不支持固定"，并提示先切到聊天。

## 实现

- 新增窗口 `pinned`（`index.html?window=pinned`，透明、无边框、置顶、可缩放、默认隐藏）；
- 新增 `src/PinnedPanel.tsx` + `PinnedPanel.css`：头部（徽章 + 取消固定 + 关闭，`data-tauri-drag-region` 支持拖动）+ 内容区；
- 新增原生命令 `pin_page_to_desktop(page)` / `unpin_page_from_desktop()`：定位到右下角、置顶、显示并广播 `maltese-pinned-page`；
- 右键菜单在 `src/PetBubble.tsx`，通过 `maltese-pin-current-page` 事件通知主窗口，主窗口按当前 `page` 调固定命令。
