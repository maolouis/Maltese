# Maltese v2.0.0

版本号从 0.2.x 跳到 2.0.0：之前 0.1–0.2 那串编号是 fly-island 时期的旧序列，
和本仓库 `docs/releases/` 里的历史记录撞号（v0.2.6 及之后的文档都是旧产品的），
以后按 2.x 走，不再复用旧编号。

这一版把插件体系真正独立出来，另修了桌宠 GIF 的加载与轮播，并新增「关系」插件。

## 1. 插件独立化

- **插件窗口**：每个插件在独立的一页里打开，不再挤在插件中心的列表里。
- **预置插件改为独立插件文件夹**：`resources\plugins` 下的 `video-automation`（自动刷视频）、
  `relationship`（关系）、`hello-world`（示例）都是普通插件目录，各有自己的 `plugin.json`，
  可以整个文件夹拷走看结构。开发环境没有预置目录时，宿主用代码里的内置清单兜底，功能不变。
- **第三方插件可自带页面**：清单里写 `"ui": "index.html"`，宿主把插件目录里的这个文件装进
  iframe 显示，页面内的相对路径资源同样从插件目录加载；写 `"ui": "host"` 表示界面由宿主渲染。
- 插件页面与宿主隔离，只能用自己的前端能力；要启动本机程序仍在插件中心点它声明的动作。

## 2. 新增「关系」插件

- 以配对码建立关系，支持情侣 / 朋友 / 兄弟三种关系类型，建立后可以互聊。
- 和自动刷视频一样以预置插件（`builtin-relationship`）分发，只读、不能卸载；
  把同 id 的插件装到 `%APPDATA%` 插件目录即可覆盖。

## 3. 修复

- **桌宠 GIF 加载与表情轮播**：修复部分素材不显示、轮播停在同一帧的问题。
- **插件中心可读性整改**：说明文字全部搬进悬停气泡，字号提上来，卡片不再被长段落撑乱。

## 4. 自动刷视频

- 插件窗口改成浅色高对比样式，在浅色桌面上也看得清。

## 5. 安装与升级

| 方式 | 文件 |
| --- | --- |
| 安装包（推荐，支持应用内更新） | `Maltese-2.0.0-x64-setup.exe` |
| 便携版（解压即用） | `maltese-assistant-v2.0.0-win64.zip` |

- 安装包仍是 per-user 安装（写 `HKCU`，不需要管理员）；安装向导里可以改到自定义目录。
- 便携版带上 `resources\assets\pets`（桌宠素材）和 `resources\plugins`（预置插件），
  解压后直接运行 `Maltese-assistant.exe` 即可。
- `identifier` 仍是 `com.maolouis.maltese`，从 0.2.4 / 0.2.5 升级不会换数据目录；
  从 0.2.1 及更早版本升级需要迁移旧数据，见 `docs/releases/v0.2.4.md`。
- 版本号变化只影响显示与更新比对，`identifier`、安装目录、数据目录都不变，属于平滑升级。

## 6. 校验

- `SHA256SUMS-v2.0.0.txt` 给出 exe / 便携包 / 安装包的 SHA-256；
- 安装包带 Tauri updater 签名（`.sig`），`latest.json` 里的签名与之一致，应用内更新可直接用；
- 交付前检查：`scripts/verify-release-artifacts.ps1`，Defender 扫描无威胁。

## 7. 已知问题

1. **未做代码签名**：SmartScreen 会提示「未知发布者」；带 Smart App Control 的机器上，
   未签名安装器可能被应用程序控制策略拦截（`os error 4551`）。签名方案见 `docs/distribution.md`。
2. **部分带安全代理的机器上安装包会报 `Error writing temporary file`**（0.2.3–0.2.5 一致现象），
   属于安全软件拦截 NSIS 自解压；替代方案是用便携版 zip，或把安装包里的
   `maltese-assistant.exe` 直接覆盖到安装目录。
3. 插件动作以当前用户权限启动本机程序，安装第三方插件前请先审查其源码。

## 8. 版本策略

- GitHub 上的 Release 每个版本都保留，不删除、不改写；
- 本地 `release\` 只维护最新版本产物，旧版本不再备份，留档以 GitHub Release 为准。
