# Maltese v2.0.5

这是一版**以修复为主**的小版本（2.0.4 → 2.0.5）：把 11-20 至 11-26 之间逐个定位、逐个验收过的
六个「用户天天会遇到」的问题修掉，并顺手带上字体自定义、动画切换频率等体验项。

## 1. 修复（重点）

### 1.1 设置窗口打不开（WebView2 user data 目录被占用）

- **根因**：另一个进程（或同名 WebView2 实例）占着 user data 目录时，建窗直接失败并抛
  `ERROR_BUSY (0x800700AA)`；之前这个失败**完全不可见**，用户只看到「点了设置没反应」。
- **现在**：
  - **失败可见**：抓 wry 的原始错误文本，面板/托盘给出中文错误条（不再静默）；
  - **退避重试**：建窗失败按退避节奏重试，并做**物化校验**（窗口真的可见才算成功）；
  - **备用 label**：主 label 被占用时换备用 label 再建，避开 profile 冲突。
- 实机：`SETTINGS_OPEN materialized attempt=1 label=settings`、
  `SETTINGS_WINDOW_SHOW visible=true rect=(992,290,576,819)`，**5/5 通过**。

### 1.2 双击「向下闪一下」

- **根因**：双击浮层已经单次落位后，又跑了一次纠正；并且用了 **stale 锚点**（旧的收起态矩形），
  实测曾一次性跳 **545px**。
- **现在**：单次落位后不再二次纠正，落位前校验锚点是否过期（stale 直接丢弃重取）。
- 实机逐帧（80ms 采样）：**5/5 PASS**，`distinctRects=1 maxDriftPx=0`、`violations=0`、`large_corrections=0`。

### 1.3 冷启动间歇卡死

- **根因**：主线程永久阻塞在 Rust `std::Mutex` 的 futex 等待（`WaitOnAddress`），
  卡在 `setup:island_ready` 之后、前端首帧之前，命中率约 56%。
- **现在**：
  - 几何缓存锁**全部改 `try_lock`**（拿不到就跳过，不再死等）；
  - `on_window_event` 只**置脏标记**，不在事件回调里做窗口操作；
  - 几何计算移到**专用线程**；
  - `extras` 重同步**延后到 `frontend_ready`**；
  - watchdog **异步投递**（不再占用主线程）。
- 实机：**20/20 PASS × 2 次独立运行**（`Responding=True`、`frontend_ready`、心跳齐全、
  `MUTEX_TRACE` 争用 **0**、watchdog 触发 **0** 次）；另附 `MUTEX_TRACE` 探针与 20 轮参数化验收脚本。

### 1.4 tab 切换时窗口上下移

- 展开态窗口高度原来会跟着当前 tab 内容变，切 tab 就像「窗口在上下跳」。
- 现在**高度与 tab 解耦**（`UNIFIED_EXPANDED_ISLAND_HEIGHT = 520`），切 tab 窗口不动，只有内容区滚动。

### 1.5 窗口边缘可缩放 + 尺寸持久化

- 岛窗口支持**边缘拖拽缩放**，尺寸写 `island-size.json` 持久化，重启后保持；
  设置里提供「恢复默认窗口大小」。

### 1.6 视频专用浏览器 profile 迁出 C 盘

- 专用浏览器 profile 从 `%LOCALAPPDATA%\Maltese` 迁到 `<数据目录>\video-browsers`
  （启动时迁移，旧位置保留只读回退，出问题可回退）。
- 效果：**C 盘释放 3.465 GiB**（`%LOCALAPPDATA%\Maltese` 现已 0 字节），
  登录态完整保留（`cookies` 账号 42 条 / default 31 条均在）。

## 2. 新增

- **字体自定义**：界面字体与桌宠气泡字体可分别设置（CSS 变量 `--app-font-family` / `--pet-font-family`）。
- **动画「切换频率」**：原来的「动画流畅度」改为 **高频 / 中频 / 低频** 三档，旧值会自动迁移，不会丢设置。
- **实例联动下线**：`PET_LINK_ENABLED=false`，设置页隐藏入口（多实例联动代码保留，后续架构稳定再上）。
- **文档入口**：README 增加「📖 使用手册」入口，新增 `docs/TODO.md`（12 条待办，随时可查进度）。

## 3. 已知问题

1. **主窗口自身遇到 `ERROR_BUSY`（0x800700AA）没有自动恢复**：本版只修了设置窗口的建窗路径；
   主窗口 profile 被占用时仍需重启应用。
2. **retry / 备用 label 失败路径未真实触发过**：只实测了成功路径（5/5）；失败分支是代码保证。
3. **B 首开有约 5px 残差**（在 8px 容差内，肉眼基本不可见）。
4. **小红书评论自动提交仍差最后一步**：已到「写入编辑器」，卡在找不到发送按钮（`no-button`）。
5. **B 站评论受账号状态限制**：未转正账号站点侧返回 `-107`，面板会给原因但不代发。
6. **混合 DPI 未实测**：多屏不同缩放比例只有静态换算与单屏实测。
7. **几何架构重构进行中**：单一真值 `DogSlot` 的迁移尚未完成，个别边缘场景仍可能有位移。
8. **未做代码签名**：SmartScreen 会提示「未知发布者」；部分带安全软件的机器 NSIS 自解压报
   `Error writing temporary file`，可改用便携版 zip。
9. **版本号口径**：原计划发布 2.0.4.1，但 Tauri 要求 `tauri.conf.json > version` 必须是合法 semver
   （四段号在配置解析阶段就被 `must be a semver string` 拒绝，构建无法进行），因此实际发布为 **2.0.5**；
   本版内容与计划的 2.0.4.1 完全一致。

## 4. 安装与升级

| 方式 | 文件 |
| --- | --- |
| 安装包（推荐，支持应用内更新） | `Maltese-2.0.5-x64-setup.exe` |
| 便携版（解压即用） | `maltese-assistant-v2.0.5-win64.zip` |
| 插件（按需安装） | `billiards.zip` / `video-automation.zip` / `relationship.zip` / `hello-world.zip` |

- 安装包为 per-user 安装（写 `HKCU`），`identifier` 仍是 `com.maolouis.maltese`，**2.0.4 → 2.0.5 不换数据目录**。
- 首次启动会把视频专用浏览器 profile 从 `%LOCALAPPDATA%\Maltese` 迁到 `<数据目录>\video-browsers`
  （**C 盘可释放约 3.5 GB**），旧目录保留只读回退；确认视频插件登录态正常后可自行清理旧目录。
- 便携版含 exe 与 `resources\assets\pets`，**不含插件**；插件到插件中心粘贴 zip 路径安装。

## 5. 校验

- `SHA256SUMS-v2.0.5.txt` 给出 exe / 便携 zip / 安装包 / 4 个插件 zip 的 SHA-256。
- 安装包带 Tauri updater 签名（`.sig`），`latest.json` 内签名与安装包一致。
- 交付前跑 `scripts/verify-release-artifacts.ps1`，Defender 扫描无威胁。
