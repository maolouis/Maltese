# Maltese v1.3.15

## 双击闪烁修复（改进版）

- 双击改成自己按间隔判定（320 ms 内两次点击），不再依赖系统 `dblclick`：拖动用的指针捕获会让 `dblclick` 时有时无，之前双击打不开、还先切了一帧表情。
- 单击切表情延迟到 340 ms 后执行；确认是双击就取消这次切换，双击时不会再闪一帧。
- 浮层打开时先把小狗按槽位尺寸钉在窗口角上，再放大原生窗口，避免窗口变大、小狗还居中的第一帧往左偏。
- 双击入口保持为互动气泡面板（原来 Ctrl + 悬停），右键仍是聊天。
