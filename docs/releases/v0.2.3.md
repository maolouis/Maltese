# Maltese v0.2.3

本地更新（按要求**未推送远端、未发布 Release**）。

## 1. 删掉聊天页的「固定到桌面」按钮

聊天面板头部那个「📌 固定到桌面」去掉了（连同年限判断 `inPinnedWindow` 与 `Pin` 图标一起清理）。

固定到桌面的入口仍然保留两处，功能没少：

- 小狗悬停气泡面板里的「📌 固定「聊天」到桌面」；
- 面板右上角按钮组里的 📌（固定当前标签）。

## 2. 改名与公司信息

| 项目 | 值 |
| --- | --- |
| `productName` | **Maltese** |
| 发布者 `bundle.publisher` | **maolouis** |
| 版权 `bundle.copyright` | © 2026 maolouis |
| `Cargo.toml` authors | `["maolouis"]` |
| `package.json` author | `maolouis` |
| `identifier` | 保持 `com.maltese.desktop-assistant` 不变 |

> `identifier` 故意没动：Windows 上应用数据目录与它相关，改掉会让待办、聊天记录、设置全部变成新的一份。
> 如果确实要改成 `com.maolouis.maltese`，需要先做数据迁移，可以单独安排。

安装包 / 卸载项 / 快捷方式名字沿用 v0.2.2 的改名结果：

- 安装包：`Maltese_0.2.3_x64-setup.exe`
- 卸载项 DisplayName：`Maltese`
- 快捷方式：`Maltese.lnk`
- 可执行文件仍是 `maltese-assistant.exe`（自启动与快捷方式继续有效）
