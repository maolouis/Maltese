# Maltese v1.3.36

## 台球改成「真的把快捷方式图标当台球」

按参考项目 [desktop-icon-billiards](https://github.com/liuxiaogang-com/desktop-icon-billiards)（作者 **GitHub@liuxiaogang-com**，MIT）的做法重写：

- **真实图标就是球**：开局读出桌面每个图标的原始位置，把它们**摆成三角球阵**；
- 击球后按物理结果**批量搬动真实桌面图标**（`LVM_SETITEMPOSITION`），图标在桌面上滚动、互相碰撞；
- 球进洞即"入袋"，桌面图标留在洞口；白球落袋回开球点、本杆不计分；
- 覆盖层只画白球、六个球洞、瞄准线、力度条、小狗和顶部状态条——图标本身是桌面上的真实图标，不再画假球；
- 你打一杆、小狗打一杆：小狗把白球位置、六个洞、剩余球编号发给本机模型，只要一行
  `{"target":编号,"power":0.3~1}`，再本地算「幽灵球」瞄准点出杆；模型不可用则用几何最优解。

## 安全兜底（重点）

搬动真实图标有风险，所以做了三层保护：

1. **开局先备份**：把每个图标的原始位置写进内存**并**落到
   `%APPDATA%\maltese\billiards-backup.json`；
2. **退出即恢复**：点「退出」、按 `Esc`、窗口关闭、页面卸载都会调用恢复；
3. **异常退出兜底**：应用每次启动时检查这个备份文件，存在就先把图标位置改回来再删掉。

另外，桌面若开着「自动排列 / 对齐到网格」，会临时关掉（否则图标会被立刻吸回去），退出时按原状态还原。

## 界面精简

顶部只有一条胶囊：回合徽章 · 比分（你 X : Y 小狗）· 剩余 · 用时 · 重开 · 退出；下面一行提示；署名在右下角淡字。

## 已知限制（请留意）

- 需要**桌面图标处于显示状态**；隐藏图标时插件卡片会直接提示，不会启动游戏。
- 搬动图标需要向 explorer 的桌面列表窗口发消息。某些系统策略/安全软件会拦截这类跨进程消息
  （我这边测试时就遇到过 `ERROR_ACCESS_DENIED`）。**拦截时不会搬动任何图标**，会直接报错，桌面保持原样。
- 多显示器只覆盖主显示器；图标很多时最多取 45 个。
