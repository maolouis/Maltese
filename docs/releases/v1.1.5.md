# Maltese 线条小狗桌面助手 v1.1.5

## 修复

- **修复 v1.1.4 在右下 / 右上角无法弹出面板**：小狗被复位到屏幕右侧后，展开面板仍然只向右侧生长，窗口大部分落在屏幕外，看起来像“点了没反应”。
  现在会根据左右剩余空间自动选择展开方向：右侧不够就翻到左侧，窗口位置同步调整，小狗本身不跳动。
- **鼠标悬停气泡同样支持向左弹出**：右侧空间不足时，气泡长在小狗左边；小狗仍钉在屏幕原位置，不会跟着气泡左移。
- **修复“气泡文字颜色”修改后不生效**：气泡颜色现在通过 CSS 变量同时应用到主窗口浮层和独立气泡窗口；设置窗口改色会即时同步，已打开的气泡也会刷新。
- 展开面板高度仍按屏幕上方可用空间压缩，避免顶部溢出。

## 新增 / 复用设置

- 新增 **小狗不透明度**（30%–100%），只影响小狗本体，不影响气泡和面板；主设置页和独立设置窗口均可调整。
- 这是从 LineDogPet 设置中复用的第一项外观能力，其余交互 / 主题 / 特效项会在后续版本按优先级补齐。

## 兼容性

- 设置中的复位位置、拖拽位置、待办、剪贴板、消息和聊天记录均保留。
- 右下 / 右上角首次展开会自动改为向左弹出；之后切回收起态仍停留在原来的角落。
- 新增 `petOpacity` 字段有默认值，旧配置文件无需迁移。

## 验证

- 新增 Rust 回归测试 `expanded_panel_flips_away_from_screen_edges`，覆盖左缘、右缘、两侧都放不下和负坐标副屏。
- `cargo test --target x86_64-pc-windows-msvc --lib`：66 passed / 0 failed / 9 ignored。
- `tsc --noEmit` 通过。

## 运行方式

1. 解压发布包，确保 `maltese-assistant.exe` 和 `WebView2Loader.dll` 在同一目录。
2. 双击 `maltese-assistant.exe`，小狗出现在桌面。
3. 鼠标悬停或点击小狗打开互动面板；右键任务栏托盘图标可配置、隐藏或退出。
