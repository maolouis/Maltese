# Maltese v2.0.6

这是一版**以修复和体验打磨为主**的小版本（2.0.5 → 2.0.6）：把 2.0.5 之后暴露的「双击小狗向左上角闪动」彻底闭环，
顺带补上新手引导、系统字体检测、WebView2 建窗自愈，并把小狗收起大小的放大上限从 1.8 倍放宽到 3.0 倍。

## 1. 修复（重点）

### 1.1 双击小狗「向左上角闪动」根因修复

2.0.5 修的是「双击下闪」，但正常冷启动下仍会复现「向左上角闪动」。根因不是 CSS，而是**多份几何真值互相覆盖**：

- 前端挂载时同步显示器偏好，旧实现会无条件清空 `custom_position`；
- 双击打开浮层时，`WindowEvent::Resized` 把**浮层大窗口左上角**写进了「收起态狗槽矩形」缓存；
- 60ms 实测上报时读到了被污染的缓存，把已对齐的窗口再减 `(328, 410)` 物理像素推向屏幕左上角；
- 云朵气泡开着时双击（`cloud → hover`）又把云朵外框左上角写回锚点；
- 跨方向样本混用预补偿、前端量 `.maltese-pet`（带 `-3/-4.5px` 内边距）而不是狗槽容器，造成首开 ~5px 残差。

**现在**：`LAST_OUTER_WINDOW_RECT`（任意外框）与 `LAST_SETTLED_ISLAND_RECT`（严格只存收起态狗槽）职责分离；
`expected_slot_from_state` 在浮层期优先认 `OVERLAY_SNAPSHOT`；计划与落位共用同一套窗口矩形计算；
测量样本按 `(side, vertical)` 隔离并改量 `.island__collapsed--pet-only`；`SetWindowPos` 补 `SWP_NOCOPYBITS` 杜绝旧位图左上角闪现。

实机逐帧（35ms 采样）两个场景各 4 轮双击 × 30 帧：`maxDriftPx=0`、`corrections=0`、`violations=0`，
首次打开也是 `dx=0 dy=0`。细节见 [diagnostics/overlay-doubleclick-flash.md](diagnostics/overlay-doubleclick-flash.md)。

### 1.2 主窗口 WebView2 `ERROR_BUSY` 自愈

上一版只修了设置窗口；主窗口 profile 被占时仍建不出句柄。现在建主窗口前先做 `lockfile` 独占探测，
失败按 3 级退避重试，仍被锁死或目录只读时自动切到 `<数据目录>\webview2-fallback-N`，
并用实机锁文件压测验证过（`src-tauri/src/webview_profile_guard.rs`）。

### 1.3 小红书评论自动提交

发送按钮一直找不到（`no-button`）。实际是三个小问题叠一起：

- `/\.submit/` 里的点号被当成**字面点号**（少写转义），扫不到 `.submit` 类名；
- 站点部分账号的按钮文案是「发 送」（中间带空格）；
- 纯图标按钮只有 `.submit-btn` 类名，没有文字。

现在按「编辑器所属底栏容器」优先查找，兼容带空格文案与纯图标按钮，并支持 `pointerSequence` + `Enter` 兜底，
发送后校验编辑器是否清空；Mock DOM 4 个场景单测全过。真实站点仍需安静窗口线上复验一次。

### 1.4 跨缩放比恢复窗口尺寸

`restore_island_rect_on_startup` 现在按目标屏**实际 `scale_factor`** 换算物理宽高并原子落定，
避免换屏 / 改缩放后窗口按旧物理值偏大偏小。

## 2. 新增与改进

- **6 步新手引导重构**：高对比度浅色云朵面板，六步「选伙伴 → 调外观 → 学互动 → 百宝箱 → 快捷键 → 出发」。
  角色卡片点了立刻换形象；外观步可实时预览经典云朵 / 液态玻璃、收起大小三档与四个停靠角；
  互动步是真的试玩台（单击 / 双击 / 右键 / 拖拽都能触发真实反应）；快捷键步可录制与重置；
  中英双语，两个设置入口都能「重新查看新手引导」。
- **系统字体检测**：`list_system_fonts` 通过 `SPI_GETNONCLIENTMETRICS` 读出 Windows 现用字体并置顶标注，
  再用 `EnumFontFamiliesExW` 枚举本机已安装字体（过滤 `@` 竖排变体与纯符号图标字体），
  界面字体 / 桌宠字体直接下拉即选，不用再手输字体名。见 [ui-fonts.md](ui-fonts.md)。
- **收起大小上限放宽**：从 1.8 倍放宽到 **3.0 倍**，设置滑块、桌宠渲染、随从宠窗口与岛窗口尺寸同步；
  展开面板仍是 0.5–1.8 倍。

## 3. 已知问题

1. **小红书评论线上复验**：逻辑已修 + Mock DOM 已过，仍差真实账号安静窗口的一次真发。
2. **B 站自动评论受账号限制**：未转正账号站点返回 `-107`，面板给原因，不绕过风控。
3. **混合 DPI 未实测**：跨缩放换算已补齐，仍缺 100% + 150% 物理双屏实测。
4. **几何单一真值仍在收敛**：`DogSlot` 状态机终态未完成，极端边缘场景仍有理论残差（当前实测 0）。
5. **实例联动仍下线**：`PET_LINK_ENABLED=false`，设置页隐藏入口。
6. **未做代码签名**：SmartScreen 会提示「未知发布者」；部分带安全软件的机器 NSIS 自解压可能报
   `Error writing temporary file`，可改用便携版 zip。
7. **每日图文总结视频**未实现（预研完成，见 [research-daily-summary-video.md](research-daily-summary-video.md)）。

## 4. 安装与升级

| 方式 | 文件 |
| --- | --- |
| 安装包（推荐，支持应用内更新） | `Maltese-2.0.6-x64-setup.exe` |
| 便携版（解压即用） | `maltese-assistant-v2.0.6-win64.zip` |
| 插件（按需安装） | `billiards.zip` / `video-automation.zip` / `relationship.zip` / `hello-world.zip` |

- 安装包为 per-user 安装（写 `HKCU`），`identifier` 仍是 `com.maolouis.maltese`，**2.0.5 → 2.0.6 不换数据目录**。
- 便携版含 exe 与 `resources\assets\pets`，**不含插件**；插件到插件中心粘贴 zip 路径安装。

## 5. 校验

- `SHA256SUMS-v2.0.6.txt` 给出安装包 / 便携 zip 的 SHA-256。
- 安装包带 Tauri updater 签名（`.sig`），`latest.json` 内签名与安装包一致。
- 交付前跑 `scripts/verify-release-artifacts.ps1`，Defender 扫描无威胁。
