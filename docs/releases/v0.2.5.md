# Maltese v0.2.5（首次发布到 GitHub）

v0.2.1 之后积压的改动一次性发布。这一版本身只改版本号，实质变化是
**v0.2.2–v0.2.4 的改名、素材外置、identifier 迁移开始对公众生效**。

## 1. 相对远端 v0.2.1 的变化（累积）

| 版本 | 内容 |
| --- | --- |
| v0.2.2 | 应用改名 `Maltese`：`productName`、安装包名、卸载项、快捷方式、默认安装目录 |
| v0.2.3 | 删掉聊天页「固定到桌面」按钮（保留气泡面板与顶部按钮组入口）；`publisher` / `authors` 改为 `maolouis` |
| v0.2.4 | 应用数据备份 + `identifier` 从 `com.maltese.desktop-assistant` 迁移到 `com.maolouis.maltese` |
| v0.2.5 | 版本号 0.2.4 → 0.2.5；重新构建并发布 |

## 2. 安装与升级

| 方式 | 文件 |
| --- | --- |
| 安装包（推荐，支持应用内更新） | `Maltese-0.2.5-x64-setup.exe` |
| 便携版（解压即用） | `maltese-assistant-v0.2.5-win64.zip` |

成员说明：

- 安装包是 per-user 安装（写 `HKCU`，不需要管理员），默认装到 `%LOCALAPPDATA%`；
  迁移到自定义目录（例如 `E:\Maltese2`）在安装向导里改路径即可。
- 便携版这次**带上了 `resources\assets\pets`**（43 MB 桌宠素材）。v0.2.0 起素材是外置的，
  之前的便携包只有 exe，解压后桌宠没有 GIF；本版补上，解压后直接运行即可。
- 升级旧版本时，`identifier` 变化会换掉 WebView2 数据目录（`%LOCALAPPDATA%\com.maolouis.maltese`）。
  需要保留旧设置的话，先把旧目录的 `Local Storage\leveldb`、`IndexedDB`、`Network`、`Preferences`
  覆盖进新目录，详见 `docs/releases/v0.2.4.md`。

## 3. 校验

- `SHA256SUMS-v0.2.5.txt` 给出 exe / 便携包 / 安装包的 SHA-256；
- 安装包带 Tauri updater 签名（`.sig`），`latest.json` 里的签名与之一致，应用内更新可直接用；
- 交付前检查：Defender 扫描无威胁（脚本 `scripts/verify-release-artifacts.ps1`）。

## 4. 已知问题

1. **未做代码签名**：SmartScreen 会提示「未知发布者」。签名方案见 `docs/distribution.md` §4/§5。
2. **部分带安全代理的机器上安装包会报 `Error writing temporary file`**（本机复现：
   安装器 0.1 秒内退出码 2，同一现象在 v0.2.3 / v0.2.4 的安装包上一致，目标目录为空目录也一样）。
   这是机器上的安全软件拦住了 NSIS 自解压，与本版构建无关。
   **替代方案**：用便携版 zip，或把安装包里的 `maltese-assistant.exe` 直接覆盖到安装目录。
3. `identifier` 换名后，翻译密钥的 Windows 凭据条目名故意保留旧值
   （`com.maltese.desktop-assistant.translation`），已保存的有道密钥不用重填。

## 5. 本机验证记录

- `verify-architecture`：56 模块、`App.tsx` 9161 行预算内、无反向依赖；
- `verify-parity`：17 项功能锚点全在位；
- `verify-build`：`tsc` + `vite build` 通过，素材 97 个路径完整，版本号三处一致（0.2.5）；
- `verify-packaging`：标准 NSIS、无加壳注入、自启动仅 `HKCU\...\Run`；
- `tauri build --bundles nsis` 带 updater 签名成功，产出 `Maltese_0.2.5_x64-setup.exe` + `.sig`；
- 本机安装：安装器被安全代理拦住（见已知问题 2），改用文件级覆盖把 0.2.5 的 exe 铺到
  `E:\Maltese2`，`ProductVersion` 校验为 `0.2.5`，素材与仓库 `assets/pets` 逐项一致；
- 产物：`release\v0.2.5\`、`release\maltese-assistant-v0.2.5-win64.zip`、`release\SHA256SUMS-v0.2.5.txt`。
