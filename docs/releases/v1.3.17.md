# Maltese v1.3.17

## 双击闪一下：改成「先定方向，再改窗口」

v1.3.16 已经做了两件事（原子 `SetWindowPos`、打开时本地预判方向），但根本顺序问题还在：**方向是原生算完再回传的，前端第一次渲染只能用上一轮的方向**。小狗贴着屏幕右侧时，气泡要往左长，窗口会整体左移；如果这时前端还按「面板在右」布局（小狗钉在窗口左边），小狗就会跟着窗口一起左移，闪一下再弹回来。

现在拆成严格三步：

1. 新增 `plan_island_overlay(mode)`：原生只算方向（左右 / 上下），**不动窗口**。
2. 前端拿到方向后先提交一次渲染，把小狗钉到正确的窗口角上（此时窗口还是原尺寸，屏幕画面不变）。
3. 再调用 `set_island_overlay`，由原生一次 `SetWindowPos` 同时改尺寸和位置。

这样窗口几何只有一次变化，且变化时小狗已经锚在正确的一侧，中间不存在错位帧。方向回传仍然是权威值，预判只作为预判失败时的兜底。
