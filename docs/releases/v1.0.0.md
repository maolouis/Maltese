# Maltese 线条小狗桌面助手 v1.0.0

首个完整发布版本。

## 桌宠与交互

- 线条小狗桌宠形态：单击摸头、双击庆祝、右键抱起/打开菜单，动作结束后自动回到系统状态。
- 状态感知动画：空闲、听歌、工作、需要关注四类系统状态自动切换；每类状态多张 GIF 随机轮换（素材来自 LineDogPet 小白角色，共 60+ 变体）。
- 全局唤醒快捷键（默认 Ctrl+Alt+M），录入时检测热键冲突。
- 窗口可拖动固定到桌面任意位置，支持开机自启动。
- 全屏避让：检测到游戏/视频全屏时，小狗自动缩到屏幕边缘（也可设为暂时隐藏），退出全屏自动恢复。

## 快捷面板

- 豆包：本地桌面端检测与一键启动。
- 网易有道词典：一键启动本地客户端。
- 音乐播放控制（Windows 媒体会话）：播放/暂停/切歌/音量。
- Clash / Watt 一键启动；计算器与 PowerToys 常用工具入口。
- Geek 卸载工具、软件版本更新检测。
- 常用脚本目录（桌面\常用脚本）自动扫描与一键启动。
- B 站/抖音自动翻页与本机 DSH API（http://127.0.0.1:3218）。
