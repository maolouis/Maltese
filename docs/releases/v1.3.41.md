# Maltese v1.3.41

## 修：「固定到桌面」按钮找不到

上一版只把按钮加在了 `PetBubble` 那个独立气泡窗口的菜单里，但**右键小狗其实是直接打开聊天页**
（`onContextMenu → onOpenPage("chat")`），根本没走那个菜单，所以看不到按钮。

这一版把入口放到了用户真正会看到的地方：

| 位置 | 什么时候能看到 | 文案 |
| --- | --- | --- |
| 鼠标悬停气泡面板 | 鼠标移到小狗身上 | 📌 固定「聊天」到桌面（显示当前标签名） |
| 聊天页头部 | 右键小狗 → 打开聊天后 | 📌 固定到桌面 |

- 悬停面板里的按钮按当前标签命名（聊天 / 待办 / 音乐 / 剪贴板 / 消息 / 快捷…），点完直接把气泡收起来；
- 聊天页头部的按钮固定的是聊天标签，点完在桌面右下角出现固定窗口；
- 固定窗口里不再显示这个按钮，避免"窗口里再固定一个窗口"；
- 两个按钮都是 12.5px 加粗、青色底，悬停变亮 + 上浮，符合上一版定的可读性规则。
