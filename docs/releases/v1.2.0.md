# Maltese v1.2.0

这一版把桌宠的表情轮播、插件和快捷方式都做成了可配置的，并修掉了几处“位置自己跑掉”的旧问题。

## 表情与 GIF

- 主狗、陪玩狗、鼠标跟随狗都接入了 GIF 轮播；主狗之前只在睡觉和待机之间切，现在会按顺序轮播所有闲置表情。
- 新增 **表情轮播** 设置页：缩略图按播放顺序排列，可直接看到第 1、2、3 张会怎么播。
- 支持给每种表情添加自己的 GIF（可多选，单张不超过 8 MB），也能删除或调整前后顺序。
- 自定义 GIF 会复制到应用数据目录，不会改动安装目录；删除条目时会同时清理对应副本。
- 把某类表情删空时会暂时使用内置默认顺序，不会显示破图。
- 设置窗口保存后，主狗、陪玩狗和跟随狗会同步更新顺序。

## 插件

- 新增插件中心：内置的“自动刷视频”和第三方插件放在同一页管理。
- 第三方插件只需一个包含 `plugin.json` 的文件夹，可在插件页填写路径安装，也可直接放入插件目录后刷新。
- 支持启用/停用、卸载、运行插件动作；插件动作以当前用户权限启动本机程序。
- 新增开发文档 `docs/plugins.md` 和可直接安装的示例 `examples/plugins/hello-world/`。
- 插件安装目前接收**文件夹**；下载的 zip 需要先解压。

## 交互与快捷方式

- 互动面板改为 **Ctrl + 鼠标悬浮** 打开，普通悬浮不再弹出，减少误触。
- 桌宠改为 **按住鼠标左键直接拖动**，不再需要按住 Ctrl；单击仍然是摸摸头，双击庆祝。
- 每个快捷方式都能单独录制打开热键：点卡片右侧的 ⌨ 按钮录制，Esc 取消，右键清除。
- 应用启动时会恢复所有已保存的快捷方式热键；热键冲突会在设置卡片里标出。
- 自定义快捷方式放在发现目录之外也能正常打开。

## 待办

- 每日滚动不再清除未完成的待办；没打勾的事项会原样保留，包括原来的计时。
- 已完成的事项仍随每日归档清理；移除了不再使用的“保留未完成待办”开关。

## 修复

- 固定在右下角的小狗偶尔会自己往左上移动：
  - 浮层展开/收起期间的窗口移动事件不再被误记为用户拖拽位置；
  - 显示器查找失败时不再直接丢弃右下角坐标，而是保留并夹到当前工作区；
  - 固定角落时禁用“随机闲逛”，避免小狗主动挪走。
- 清理了热键管理器里一个未使用字段的编译警告。
