# Maltese v1.3.3

## Bongo 模式

- 修复「开了 Bongo，开机后不自动出现，要先关一次再开」的问题：启动时如果 Bongo 窗口还没注册完或者 show 被系统吞掉，现在会在后台重试最多约 8 秒，直到窗口真的可见。
- 新增「Bongo 默认位置」：底部居中（默认）/ 左下 / 右下 / 顶部居中，岛内设置和独立设置窗口里都能改，改完立刻生效，下次启动也从这里出现。

## 桌宠显示

- 收起态的小狗不再被窗口底边裁掉一点：图片下移量从 23px 收到 8px，脚和趴卧线条仍然贴着桌面，但整只狗都能露出来。

## 验证

- `tsc --noEmit`、`vite build`、`cargo check` 通过。
