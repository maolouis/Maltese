# Maltese v0.2.1（修复：小狗 GIF 不显示 / README 图标失效）

本次只修 bug，不改功能。

## 1. 小狗图标不显示（v0.2.0 素材外置引入）

**现象**：升级到 v0.2.0 后，桌宠窗口一片空白 —— 小狗 GIF 完全没加载；换成 `E:\Maltese2` 安装目录后依旧。

**两个原因叠加**：

1. `tauri.conf.json` 的 `app.security.assetProtocol.scope` 里只有 `$APPDATA/pet-gifs/**`。
   素材外置后 GIF 走 `convertFileSrc` 的 `asset:` 协议读取，路径落在安装目录，
   **不在授权范围**，请求被拒；
2. `get_pet_asset_base` 只探测了 `<resource_dir>/assets/pets` 一种布局，
   而 NSIS 实际把资源放在 `<安装目录>/resources/assets/pets`，探不到就退回 `/assets/pets/...`
   —— 前端产物里已经没有这个目录，于是 404。

**修复**：

- asset 协议 scope 增加 `$RESOURCE/**`（保留原来的 `$APPDATA/pet-gifs/**`）；
- `get_pet_asset_base` 改为按顺序探测 4 种布局并返回第一个存在的：
  `<resource_dir>/assets/pets`、`<resource_dir>/resources/assets/pets`、
  `<exe 目录>/assets/pets`、`<exe 目录>/resources/assets/pets`。

**实测**（安装目录 `E:\Maltese2`，桌宠槽位像素采样）：

| 版本 | 深色像素 | 彩色像素 | 结论 |
| --- | --- | --- | --- |
| 修复前（0.2.0） | 0 | 0 | 槽位纯白，小狗完全没画出来 |
| 修复后（0.2.1） | 103 | 402 | 小狗正常渲染 |
