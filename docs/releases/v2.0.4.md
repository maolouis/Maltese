# Maltese v2.0.4

这一版把「小狗自己刷视频」做成一条能跑起来的完整链路（采集稳定 → 看懂内容 → 用自己的语气点评 → 气泡回传），
同时新增 Agent 控制台与 Token 统计、三层记忆、桌宠人设与轮播多样性，并把数据目录迁出系统盘。
**升级前请先看第 3 节的数据位置变更。**

## 1. 新增

### 1.1 视频插件：采集稳定 + 看得懂 + 会点评

- **采集稳定性**：改为「候选队列 + 确定性导航」，强制进入视频详情页（导航 / 点卡片 / 排行榜三段降级），
  只收具体视频页、过滤伪条目；每次运行单独落日志并同步托盘状态。
- **多实例体检与自愈**：运行中单实例化 + CDP target 锁定与复核，导航被站点带回首页时记录 `NAV_REVERT`
  并重导航（3 次），必要时 `BROWSER_RESTART` 真正重新拉起浏览器并重进视频页——不再「一次异常就全程空转」。
- **历史与小结不再空白**：用户停止也必定写终态小结并增量落盘；历史会话可展开详情，`stopReason` 区分
  用户停止 / 浏览器不可用 / 端口占用。
- **面板可读性**：口味卡片折叠让首屏更简洁；小结区块白字改深色、字号统一放大。
- **聊天改口味**：新增 `video_taste`（口味偏好解析 + 关键词快速通道直出 + `SKILL_MATCH` 日志），
  你可以直接跟小狗说「最近想看 XX」，它会把口味带进采集与小结。
- **小狗人设评论**：评论由本地模型按小狗口吻生成（第一人称「我看了什么/我感觉如何」+ `dogTake`），
  带深度思考、禁用语过滤与完整性校验；自动评论有独立策略层（触发条件 / 去重 / 安全阀 / 文案模板），
  发送前后共三重校验，回读穿透 Shadow DOM，只认真正发出去的评论（`COMMENT_POSTED` 才算 verified，否则 `COMMENT_UNVERIFIED`），
  「只输入没发出去」不再谎报成功。
- **评论气泡**：展开态在面板显示最后一条评论，收起态顶着气泡弹出（不受 `bubbleOn` 限制）。
- **小红书**：只读采集 MVP（图片懒加载、字段缺失时的健壮性处理）、图文草稿骨架、
  **模型自动编辑图文**（严格 JSON 输出 + 原创性检查 + 可编辑预览）、小狗口吻短评 `dogTake` 与
  「只挑了几篇」的 `pickNote`、文字配图填充；登录检测改为 URL / 用户标识 / 弹窗遮罩三级探针。
- **B 站**：补齐评论选择器，评论发送增加专项诊断与 API 兜底（可定位到「账号未转正 -107」这类站点侧原因）。

### 1.2 Agent 控制台与 Token 统计

- **桌面 AI 应用监控**：识别 Claude / ChatGPT / 豆包 / 通义等桌面客户端并支持聚焦切换，多 Agent 适配器 + 串行流水线。
- **任务进度状态机**：对话任务从排队到完成的状态流转 + 控制台任务列表（心跳不落盘，只有真变化才写）。
- **Token 统计**：按天 JSONL 落库，`usage_summary` / `usage_clear` 命令与 Token 卡片（总量 / 请求数 / 六大来源分组 /
  失败数 / 平均耗时 / 模型名 / 最近记录）；一次请求只记一条（主尝试 + 重试合并），模型名统一用服务端 id。

### 1.3 三层记忆

- 短期 10 条 / 当日摘要 / 事实卡三层注入，预算默认 ≤70 token。
- **记忆维护**：空闲 30s 后用模型生成当日摘要并抽取事实（不抢前台请求）。
- **观看记忆**：只记「强兴趣、看较久」的视频（stop 后读 session 写 `watch[]`），可单独开关，注入聊天上下文。

### 1.4 桌宠

- **人设**：加入天真烂漫 / 单纯的一面；状态低落时会主动求安慰（每日 ≤2 次、间隔 ≥3h，可在设置里关）。
- **体力与情绪**：离线恢复体力（手动睡觉 25/h、待机 8/h）；刷视频涨情绪（mood +2/条，每日最多 6 条）；
  睡觉态暂停读取电脑状态，待机打盹时置 idle 档。
- **轮播多样性**：洗牌袋 + 最近去重 + 权重封顶，表情重复率从 **88.5% 降到 0**（不再老是那几张）。
- **启动位置**：退出即快照、启动先按快照矩形恢复（`STARTUP_RESTORE source=file`），不再依赖设置解析链路。
- **几何不变量兜底**：双击/右键/展开/收起统一走「不变量强制约束」（±2px 内必须回到原狗槽），
  规划阶段禁止移动，并新增 `geometry_authority` 记录层（source / epoch / before / after）便于追责定位。
- **任务栏避让**：气泡、浮层、固定页都避开任务栏；展开/右键不再跨屏。
- **多屏与 Bongo**：Bongo 偏好为空时按小狗实际所在屏解析，重启后跟着小狗走。

### 1.5 素材

- 收下 **220 张重新抠背景的白底 GIF**（用户已验收），素材清单保持 **789 张**不变。

### 1.6 数据目录外迁

- 新增 `paths.rs` 统一数据根，首次启动把业务数据从系统盘迁到非 C 盘；默认数据根改为运行版安装目录下的 `data/`
  （便携布局），可用 `data-dir.txt` 指定自定义位置。

### 1.7 插件

- 用户目录安装的插件优先于安装包预置版本（列表 / 界面 / 动作指向一致）。
- 插件声明可执行动作时必须声明 `process` 能力，插件卡片会显示「进程权限」徽章。

## 2. 修复

1. **修复构建完整性**：`lib.rs` 残留括号与重复命令片段、`PinnedPanel` 导入路径、移除已废弃的
   `video_automation`/`video_rules` 模块。此前 HEAD 在干净工作区无法编译，现已修正。
2. **视频**：命令阻塞 P0（刷视频时界面卡死）、历史/最近小结空白、页面被带回首页后不恢复、切换视频后
   `TARGET_REPICK` 回到旧视频、评论「只输入没发出」谎报 `verified=true`、小红书评论脚本双大括号语法错误、
   小结白字不可读。
3. **桌宠几何**：浮层开着时右键不再重算几何（左上角跳）、收起态展开用「真实落定矩形」当锚点、
   Esc 关闭浮层走与点击外部同一条收尾路径（200ms 内收回）、双击也纳入不变量纠正。
4. **设置窗口**：创建后显式 `show + unminimize` 并复核可见性（重试 3 次），解决「创建了但不显示」。
5. **冷启动**：新增分步时间戳与 8s watchdog，卡死可定位且不阻塞主窗口显示。
6. **聊天与用量**：一次请求只记一条 usage（主尝试 + 重试合并）、模型名统一服务端 id、主动提示词基线随人设更新、
   设置页记忆条数改为挂载/更新时只解析一次（去掉渲染期 localStorage 读取）。

## 3. 数据位置变更（重要）
- **实机核对（2026-11-20）**：2.0.4 的默认 `data/` 实际未生效（数据仍写在旧位置），`E:\Maltese2\data` 未创建；默认 `data/` 与启动迁移自 **2.0.5 起生效**。

- 业务数据（聊天记录、待办、剪贴板、记忆、视频会话、Token 统计等）**默认根目录改为运行版安装目录下的 `data/`**，
  首次启动会把旧位置（系统盘用户目录）的数据迁移过去，并在原处留下说明。
- 想放到别的盘：在程序目录写 `data-dir.txt`（一行绝对路径）即可，重启生效。
- 迁移是**一次性**的；迁移后请不要再手工搬回去，否则会出现两套数据。

## 4. 体验

- 视频页：首屏更简洁（口味折叠），小结可读性提升，历史会话可展开；评论与气泡都在面板内可见。
- 控制台：新增 Agent 主视图（桌面 AI 应用 + 任务列表 + Token 卡片）。
- 设置：素材库数字口径中性化、记忆条数不再拖慢渲染、几何自检入口（设置 → 关于与更新附近）。

## 5. 已知问题

1. **小红书评论自动提交未通**：目前只到「占位入口 / 脚本异常」，提交结果如实报 `verified=false`，没有伪装成功；
   后续版本继续跟。
2. **设置窗口偶发创建后不显示**：已加 `show + unminimize` 复核与 3 次重试，仍偶发。
3. **冷启动间歇卡死**：已加 8s watchdog 与分步时间戳，问题可定位但不能保证消失。
4. **混合 DPI 未实测**：多屏不同缩放比例下的几何只做了静态换算与单屏实测。
5. **几何仍有偶发位移**：不变量兜底已挡住大部分，但根因（多真值 / 事件竞态）要等几何架构重构版。
6. 未做代码签名：SmartScreen 会提示「未知发布者」；部分带安全软件的机器上 NSIS 自解压可能报
   `Error writing temporary file`，可改用便携版 zip。
7. B 站评论发送仍受账号状态限制（未转正的账号站点侧会拒），面板会给出对应原因。

## 6. 安装与升级

| 方式 | 文件 |
| --- | --- |
| 安装包（推荐，支持应用内更新） | `Maltese-2.0.4-x64-setup.exe` |
| 便携版（解压即用） | `maltese-assistant-v2.0.4-win64.zip` |
| 插件（按需安装） | `billiards.zip` / `video-automation.zip` / `relationship.zip` / `hello-world.zip` |

- 安装包为 per-user 安装（写 `HKCU`，不需要管理员），`identifier` 仍是 `com.maolouis.maltese`，2.0.x 升级不换数据目录
  （2.0.3 → 2.0.4 首次启动会自动迁移数据，见第 3 节）。
- 便携版含 exe 与 `resources\assets\pets`（桌宠素材），**不含任何插件**；解压运行 `Maltese-assistant.exe`，
  插件到插件中心粘贴 zip 路径安装。
- 插件版本：`hello-world` 需要 `process` 能力声明（本版已补），旧版自定义插件若声明了可执行动作，
  请在其 `plugin.json` 补 `"capabilities": ["process"]` 后再安装。

## 7. 校验

- `SHA256SUMS-v2.0.4.txt` 给出 exe / 便携 zip / 安装包 / 4 个插件 zip 的 SHA-256。
- 安装包带 Tauri updater 签名（`.sig`），`latest.json` 里的签名与安装包一致，应用内更新可直接使用。
- 交付前跑 `scripts/verify-release-artifacts.ps1`，Defender 扫描无威胁。
