# Maltese v0.2.0

在 v0.1.0（打包重构、素材外置）基础上继续做**前端分离**与**架构规范性**，并补上守护脚本。

## 1. 前端分离：继续外置（第 2 步）

新增 `src-tauri/src/web_protocol.rs` + 自定义协议 `maltese`：

- `http://maltese.localhost/...` 由 Rust 从 `<资源目录>/web` 读取 index.html / JS / CSS / 字体；
- 只读、只允许 `web/` 内（路径规范化后校验，防目录穿越）；未知路径回 `index.html`（SPA 兜底）；
- MIME 覆盖 html / js / css / json / 字体（woff/woff2/ttf/otf）/ gif / webp / wasm；
- 默认构建不请求该协议，注册本身无副作用。

新增 overlay `src-tauri/tauri.external-web.conf.json`（一条命令切换外置模式）：

```powershell
pnpm build
node_modules\.bin\tauri.cmd build --config src-tauri\tauri.external-web.conf.json --bundles nsis
```

它会把 `dist` 装到 `resources/web`、12 个窗口 URL 换成 `http://maltese.localhost/...`，
并把内嵌产物缩成 `src-tauri/web-stub/index.html`（「资源缺失」提示页）。

## 2. 架构规范性：单模块预算 + 功能面守护

新增两个脚本（都能独立运行，失败退出码 1）：

| 脚本 | 内容 |
| --- | --- |
| `scripts/verify-architecture.mjs` | `App.tsx` 行数只降不升（当前预算 9161）、其它模块 ≤900 行、禁止反向 import `App.tsx`、输出最大 10 个模块 |
| `scripts/verify-parity.mjs` | 17 项能力锚点（桌宠动画、GIF 轮播、主动聊天/主动程度、聊天与思考、待办、剪贴板、音乐歌词、视频翻页、快捷入口与路径校验、插件与台球、固定标签、翻译、消息、更新链路、外置协议、打包卫生） |

本轮拆分：

- 设置面板的 6 个通用控件（Slider / Color / Toggle / AppearanceMode / Number / Locale）
  从 `App.tsx` 抽到 `src/uiControls.tsx`（190 行），`App.tsx` 9347 → **9161 行**。

`PinnedPanel.tsx` 仍依赖 `App.tsx` 里的 `AssistantPanel`，已登记为**已知债务**：
脚本会打印警告但不判失败，完成 `docs/architecture.md` §4 第 5 步后清零。
