# Maltese v1.3.23

## 修：浏览器播视频仍然显示歌词

上一版用系统媒体会话的 `PlaybackType` 区分音乐 / 视频，但浏览器（Chrome / Edge / Firefox）播视频时经常上报 `Unknown`、甚至直接报 `Music`，所以照样去搜歌词，看起来像没修。

这一版改成三道判定，任一命中就当作视频处理：

1. 系统明确上报 `Video` / `Image`；
2. **前台是浏览器，且这段媒体没有歌手信息**——浏览器播视频通常只有标题；`artist` 为空、或者是网站名（YouTube / bilibili / 哔哩哔哩 / Netflix / 爱奇艺 / 腾讯视频 / 优酷 / 抖音 / 微博 / Vimeo / Twitch）都算没有歌手；
3. 前台窗口类型已经是 `video`（B 站客户端、播放器、全屏视频页）。

为了拿到第 3 条，新增一个 10 秒轮询 `get_active_activity` 的轻量状态（只在前台类型变化时才更新界面）。

命中视频时统一生效：**不请求歌词**、不切「听歌」表情、不说「你也喜欢听《…》」。浏览器里放音乐（有歌手信息）仍然正常显示歌词。

## 验证

- `tsc --noEmit`、`vite build`、`cargo check` 通过。
- 本机安装后播浏览器视频，音乐卡不再出现歌词；播网易云 / 有歌手的网页音乐仍有歌词。
- 交付前按 [release-checklist](../release-checklist.md) 跑 `verify-release-artifacts.ps1`。

## 同时包含 v1.3.22 的修复

- **收起 / 隐藏快捷键失效**：两个全局快捷键只在启动注册一次，更新或自动重启时旧实例还没释放 `RegisterHotKey`，新实例注册失败就整场会话变哑。现在两个模块都记住目标组合键，失败后每 2 秒重试（最多 30 次），主窗口启动时也会注册保存的「显示 / 隐藏」组合键；录键时和另一个快捷键重复会被拦下。
