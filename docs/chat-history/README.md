## 怎么重新导出

仓库里留了一个导出脚本，只依赖 Node，读取 rollout 日志并输出 Markdown：

```bash
node scripts/recover-chat-history.mjs \
  --out docs/chat-history/2026-11-02-Maltese-主对话.md \
  --title "会话记录 · Maltese 桌面助手搭建（主线程）" \
  --note "同一线程的两个存档分片合并去重" \
  "$USERPROFILE/.codex/archived_sessions/rollout-2026-11-02T19-41-33-01a19c10-9178-70b1-8b9c-89db6a949c71.jsonl" \
  "$USERPROFILE/.codex/archived_sessions/rollout-2026-11-02T19-56-26-01a19c10-9178-70b1-8b9c-89db6a949c71_01a19c1e-2f94-7032-ad95-2e7760645609.jsonl"
```

脚本会跳过 `environment_context`、工具调用和加密的推理内容，只保留对话正文，并按 `时间戳 + 角色 + 正文` 去重，所以同一线程的多个分片可以一起传给 `--out`。
