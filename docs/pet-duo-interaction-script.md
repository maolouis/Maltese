# 小白 × 小鸡毛 双狗互动脚本（初版，给研发直接实现）

> 2026-11-17 · 版本 2.0.2（不改版本号）
> 目标：把「联动=随从换个 GIF」改成「两只狗有来有回地说话、有先后动作」，台词必须真的看得见。
> 依据：人设来自 [petCharacters.ts](../src/petCharacters.ts)（小白安静温柔细心、略害羞胆小；小鸡毛活泼黏人爱表现、直球）；联动总线 [petLinkBus.ts](../src/petLinkBus.ts)；随从 [CompanionPet.tsx](../src/CompanionPet.tsx)；Bongo [BongoPet.tsx](../src/BongoPet.tsx)。

## 1. 角色语气卡（Voice）

**小白（xiaobai）**
1. 短句为主，常用省略号起头或停顿（「……嗯。」「我先等等。」），不抢话。
2. 先看再应：先观察对方/主人，再给一句克制的回应；关心落在别人身上，不直说自己开心。
3. 害羞但有回应：可以退半步、让位置，但一定会接一句，不会冷场。

- 口头禅：「……嗯。」「没关系。」「我在这里。」「你先。」「我也……可以。」
- 忌用词：夸张感叹（「哇塞」「超」「必须」）、连串感叹号、网络热梗、命令句、长篇大论。

**小鸡毛（xiaojimao）**
1. 先点名再说话（「小白小白！」「主人主人！」），句子里带感叹或叠词。
2. 主动提议、要一起：爱表现、直球，先做动作后解释（先蹦过去再喊）。
3. 情绪外放但不讨厌：抢镜、黏人，最后一定把小白拉进来（「一起嘛！」）。

- 口头禅：「小白小白！」「好耶！」「一起嘛～」「看我看我！」「等等我！」
- 忌用词：书面连接词（「然而」「因此」「综上」）、冷淡词（「随便」「无所谓」）、长句、消极丧气话。

## 2. 谁是谁：说话归属与随从身份

| 主狗形象 | 主狗身份 | 随从 1 身份 | 随从 2 身份 | 台词策略 |
| --- | --- | --- | --- | --- |
| `xiaobai` | 小白 | 小鸡毛（优先） | 小鸡毛 | 小白通常后说/短句；小鸡毛先说/主动 |
| `xiaojimao` | 小鸡毛 | 小白（优先） | 小白 | 小鸡毛先说；小白用短句回应 |
| `duo`（主狗同框） | 小白+小鸡毛 | 小白 / 小鸡毛 交替 | 另一只 | 主狗台词标 `speaker` 随机取一人，随从补另一人，保证成对 |

- **必须区分身份**：随从窗口当前渲染的是主狗形象（同一 `usePetCharacter`），需新增 `resolveCompanionCharacter(label, mainCharacter)`：`companion-奇数 → 小白`、`companion-偶数 → 小鸡毛`；若与主狗重复则交换。用返回值作为 `rotationFramesForState(..., character)` 的角色参数，台词与 GIF 才对得上。
- 一句台词 = 一个 `speaker`（`xiaobai` / `xiaojimao` / `main`）+ 一句文本；主狗说的显示在主狗头顶，随从说的显示在该随从窗口头顶。

## 3. 互动桥段（7 个，按触发场景）

> 每组台词 ≤18 字、必须一问一答来自不同角色；每场景给 3 组备选（随机 + 最近 5 条不重复）。动作节拍要求「先后差 ≥120ms」，不允许两只狗同一帧一起播同一个 GIF。

**S1 摸头（主狗被摸 `pet`）** — 最高频，优先实现
① 毛：「小白小白！主人先摸我了！」→ 白：「……嗯。我排队。」
② 毛：「摸摸头，分你一半！」→ 白：「……那，我靠近一点点。」
③ 毛：「主人手好暖！」→ 白：「别挤……我也在。」
- 节拍：小鸡毛先向主狗方向位移 8–16px（现有 shift）并播 `pet` → 120ms 后小白播 `pet` 但不位移、只放大 0.6s → 2.6s 一起回 idle。
- 人设：毛抢镜直球、白克制但不拒绝；互动关系=「抢—让—靠近」。
- 素材：无 pet 同框素材，用两个窗口各自 GIF；位移方向朝向主狗（`linkMessage.origin`）。

**S2 喂食（主狗 `eating`）**
① 白：「你先吃，我不急。」→ 毛：「那我吃一半，留一半给你！」
② 毛：「好吃！小白快尝！」→ 白：「……留着吧。我闻闻就好。」
③ 白：「慢点，别噎到。」→ 毛：「知道啦！你也吃一口嘛！」
- 节拍：小鸡毛先播 `eating` 并前倾 8px → 300ms 后小白播 `eating`，同时**后退 4px 再在 1.2s 内靠回**（让食）→ 收尾两只同时 `happy` 0.6s。
- 人设：毛贪吃但记得分享；白把「让」做成动作，不靠台词说教。

**S3 开心 / celebrate（主狗 `happy` / `celebrate`）**
① 白：「今天……好像不错。」→ 毛：「超不错！转圈圈！」
② 毛：「好耶！一起跳！」→ 白：「……就一下下。」
③ 白：「嗯。就这样待着吧。」→ 毛：「那我陪你转一圈！」
- 节拍：celebrate 时主狗播同框转圈（`spin`/`hop` 有 `shared` 同框素材）；小鸡毛 120ms 后播 `spin`，小白只轻跳 `hop`（不转）；800ms 后小白回到主狗身边位置。
- 人设：毛外放、白含蓄；动作差异（转圈 vs 轻跳）就是人设差异。

**S4 Bongo 敲击（Bongo 空格按键）** — 唯一双向，优先实现
① 毛：「咚！我也敲！」→ 白：「……小声一点。」
② 白：「吵到主人了。」→ 毛：「那、那轻一点咚……」
③ 毛：「听！节奏！」→ 白：「……我听到了。」
- 节拍：Bongo 先切 `space` 帧 + 560ms 缩放脉冲 → 450ms 内小鸡毛 `hop` 回应 → 小白 `peek` 并轻微放大，不位移；主狗同时 `happy` 1.2s。
- 人设：毛跟节奏、白嘴上嫌吵但没走开（留在原地就是回应）。

**S5 久坐提醒（待办计时 / 整点提醒触发）**
① 白：「主人坐好久了……」→ 毛：「起来动动！我带路！」
② 毛：「走啦走啦！」→ 白：「……我陪着走到窗边。」
③ 白：「腰会酸的。」→ 毛：「那我来当闹钟！」
- 节拍：小白先 `peek` 看主人 2s（不位移）→ 小鸡毛 `hop` 并向屏幕中间位移 12px → 主狗云朵气泡与小白台词同帧、毛的台词错峰 120ms。
- 人设：白细腻观察、毛行动派；台词分工=「提醒 + 拉人」。

**S6 晚上告别（夜间首次进入 23:00 / 主狗准备缩边睡觉）**
① 白：「灯关小一点……晚安。」→ 毛：「明天还要一起玩！」
② 毛：「今晚也要梦到骨头！」→ 白：「……梦到你，就够了。」
③ 白：「晚安。」→ 毛：「明天见，小白！」
- 节拍：主狗先说话并播 `sleep` 前摇（暂不 tuck）→ 250ms 后小鸡毛 `peek` + 轻跳 0.8s、**不播 sleep** → 3s 后主狗才缩边。
- 边界：缩边/睡眠态默认不联动；本场景是「缩边前一次性节目」，播完立即进入静默，随从不跟着睡。

**S7 主人离开又回来（前台闲置恢复 / 切回桌面）**
① 毛：「你回来啦！！」→ 白：「……欢迎回来。」
② 白：「刚还在想，你会不会回来。」→ 毛：「我一直在窗口看！」
③ 毛：「等你超久了！」→ 白：「其实……我也在等。」
- 节拍：小鸡毛先 `hop` 向屏幕前沿位移 16px → 小白 200ms 后 `peek` 探头、放大 0.6s；停下后两只都回 idle。
- 人设：毛先炸、白后暖；一个动一个静。

## 4. 台词气泡落位规格（含当前「看不到台词」的原因）

**当前为什么看不到（读代码判断）**：[DesktopExtras.css:96](../src/DesktopExtras.css) 的 `.companion-pet__bubble` 用 `position:absolute; bottom:100%`，而父容器 `.companion-pet` 是 100% 窗口高（200×180），所以气泡被放到了**窗口顶部之外**；再被 [DesktopExtras.css:8](../src/DesktopExtras.css) 的 `html,body,#root { overflow:hidden }` 和窗口矩形裁掉 → 永远画不出来。次要原因：`PET_LINK_BUBBLE_MS=1200` 太短、只有随从有台词、Bongo 完全没有台词、台词是通用句不是角色对话。

**研发按这个规格改**：

| 项 | 规格 |
| --- | --- |
| 位置 | **说话的那只狗自己的头顶**：随从气泡放在该随从窗口**内部**顶部（`position:absolute; top:2px; left:50%; transform:translateX(-50%)`），不再用 `bottom:100%`；主狗台词复用现有云朵气泡，贴主狗上方。 |
| 尺寸 | 宽 ≤160px；2 行内自动换行（`white-space:normal`）；字号 **11–12px**、行高 1.25–1.35；白底 #ffffff、字色 #2b2f3a、圆角 10px、`z-index` 高于小狗图。 |
| 时长 | 显示 **1.6–2.2s**（建议 1800ms±200ms），进场 140ms、退场 120ms 淡出；同一窗口同时最多 1 个气泡。 |
| 节拍 | 主狗与随从各说各的话，**先说的先显示，错峰 ≥120ms**；全局同时最多 2 个气泡。 |
| 不打架 | 气泡挂在窗口容器层，不能加在会 `transform` 位移的 `<img>` 上；随从位移/缩放时气泡不跟着抖；不写聊天记录、不触发主动聊天冷却与云朵 TTL。 |
| 大缩放 | 随从 `scale` 1.8 时图高会超过 180px 窗口：气泡仍钉在窗口顶部并置顶，允许压住狗头顶，不允许出窗口。 |

## 5. 没有随从时怎么办（任何配置都有「对话感」）

| 配置 | 剧本（≤2 句，仍要不同角色） | 动作节拍 |
| --- | --- | --- |
| A. 只有小白（`petCount=1`、Bongo 关） | 白：「……今天也辛苦啦。」→ 白（第二句可内心独白）：「我去旁边趴一会儿。」 | `peek` 1.2s → `relax` 1.6s；无位移，气泡 1.8s；用「自问自答」补对话感 |
| B. 小白 + Bongo（无随从） | 白：「有人陪，真好。」→ 白：「……你也是这么想的吧。」（Bongo 用敲击回应，不出字） | Bongo 先敲 2 下（间隔 250ms）→ 主狗 `happy` 1.2s → 主狗第二句气泡在第二下敲击后 120ms 出现 |
| C. 小白 + 小鸡毛（有随从，默认多狗） | 毛：「小白小白！」→ 白：「……嗯，我在。」 | 毛 `hop` 先动 → 白 `peek` 后应；成对台词，错峰 120ms |

- B 场景 Bongo 不显示文字（它是键盘狗、不是说话者）；如果一定要有「回应文字」，只在主狗气泡里用「咚。」收尾，不新增 Bongo 气泡 UI。
- A 场景没有第三个角色，允许主狗连说两句，但第二句必须换语气（自我回应），不能复读。

## 7. 台词库与去重（避免「几句来回念」）

- 每个场景 **≥3 组**备选（本文 S1–S7 各 3 组，共 21 组）；新增场景同样至少 3 组。
- 选择规则复用 `proactiveChat` 的思路：按场景抽一句，**最近 5 条说过的组不重复**（`localStorage["maltese-pet-link-history"]`，只存句子 hash，滚动保留 20 条，不落聊天记录）。
- 优先级：场景内未说过 > 最久未用；同一次联动里两只狗必须来自同一组（一问一答成对），不允许跨组拼接。
- 台词文案放 i18n：`petLink.scenes.<sceneId>`（`{ speaker, line }[]`，中英各一份），**不要硬编码在组件里**。
