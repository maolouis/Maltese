# 键盘操作快捷入口

按设置里的「快捷面板热键」打开快捷入口后，焦点会自动落到「搜索应用名称添加」输入框。输入电脑上能查找到的软件名称后：

- 按 **Enter**：直接启动第一个匹配的软件；
- 按 **↓**：进入匹配结果，聚焦结果后按 **Enter** 直接启动；没有搜索结果时会进入第一个快捷卡片；
- 使用 **Tab / Shift+Tab**：继续在快捷卡片、设置控件和搜索控件之间移动；
- 鼠标点击结果仍然保留原来的「添加到快捷入口」行为。

搜索结果同时包含桌面/开始菜单中的文件入口和 Windows 登记的 Microsoft Store / MSIX 应用，启动仍由现有的原生 ShellExecute / AppsFolder 命令处理。
