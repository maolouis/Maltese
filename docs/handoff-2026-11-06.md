## 还没做完的两件事

### 1. `.cmd` 快捷方式点了打不开（用户报的 `F:\Qwen3.6-35B-A3B\start-qwen36.cmd`）

怀疑点：`launch_custom_shortcut` / `launch_discovered_shortcut` 调用 `Path::canonicalize()`，
Windows 返回扩展长度路径 `\\?\F:\...`；1.3.2 起 `launch_canonical_path` 把该路径交给
`ShellExecuteW`，而 ShellExecute 对 `\\?\` 前缀通常报文件不存在（旧实现走 `cmd /C start` 时能容忍）。

下一步：

1. 在 `src-tauri/src/lib.rs` 里加一个规范化函数：`\\?\UNC\server\share` → `\\server\share`，
   `\\?\C:\...` → `C:\...`；`shell_execute()` 使用去掉前缀后的路径。
2. 复现验证：写一个只写标记文件的 `probe.cmd`，分别用带/不带 `\\?\` 前缀 `Start-Process`
   测试，确认前者失败后者成功。
3. 改完跑 `cargo check`，再发 1.3.6；顺带确认 `.lnk`、`.bat`、`.ps1`、`.py` 四种入口都能打开。

### 2. 聊天改成「两只小狗一起聊」

聊天时两只一起回应。

  「小白：」和「小鸡毛：」各说一句，总计不超过 3 句。

## 常用命令与坑

```powershell
# 前端 / 类型检查
node node_modules\typescript\bin\tsc --noEmit
# 构建（TEMP 必须指到工作区，否则 esbuild 删临时文件会被拒）
$env:TEMP="E:\Maltese\.tmp-build"; node node_modules\vite\bin\vite.js build
# Rust 检查
cd src-tauri; cargo check
# 安装最新版（绕开 SmartScreen，且会先结束旧实例）
powershell -ExecutionPolicy Bypass -File scripts\install-latest.ps1
```

- 签名环境：`%USERPROFILE%\.tauri\maltese\` 下的 `updater.key`、`updater.key.pub`、`password.txt`；
  `TAURI_SIGNING_PRIVATE_KEY` 要传**文件内容**（base64），不是路径。
- git 推送需要 `-c http.sslBackend=schannel`（默认 SSL 后端证书报错）；curl 需要 `--ssl-no-revoke`。
- 用 PowerShell 写 JSON/TS 会带 BOM：`tauri.conf.json` 带 BOM 会让构建脚本解析失败，提交前用
  UTF-8 无 BOM 重写；`.ps1` 反而必须是 UTF-8 **带** BOM，否则 PowerShell 5.1 按 GBK 读中文会语法错误。
- 发布走 `docs/release-checklist.md`：版本三处一致 → 构建 → 文档 → `verify-release-artifacts.ps1`
  → 上传附件 → 校验 `latest.json`。
- GitHub token 是用户私发的，没写进任何文件；建议提醒用户轮换。
