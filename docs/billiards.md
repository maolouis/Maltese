# 桌面图标台球（和小狗一起玩）

把 Windows 桌面上的**真实快捷方式图标**当成台球：开局摆成三角球阵，你拉杆击球，图标会在桌面上滚动、碰撞、入袋；退出后桌面恢复原样。

## 入口

**插件页 →「桌面图标台球」→ 和小狗开一局**。需要桌面图标处于显示状态。

## 玩法

- 开局读取每个图标的原始位置，把它们摆成三角球阵，并记录备份；
- 你打一杆：按住左键从白球往后拉杆（拉得越远力度越大），松手击球；
- 轮到小狗：它把白球位置、六个球洞、剩余球编号发给**本机模型**，让模型挑打哪颗、用多大力，
  再本地算「幽灵球」瞄准点出杆；模型不可用时退回几何最优解；
- 白球落袋算犯规（回开球点，本杆不计分）；
- 顶部条：回合 / 比分 / 剩余 / 用时 / 重开 / 退出；`R` 重开，`Esc` 退出并恢复桌面。

## 安全设计

搬动真实图标有风险，所以：

1. 开局把每个图标的原始位置写进内存**并**备份到 `%APPDATA%\maltese\billiards-backup.json`；
2. 退出 / 关闭窗口 / 页面卸载都会恢复；
3. **应用启动时**如果发现备份文件还在（说明上次没正常退出），先把图标位置改回来再删除备份；
4. 桌面若开着「自动排列 / 对齐到网格」，临时关掉并在退出时还原，否则图标会被立刻吸回原位。

## 实现

- `src-tauri/src/desktop_icons.rs`：
  - `desktop_icons_begin_game`：找到 `Progman/WorkerW → SHELLDLL_DefView → SysListView32`，
    用 `LVM_GETITEMCOUNT` / `LVM_GETITEMPOSITION` / `LVM_GETITEMSPACING` 读数量、位置、格距，写备份、关吸铁石样式；
  - `desktop_icons_move`：把一批「图标编号 + 屏幕坐标」批量 `LVM_SETITEMPOSITION` 到真实图标；
  - `desktop_icons_restore`：按备份还原并清理备份文件；
  - `restore_desktop_on_startup`：启动兜底。
- `src/Billiards.tsx`：物理（摩擦、库边反弹、球球碰撞、六洞入袋）、瞄准与力度、
  小狗回合（模型算球 → 幽灵球瞄准）、每 40ms 把球位置同步给真实图标。

## 已知限制

- 桌面图标被隐藏时无法开玩（插件卡片会提示）。
- 搬动图标依赖向 explorer 桌面窗口发跨进程消息；某些系统策略 / 安全软件会拦截
  （返回 `ERROR_ACCESS_DENIED`）。拦截时**不会动任何图标**，直接报错，桌面保持原样。
- 只覆盖主显示器；最多取 45 个图标。
