## 3. 2.0.2 做了什么

| 提交 | 内容 |
| --- | --- |
| `a709fd0` | 桌面图标开局闸门（`GAME_ACTIVE`）；台球拆独立插件；应用搜索/打开改缓存 + async |

- **issue #1 根治**：`desktop_icons_restore` 以前会退回读备份文件，窗口挂载/卸载、应用启动都可能搬图标。
  现在 `desktop_icons_move` 未开局直接返回、`desktop_icons_restore` 未开局不读备份文件；
  只有 `desktop_icons_begin_game()` 成功才置位 `GAME_ACTIVE`。崩溃兜底仍由
  `restore_desktop_on_startup()` 负责（只执行一次）。
- **台球是插件**：`examples/plugins/billiards/plugin.json`（`ui: host`），插件中心不再内置台球卡片；
  「打开」走 `open_billiards_window` 覆盖桌面的独立窗口。zip 由 `scripts/pack-plugins.ps1` 一起产出。
- **快捷入口不卡**：`discover_installed_apps` 清单缓存 10 分钟、搜索只做内存过滤；
  `discover_start_apps` 同样缓存；`discover_*` / `get_shortcut_icon` / `launch_*` 全部 async，
  不再堵 Tauri 主线程。

## 5. 构建与发布（本机复制即用）

```powershell
$env:PATH = "E:\Git\bin;$env:PATH"          # git 不在默认 PATH
$env:TAURI_UPDATER_PUBKEY = (Get-Content "$env:USERPROFILE\.tauri\maltese\updater.key.pub" -Raw).Trim()
$env:TAURI_SIGNING_PRIVATE_KEY = (Get-Content "$env:USERPROFILE\.tauri\maltese\updater.key" -Raw).Trim()
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = (Get-Content "$env:USERPROFILE\.tauri\maltese\password.txt" -Raw).Trim()
node scripts/prepare-release-config.mjs     # 生成 src-tauri\tauri.release.conf.json（pubkey + createUpdaterArtifacts）

# 本机 esbuild 被安全软件限制：pnpm build / vite 压缩都会 Access denied。绕法：
node_modules\.bin\tsc.cmd
node_modules\.bin\vite.cmd build --target esnext --minify false
$esb = "node_modules\.pnpm\@esbuild+win32-x64@0.28.1\node_modules\@esbuild\win32-x64\esbuild.exe"
# 对 dist\assets 下每个 js/css：& $esb <file> --minify --outfile=dist\assets\__min_<name>，再 Move-Item -Force 覆盖。
# 输出必须写在 dist\assets；写 E:\MalteseWork\tmp 会被拒。
# 然后手工往 tauri.release.conf.json 注入 "build": { "beforeBuildCommand": "" }，复用现有 dist。

node_modules\.bin\tauri.cmd build --ci --config src-tauri/tauri.release.conf.json --bundles nsis
node scripts/make-latest-json.mjs --notes-file docs/releases/v<ver>.md
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\pack-plugins.ps1   # dist-plugins\ 4 个 zip
# 组装 release\v<ver>（setup / sig / latest.json / exe / 4 zip）+ 便携 zip + SHA256SUMS
powershell -File scripts/verify-release-artifacts.ps1 <7 个二进制路径>
```

发布走 REST（本机没有 `gh`）：`POST /repos/maolouis/Maltese/releases`（`draft=true`，body 取
`docs/releases/v<ver>.md`）→ `POST https://uploads.github.com/.../releases/<id>/assets?name=<文件>`
逐个上传并核对 `state=uploaded` + `digest` → `PATCH /releases/<id>` 置 `draft=false` / `make_latest=true`。

## 7. 已知问题 / 未验证项

1. **未做代码签名**：SmartScreen 提示「未知发布者」；带 Smart App Control 的机器上，未签名安装器
   可能被应用程序控制策略拦（`os error 4551`）。方案见 `docs/distribution.md`。
2. **本机安装器跑不起来**：NSIS 自解压被拦，`/S` 与 UI 都退出码 2 +「Error writing temporary file」；
   本机升级只能文件级覆盖，卸载项版本号会与实装 exe 不一致。
3. **OTA 未在本机实拉**：CDN 直连不通，只验证到 API 侧 latest=v2.0.2、`latest.json` 在资产列表、
   签名与 `.sig` 本地一致。
4. **external-web overlay 未实机验证**（`tauri.external-web.conf.json`，白屏风险，需单独提交验证）。
5. **`App.tsx` 仍 8817 行**（预算 9161，只降不升），下一步按 `docs/architecture.md` 顺序拆模块。
6. **插件必须手动装**：应用不预置任何插件；新机器要先从 Release 下载对应 zip 再在插件中心安装。
7. `src-tauri\src\local_chat.rs` 的 `STRATA_LAUNCHER` 仍是本机写死路径（`F:\Strata\bin\strata.cmd`），
