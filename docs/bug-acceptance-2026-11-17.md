# 回归验收标准（产品口径）· 2026-11-17

> 对象：`c327044`「多实例启动 P0/P1 修复」之后出现的两个回归
> B1 设置打不开 · B2 气泡点开后小狗会移动
> 角色：产品（product-acceptance）；版本仍为 **2.0.2**，不升版本号、不 push、不打 tag。
> 用法：研发修完后按本清单逐条执行；每条用例先按「Given / When / Then」走一遍，再按「失败信号」判定。
> 同一个用例两次执行失败，即判定该用例失败（不排期重跑第三次）。

## 0. 通用约定

### 0.1 环境与构建

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 实机，WebView2 运行时已安装（用户机器默认状态） |
| 构建 | 优先 `pnpm tauri dev`；再用 `src-tauri/target/debug/maltese-assistant.exe` 复跑 B1/B2 主用例；发布前用 `pnpm build` + `pnpm tauri build --no-bundle` 的产物再跑一遍 |
| 显示基线 | 单显示器 1920×1080、缩放 100%、任务栏在底部 |
| 加分环境 | 150% 缩放、双屏各跑 B1-01 / B1-04 / B2-01 / B2-09 |
| 起始状态 | 设置保持默认（气泡开关、剪贴板气泡、主动气泡均为开）；小狗处于收起态；每轮开始前关闭设置/插件/台球/翻译等窗口，保证「首次打开」是真正的冷打开 |
| 计时口径 | 从鼠标点击到「窗口可见且内容绘制完成」；用录屏（30fps 足够）或秒表，允许 ±200ms 误差 |

### 0.2 判定口径

- **打开成功**＝窗口可见 + 标题正确 + 内容完整可交互 + 没有白屏/半透明空块/只有边框。
- **聚焦而非新建**＝系统里同标题窗口数量始终为 1，重复点击后该窗口从后台回到前台并获得焦点，不出现第二个任务栏按钮。
- **位置误差 ≤2px**＝按 100% 缩放下的物理像素计；150% 缩放下放宽到 3px（≈2 逻辑 px）。基准是**主窗口矩形**：收起态小狗槽贴在窗口左下角，窗口左下角即小狗屏幕位置（见 [pet-overlay-geometry.md](pet-overlay-geometry.md) 不变量 1）。
- **气泡完全展开/关闭完成**＝尺寸变化结束并稳定 ≥500ms 后再测量，不允许拿中间帧数值充数。
- **P0** 阻断日常使用，必须全过；**P1** 影响体验，必须全过才算可交付；**P2** 记录项，不阻断但必须写进修复记录。

### 0.3 取证工具（只读，不改任何文件）

B2 的位置判据建议直接量窗口矩形。在**测试机**的 PowerShell 里跑下面这段（已在本机验证可输出；只读枚举窗口，不修改系统）：

```powershell
Add-Type @"
using System; using System.Text; using System.Runtime.InteropServices;
public static class Win {
  public delegate bool EnumProc(IntPtr h, IntPtr l);
  [DllImport("user32.dll")] public static extern bool EnumWindows(EnumProc cb, IntPtr l);
  [DllImport("user32.dll")] public static extern bool IsWindowVisible(IntPtr h);
  [DllImport("user32.dll")] public static extern int GetWindowText(IntPtr h, StringBuilder s, int n);
  [DllImport("user32.dll")] public static extern bool GetWindowRect(IntPtr h, out RECT r);
  [StructLayout(LayoutKind.Sequential)] public struct RECT { public int Left, Top, Right, Bottom; }
}
"@
$rows = [System.Collections.Generic.List[string]]::new()
[void][Win]::EnumWindows({ param($h, $l)
  $sb = New-Object System.Text.StringBuilder 256
  [void][Win]::GetWindowText($h, $sb, 256)
  $title = $sb.ToString()
  if ($title -eq "Maltese 线条小狗桌面助手" -or $title -eq "Maltese · 桌宠设置") {
    $r = New-Object Win+RECT
    [void][Win]::GetWindowRect($h, [ref]$r)
    $rows.Add(("{0} | visible={1} | left={2} top={3} right={4} bottom={5}" -f $title, [Win]::IsWindowVisible($h), $r.Left, $r.Top, $r.Right, $r.Bottom))
  }
  $true
}, [IntPtr]::Zero)
$rows
```

- 窗口标题固定：主窗口 `Maltese 线条小狗桌面助手`；设置窗口 `Maltese · 桌宠设置`。不要用 `-like "*Maltese*"` 模糊匹配（会把资源管理器里含 Maltese 的文件夹也匹配进来）。
- 每跑一次输出 1～2 行：`visible` 表示是否可见，`left/top/right/bottom` 供直接做 ≤2px 比对。**隐藏的窗口也会被列出**（`visible=False`），这是有意义的证据（例如设置窗口只隐藏未销毁）。
- 用法：B2 每个用例在「打开前 / 完全展开后 / 关闭稳定后」各跑一次，把数值抄进附录 A 的表；主窗口 `visible=False` 一律算失败。
- 设置窗口矩形会含标题栏与边框（内尺寸 560×780，外部矩形约 576×819），**不要拿外部矩形断言 560×780**；判 B1 只判「窗口存在 + visible=True + 内容可交互」。
- 2px 容差本身可以吸收 DWM 边框/缩放带来的 1px 级差异。

## 1. B1 设置打不开

### 1.1 用户视角现象

**一句话**：点「设置 / 配置桌宠」之后，设置窗口不出现——没有任何反应、或闪一下就消失、或出现一块空白窗口，配置项改不了。

**影响面**：

| 入口 | 使用频率 | 失效后的后果 |
| --- | --- | --- |
| 展开面板顶部导航「设置」 | 高（配置主入口） | 形象、气泡、布局、快捷键、自启、全屏避让全部不可达 |
| 快捷面板（快捷入口页）右上角「设置」 | 中 | 同上，且提示语会把用户引到不存在的「桌宠右键菜单」 |
| 托盘右键「配置桌宠」 | 中，但**小狗隐藏到托盘时是唯一入口** | 狗不可见时彻底无法配置 |
| 独立气泡窗口菜单「配置桌宠」 | 低（当前 UI 无到达路径，见 1.2） | 本轮不作为必测 |

**频率与严重度**：点击即现或「关掉后再开必现」；属于**配置能力整体不可用**，判 **P0**。前端有两条 fallback（岛内跳到「布局」页 / 弹一条提示），fallback 能用不等于 bug 不存在——验收必须区分「真的打开了设置窗口」和「退回了 fallback」。

| --- | --- | --- | --- |

### 1.3 验收清单（Given / When / Then）

**B1-01（P0）冷开设置——岛内入口**
- Given：应用刚启动；本进程内设置窗口从未打开过；小狗处于收起态。
- When：双击小狗展开面板 → 点顶部导航「设置」。
- Then：≤3s 出现独立窗口，标题「Maltese · 桌宠设置」，内尺寸 560×780（首次创建居中）、可缩放且不小于 460×560；内容完整（分组、开关、滑块、形象轮播图可见可点）；主窗口**不会**跳到岛内「布局」页。
- 失败信号：无窗口 / 超过 3s / 空白或半透明空块 / 只有边框 / 岛内跳到布局页 / 点击无任何反应。

**B1-02（P0）冷开设置——快捷入口页**
- Given：同 B1-01 起始状态。
- When：展开面板 → 切到「快捷入口」页 → 点右上角「设置」。
- Then：与 B1-01 相同；页面右上**不出现**「设置窗口打开失败，可在桌宠右键菜单里重试」提示。
- 失败信号：同 B1-01，或出现失败提示。

**B1-03（P0）设置——托盘入口（含隐藏态）**
- Given：收起态，设置窗口未打开；随后用托盘「隐藏到托盘」让小狗消失。
- When：分别在小狗可见时、隐藏后，托盘右键 →「配置桌宠」。
- Then：两次都能打开设置窗口且可交互；隐藏态打开设置**不要求**小狗出现；关闭设置后小狗仍保持隐藏（隐藏状态不被改变）。
- 失败信号：任一状态打不开 / 打开后小狗被强行显示 / 托盘无响应。

**B1-04（P0）重复点击应聚焦，而不是新建**
- Given：设置窗口已打开且可见；先点到别的应用上，让它失去焦点。
- When：从任一入口再点一次；重复 5 次，每次间隔 1s（中途可点任务栏切走）。
- Then：系统里「Maltese · 桌宠设置」窗口**始终只有 1 个**；每次点击窗口被带到前台并获得焦点；任务栏不新增按钮；窗口内滚动位置/表单输入不被重置。
- 失败信号：出现第二个设置窗口 / 第二个任务栏按钮 / 窗口没被提到前台 / 每次点击都重新加载（内容闪回默认值）。

**B1-05（P0）关闭后可再次打开**
- Given：设置窗口已打开；改一项即时生效的设置（例如「气泡停留时长」6s→8s，本窗口无保存按钮，改完即生效）。
- When：点窗口 X 关闭（预期只隐藏不销毁）→ 从托盘再次打开；循环 3 次。
- Then：每次 ≤2s 重新出现；刚才改的值仍在；关闭后不残留可见的空白/半透明窗口；不产生新的 WebView 进程。
- 客观佐证（0.3 脚本）：关闭后仍能列出 `Maltese · 桌宠设置` 且 `visible=False`；再次打开后 `visible=True` 且左右上下位置与关闭前一致（说明是复用而非重建）。
- 失败信号：关闭后再也打不开 / 每次重开都变慢且从零加载 / 改动被重置 / 有残影。

**B1-06（P0）与小狗显示状态解耦**
- Given：先用托盘「隐藏到托盘」让小狗消失。
- When：托盘「配置桌宠」。
- Then：设置窗口正常出现且可交互；关闭设置后小狗仍隐藏（复位显示需用户显式操作）。
- 失败信号：狗隐藏时设置打不开 / 打开设置把狗一起叫出来且关设置后不回隐藏态。

**B1-07（P1）首次打开耗时（懒加载窗口）**
- Given：冷启动完成、小狗可见；设置窗口从未打开。
- When：首次打开（B1-01）→ 关闭 → 再打开。
- Then：首开 ≤3s；第二次起 ≤800ms；重复开关 5 次后任务栏窗口数、进程数不增长（复用同一窗口）。
- 失败信号：首开 >5s / 每次打开都像第一次（重新创建 WebView）/ 窗口数量增长。

**B1-08（P1）其它入口（如本轮新增）**
- Given：修复若引入快捷键、桌宠技能「调设置」、气泡内设置入口等。
- When：逐个触发。
- Then：行为与 B1-01/B1-04 一致，不允许「部分入口能开、部分不能」。
- 失败信号：任一入口静默失败或退回 fallback。

**B1-09（P1）失败反馈不得误导**
- Given：人为制造打开失败（研发自测：临时注入错误/断点即可，不要求测试同学制造）。
- When：从任一入口触发。
- Then：前端给出**有效**反馈（岛内布局页或明确提示）；提示语不能指向已经不存在的「桌宠右键菜单」（现在右键小狗是打开聊天页）。
- 失败信号：静默无反应 / 提示用户去做一步现在做不到的操作。

**B1-10（P2）多显示器 / 缩放**
- Given：150% 缩放，或把小狗放在副屏。
- When：B1-01、B1-04。
- Then：窗口完整落在当前屏幕工作区内，不超出屏幕，不被 DPI 撑得过大或模糊；重复点击仍聚焦。
- 失败信号：窗口一半在屏幕外 / 出现在错误显示器 / 尺寸异常。

### 1.4 取证

每次失败记录：时间、入口、5s 录屏、0.3 脚本的 `rect/visible` 输出、是否出现 fallback（岛内布局页 / notice 文案）、任务栏窗口数量。

## 2. B2 气泡点开后小狗会移动

### 2.1 用户视角现象

**一句话**：鼠标一碰小狗弹出互动气泡（或收到消息云朵、右键气泡），小狗就在屏幕上偏移；关掉气泡也不回原位，反复开合会一次比一次漂。

**影响面**：

| 场景 | 触发方式 | 频率 | 后果 |
| --- | --- | --- | --- |
| 悬停互动面板 | 鼠标移入小狗即弹 | 每天高频 | 最影响手感，狗「自己跑掉」 |
| 云朵消息气泡 | QQ/微信/邮件预览、剪贴板摘要、更新提示、听歌、整点提醒、主动聊天 | 每条消息一次 | 位置逐次漂移，越用越偏 |
| 右键入口 | 右键小狗（当前版本进聊天页；若本轮恢复右键气泡菜单则按气泡测） | 中 | 展开/回落同样偏移 |
| 关闭气泡回落 | 移开鼠标（420ms 后）、云朵 TTL 到期、点气泡内入口 | 每次关闭 | 回不到原位，需手动拖回 |

**严重度 P0**：气泡是核心交互，视觉抖动明显且位置漂移会累积，同时直接违反既有不变量文档 [pet-overlay-geometry.md](pet-overlay-geometry.md)。

### 2.2 验收依据：不变量与几何判据

**不变量（来自既有文档，本轮回归等于破坏它们）**：
1. 打开浮层只允许改窗口宽高，**不允许移动小狗**；向右展开原点不变，向左展开窗口左移 `phys_w - base_w`，CSS 把小狗钉在窗口右侧，两者抵消。
2. 前端必须「先 `plan_island_overlay` 拿方向 → `flushSync` 钉住小狗 → 再 `set_island_overlay` 一次设矩形」，两侧用同一份输入。
3. 关闭时先按快照原样恢复矩形；只有浮层期间尺寸设置真的变了才重算几何。
4. 纯竖直的缩边/唤醒落定允许落定；**带横向位移（闲逛）不允许落定**，否则小狗被拽到动画终点。

**几何判据（可用 0.3 脚本直接量）**：

设收起态基线矩形 `R0 = (left, top, right, bottom)`，打开后 `R1`，关闭并稳定 500ms 后 `R2`：

| 面板方向 | 打开后必须保持的那条边 | 容差 |
| --- | --- | --- |
| 面板在右 | `R1.left == R0.left` | ±2px |
| 面板在左 | `R1.right == R0.right` | ±2px |
| 面板在上 | `R1.bottom == R0.bottom` | ±2px |
| 面板在下 | `R1.top == R0.top` | ±2px |

- `R2` 与 `R0` 的 `left/top/right/bottom` 各 ≤2px。
- 连续 10 次开合后 `R2(10)` 与 `R0` 各边 ≤2px（**不允许累积漂移**）。
- 打开时窗口必须完整容纳面板：面板四边留白可见，最后一行按钮/文字不被窗口边裁切。

**视觉判据（QA 手工）**：30fps 录屏逐帧看打开、关闭两帧，小狗不出现横向/纵向跳动；关闭后截图与打开前叠图，肉眼看不出偏移。

### 2.3 验收清单（Given / When / Then）

**B2-01（P0）悬停互动面板（默认朝右）**
- Given：收起态；小狗在屏幕中左（左右各留 ≥400px）；跑脚本记录 `R0`。
- When：鼠标移入小狗 → 等气泡完全展开（≤500ms）→ 记录 `R1` → 鼠标移到气泡上停 1s → 移开 → 等自动收起（420ms 后）→ 稳定 500ms 记录 `R2`。
- Then：几何判据（面板在右）通过；面板完整（15 个互动按钮 + 待办/音乐状态 + 链接行 + 2 个底部按钮，超高可滚动）；云朵尾巴指向小狗。
- 失败信号：打开或关闭时小狗跳动 / 面板被裁 / 尾巴不再指向小狗 / `R2 != R0`。

**B2-02（P0）靠右边缘向左弹出 + 抗累积漂移**
- Given：把小狗拖到屏幕最右侧（面板应翻到左边）；记录 `R0`。
- When：重复 B2-01 的动作；再连续开合 10 次。
- Then：面板确实在左（小狗在窗口右侧）；`R1.right == R0.right`；第 10 次关闭后各边与 `R0` ≤2px；不出现「每开合一次被往里挤一点」。
- 失败信号：面板方向判断反了 / 关闭后小狗向左或向右移动 / 10 次后偏移 >2px。

**B2-03（P0）云朵气泡（消息 / 更新 / 剪贴板）**
- Given：设置默认（气泡开、剪贴板气泡开）；收起态；狗在屏幕中左；记录 `R0`。
- When：复制一段 ≥100 字的文本触发剪贴板云朵气泡 → 完全出现后记录 `R1` → 等自动收起（默认 6s，可在设置改 1.5–20s）→ 稳定 500ms 记录 `R2`。再用「设置 → 主动聊天自测 → 立即试一句」触发一条小狗说话云朵（本机模型不可用时，改用整点提醒 / 更新提示 / 消息预览任一条）。
- Then：`R1`/`R2` 满足判据；长文本自动换行不被裁切；气泡自动消失时间与设置一致（±1s）；气泡出现/消失时小狗不动。
- 失败信号：云朵弹出瞬间狗位移 / TTL 到期关闭后回不到原位 / 文字被截断。

**B2-04（P1）右键入口**
- Given：收起态；记录 `R0`。
- When：右键小狗（当前版本：打开聊天页；若本轮恢复右键气泡菜单：弹出右键气泡）。
- Then：无论当前行为是什么，`R1`/`R2` 各边 ≤2px；若为气泡形态，关闭后回到收起态位置；若为聊天页，收起回收起态位置不变。
- 失败信号：右键后狗位移 / 回落偏移 / 面板方向错乱。

**B2-05（P0）气泡 → 展开页 → 关闭回落**
- Given：悬停气泡已打开，记录 `R1`。
- When：点气泡内「待办 / 音乐 / 聊天」任一入口切到展开页 → 收起回收起态 → 再悬停打开气泡并移开关闭。
- Then：切展开页、收起回落、再次开关的每一次跳变，小狗位置 ≤2px；不出现「先缩回去再弹开」的频闪（录屏两帧内完成）；气泡无残留。
- 失败信号：频闪 / 小狗在展开/收起瞬间跳一下 / 残留旧面板。

**B2-06（P0）残影 / 裁切 / 空白**
- Given：连续 5 次打开-关闭悬停气泡。
- When：观察每次关闭后的主窗口与小狗。
- Then：每次关闭后主窗口恢复为小狗槽尺寸；无半透明矩形残影、无旧面板像素残留；打开时面板不被窗口边裁切；小狗 GIF 正常显示不空白。
- 失败信号：任何一次出现残影 / 裁切 / 空白块。

**B2-07（P1）缩边唤醒后立即开气泡**
- Given：设置 → 布局 开启全屏避让/缩边；小狗缩到屏幕底边。
- When：鼠标移入唤醒 → 立刻悬停打开气泡 → 关闭。
- Then：小狗不被拽回屏幕边缘/角落；开合前后 ≤2px；不出现「先跳到角落再回来」。
- 失败信号：唤醒瞬间跳位 / 气泡关闭后停在边缘外 / 位置累积漂移。

**B2-08（P1）闲逛动画期间开气泡**
- Given：开启随机闲逛，等动画进行中。
- When：动画途中打开悬停气泡。
- Then：小狗停在当前位置（≤2px），不被拽到动画终点；关闭后仍停在当前位置。
- 失败信号：小狗瞬间被拉到终点 / 气泡打开后整块面板滑走。

**B2-09（P2）多屏 / 150%**
- When：在副屏、150% 缩放下执行 B2-01、B2-05。
- Then：通过（容差 3px）；面板朝向符合当前工作区，不越界。
- 失败信号：方向判断用错显示器 / 位置跳变。

**B2-10（P0）连续压力**
- Given：与 B2-02 可合并执行。
- When：10 次开合（悬停 + 云朵交替）。
- Then：无累积漂移（最终 ≤2px）、无窗口数/进程数增长、无内存异常（任务管理器观察不明显上涨）。
- 失败信号：偏移逐次增大 / 每次多出一个窗口 / 明显卡顿。
