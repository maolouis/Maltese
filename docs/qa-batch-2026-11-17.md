## 缺陷清单（本批新发现）

### D1（P2）"停止生成"在加载模型阶段只取消流式请求，不取消 Rust 侧加载

- 复现：`POST /unload` → 聊天发消息（进入「正在加载本地模型…」）→ 点「停止」。
- 预期：停止后模型加载也应中止/至少提示"已取消"；再次发送不应被上一轮加载阻塞。
- 实际（代码级）：`stopGeneration` 只标记取消并 `invoke("local_chat_cancel")`、复位 UI（`PetChat.tsx:787-799`）；`local_chat_cancel` 针对流式请求；`ensure_local_model` 的 `/load` 与轮询在 Rust 继续跑（`local_chat.rs:610-644`）→ UI 显示"已停止"但后台仍在加载（最长 240s）。
- 可疑位置：`src/PetChat.tsx:787-799`、`src-tauri/src/local_chat.rs:610-644`。
- 严重级别：P2（不阻塞，但"停止"语义不完整；实机未验证，需研发确认）。

### D2（P3）A3 错误文案分支不一致：改错地址时不是"模型没能加载…"

- 复现：聊天模型 → 接口地址改为 `http://127.0.0.1:9/v1` → 发消息。
- 预期（验收）：给出「模型没能加载：请检查 Strata 是否在运行…」+ 重试。
- 实际（代码级）：`ensure_local_model` 对非 8080 地址直接返回 `Ok(true)`（`local_chat.rs:581-583`），不触发"模型没能加载"分支；随后连接失败，提示「连接不到本地模型服务（…）。请确认服务已启动，并检查接口地址。」（`local_chat.rs:392/230`）——语义正确但文案与验收要求不一致。
- 建议：两种失败（未启动/地址错）统一为可搜到的中文原因，或把验收文案覆盖 `ensure=false` 与 `连接不到` 两类。
- 严重级别：P3（文案/可诊断性）。
