## 规格

- 画布统一 **240×240**，与 `assets/pets/chars/<角色>/<动作>/` 现有素材一致。
- 透明底保留（放射线、白底相框、沙发场景这类自带底色的图也保留原始底色，不被抠掉）。
- 原图是 1080×1080 / 240×240 的多帧 GIF，已按内容并集裁掉留白、等比缩放居中到画布，帧时长与循环次数沿用原图。
- 命名 `p<弹数>-<序号>.gif`，序号对应官方帖九宫格里的顺序。

## 怎么用

这些文件目前只是素材，**没有被代码引用**，不会改变桌宠现在的动作。

- 要作为桌宠动作素材：把它们移/复制到 `assets/pets/chars/shared/<动作>/`（双狗同框放 `shared`，单只放 `xiaobai` / `xiaojimao`），然后跑 `node scripts/build-pet-manifest.mjs` 重新生成清单。
- 要作为聊天/通知贴纸：直接按文件路径引用即可，格式是普通 GIF。

## 采集与复现

- 帖子与图片来自 `https://m.weibo.cn/u/7776232700` 时间线；图片原图地址是把缩略路径 `/orj360/` 换成 `/large/`。
- 抓取脚本 `fetch.py`、归一化脚本 `normalize.py`、原图与拼版预览都放在仓库根目录的 `work/weibo-stickers/`（`work/` 已被 `.gitignore` 忽略），换新弹数时改脚本里的地址列表即可。
