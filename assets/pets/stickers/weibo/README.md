## 规格

- 画布统一 **240×240**，与 `assets/pets/chars/<角色>/<动作>/` 现有素材一致；文件合计约 29.6 MB。
- 透明底保留（沙发、草地、烟花夜景这类自带背景的保持原样），四周留白已裁掉，居中贴到画布，开头/结尾的全透明空帧已剔除。
- 原图多为 1080×1080 多帧 GIF，帧时长与循环沿用原图；个别 GIF 因起始帧与前一帧完全相同会少一帧，不影响观感。
- 命名 `<组>-<序号>.gif`，序号对应官方帖九宫格里的顺序。

## 怎么用

这些文件目前只是素材，**没有被代码引用**，不会改变桌宠现在的动作。

- 当桌宠动作素材：按画面复制到 `assets/pets/chars/shared/<动作>/`（双狗同框放 `shared`，单只放 `xiaobai` / `xiaojimao`），再跑 `node scripts/build-pet-manifest.mjs`。
- 当聊天/通知贴纸：直接按路径引用；想按情绪挑图，先看 `by-emotion.md`。
